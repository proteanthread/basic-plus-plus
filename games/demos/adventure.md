# `adventure` Classic Colossal Cave Style Adventure Engine

## 1. Library Overview & Usage

The `adventure` game library implements the canonical 1970s Colossal Cave Adventure command mechanics, treasure scoring, and dwarf hazard random encounters.

### Features:
- Vocabulary parsing for classic two-word commands (`GO NORTH`, `TAKE LAMP`, `DROP KEYS`, `UNLOCK GRATE`).
- Score tracking for recovered treasures brought to the building.

---

## 2. BASIC Example

```basic
10 PRINT "Welcome to Colossal Cave Adventure!"
20 PRINT "Treasure score: 0 / 350"
```
