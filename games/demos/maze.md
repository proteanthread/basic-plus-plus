# `maze` 2D/3D Maze Generator & Traversal Library

## 1. Library Overview & Usage

The `maze` library provides randomized 2D/3D maze generation algorithms (recursive backtracker, Prim's algorithm, Kruskal's algorithm) and raycasting 3D perspective views.

### Features:
- **Generation Algorithms**: Generates perfect mazes with guaranteed solvable single paths.
- **3D Raycaster**: Pseudo-3D wireframe or textured wall rendering in BGI text or graphics modes.

---

## 2. BASIC Example

```basic
10 DIM MAZE(21, 21)
20 PRINT "Generating 21x21 perfect maze..."
```
