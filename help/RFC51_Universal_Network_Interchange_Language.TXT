==============================================================================
BASIC++ RFC 51 UNIVERSAL NETWORK INTERCHANGE LANGUAGE (NIL) ARCHITECTURE
==============================================================================

The authoritative specification for network payload serialization, stream
compression, and cross-platform binary bead framing based on RFC 51 in
BASIC++ v6.5.2.


1. OVERVIEW AND DESIGN PRINCIPLES

BASIC++ implements the foundational principles of RFC 51 ("Proposal for
a Network Interchange Language") by M. Elie (May 1970). It provides a
compact, architecture-neutral stream serialization and payload
compression layer designed for low-bandwidth networks, low-MTU wireless
links (BLE 20-byte MTU, ESP-NOW 250-byte frames), and NFC sectors (16 bytes).

The NIL subsystem is implemented in:
* engine/src/eval/functions/string/manipulation/func_nil_compress.c
  (COMSTR$, DECOMSTR$, NIL.COMPRESS$, NIL.DECOMPRESS$)
* engine/src/eval/functions/system/hardware/func_nil_bead.c
  (NET.PACK$, NIL.PACK$)
* engine/src/statements/network/stmt_nil_bead.c
  (NET.UNPACK, NIL.UNPACK)


2. RFC 51 STREAM COMPRESSION

NIL provides fast run-length and tokenized whitespace compression to
minimize network transmission latency:

* COMSTR$(raw$) / NIL.COMPRESS$(raw$): Encodes repeating character
  sequences and whitespace into compact RFC 51 escape beads.
* DECOMSTR$(comp$) / NIL.DECOMPRESS$(comp$): Reconstructs the original
  uncompressed string from an RFC 51 compressed stream.


3. BINARY BEAD SERIALIZATION AND DESERIALIZATION

NIL organizes heterogeneous structured data into compact, self-describing
binary beads:

* NET.PACK$(type_tag, val1 [, val2...]) / NIL.PACK$(...): Serializes
  scalar values, strings, and ordinals into a contiguous binary frame.
* NET.UNPACK frame$, var1 [, var2...] / NIL.UNPACK frame$, var1 [, var2...]:
  Unpacks fields from a binary frame directly into destination variables.


4. EXAMPLE: PACKET COMPRESSION AND FRAMING

    10 REM RFC 51 NIL Stream Compression
    20 Payload$ = "SENSOR:TMP:22.50       STATUS:OK       BATTERY:98"
    30 Compressed$ = NIL.COMPRESS$(Payload$)
    40 PRINT "Raw: "; LEN(Payload$); " -> Compressed: "; LEN(Compressed$)
    50 Packet$ = NIL.PACK$("BEAD01", 101, Compressed$)
    60 PRINT "Packaged Bead Length: "; LEN(Packet$)
