BASIC++ PUBLIC C17 API AUDIT & COMPLIANCE MATRIX
======================================================================

1. EXECUTIVE SUMMARY & AUDIT SCOPE
Formal audit of all public C17 APIs, structs, function prototypes, and header
boundaries in the BASIC++ v6.5.2 engine codebase.

Compliance Standards:
- Freestanding ISO C17 cleanliness with zero OS headers in core.
- Memory safety and tagged union BValue representation.
- Two-parameter string release: str_release(vm_get_str(vm), str).
- Non-recursive AST evaluation and interpreter-managed heap stacks.
- Platform decoupling via libplatform encapsulation.
- Descriptive module prefixes (avoiding BPP/bpp prefixes for new code).

3. STRING LIFECYCLE INVARIANT
Every C API returning BValue strings requires the two-parameter release:
  str_release(vm_get_str(vm), val.as.string);
