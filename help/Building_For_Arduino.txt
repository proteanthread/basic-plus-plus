1. Overview

BASIC++ runs on Arduino boards as embedded firmware. The interpreter
provides a BASIC REPL over the serial console (USB). Programs can be
typed interactively or uploaded via the serial monitor.

Arduino boards use the Arduino framework (C++), so a thin C++ wrapper
calls the BASIC++ C core. The BPP_EMBEDDED build profile reduces
memory pools to fit within Arduino's limited SRAM.

Best boards: Arduino Due (96 KB SRAM) and Arduino Mega (8 KB SRAM,
marginal). Arduino Uno/Nano (2 KB SRAM) are NOT viable.


2. Supported Arduino Boards

  Board               MCU                 SRAM                Flash               Status
  ----------------------------------------------------------------------
  Arduino Due         SAM3X8E (ARM)       96 KB               512 KB              Supported
  Arduino Mega 2560   ATmega2560          8 KB                256 KB              Marginal

3. Prerequisites

- Arduino IDE 2.x (or PlatformIO)
- USB cable for your board
- Serial monitor (built into Arduino IDE or PuTTY)


4. Arduino IDE Setup

Step 1: Create a new Arduino sketch.

Step 2: Copy the BASIC++ source files into your sketch folder:
MyBASICPP/
  MyBASICPP.ino         (main sketch -- the C++ wrapper)
  source/               (copy of BASIC++ source directory)

Step 3: In Arduino IDE, go to File > Preferences and ensure
"Compiler warnings" is set to "Default" or "More".

Step 4: Select your board (Tools > Board > Arduino Due).

Step 5: Verify and upload.

Note: The Arduino IDE compiles all .c files found in the sketch
directory and its subdirectories. To exclude files, remove them
from the source/ directory or rename them with a different extension.

6. The C++ Wrapper

Arduino uses C++, but BASIC++ is pure C. You need a thin C++ wrapper:

// MyBASICPP.ino (or main.cpp for PlatformIO)

extern "C" {
    #include "config.h"
    int basicpp_main(int argc, char **argv);
}

void setup() {
    Serial.begin(115200);
    while (!Serial) { ; }   // Wait for USB serial (Due/Leonardo)

    Serial.println("BASIC++ for Arduino starting...");
}

void loop() {
    static int done = 0;
    if (!done) {
        char *argv[] = {"basicpp", NULL};
        basicpp_main(1, argv);
        done = 1;
        Serial.println("BASIC++ exited.");
    }
}

Arduino Mega (8 KB SRAM) -- Absolute minimum (~36 files):

8. Memory Budget

Arduino Due (96 KB SRAM)

Total SRAM:                          96 KB
Arduino framework overhead:         -12 KB
Available for application:          ~84 KB

BASIC++ pools (BPP_EMBEDDED):        -38 KB
RuntimeState (reduced):              -30 KB
C stack:                              -8 KB
                                     ------
Remaining free:                      ~8 KB (tight but viable)

Arduino Mega 2560 (8 KB SRAM)

Total SRAM:                          8 KB
Arduino framework overhead:         -2 KB
Available for application:          ~6 KB

BASIC++ pools (ultra-minimal):       -3 KB
RuntimeState (absolute min):         -2 KB
C stack:                             -0.5 KB
                                     ------
Remaining free:                      ~0.5 KB (VERY tight)

For the Mega, use the ultra-minimal config from
Building_A_Minimal_BASIC++.md section 10 (sizing for 8 KB SRAM).


9. Serial Console (REPL)

The BASIC++ REPL communicates over Serial (USB). Open the Serial
Monitor in Arduino IDE at 115200 baud, line ending "Newline" or
"Both NL & CR":

BASIC++ (Stable) Version 4.0.1
@COPYLEFT ALL WRONGS RESERVED
Ready.
> PRINT "Hello from Arduino!"
Hello from Arduino!

For a custom serial driver using the VDev system:

static int arduino_putc(VDev *d, int ch) {
    (void)d;
    Serial.write((char)ch);
    return 0;
}

static int arduino_getc(VDev *d) {
    (void)d;
    while (!Serial.available()) { /* wait */ }
    return Serial.read();
}


10. Which BASIC Features Work

- REPL (interactive prompt over serial)
- PRINT, INPUT, LET, IF/THEN/ELSE
- FOR/NEXT, WHILE/WEND, DO/LOOP (Union Mode)
- DEF FN user functions
- String operations
- Math functions
- PEEK/POKE virtual memory
- VDev devices (GPIO, I2C, SPI if registered)
- Security sandboxing
- TRON/TROFF trace mode


11. Which BASIC Features Are Excluded

- SHELL / EXEC (no OS)
- Dynamic library loading
- Network I/O
- JIT compilation
- USB module (different USB stack)
- FujiNet / UPnP
- Transpiler/codegen
- File I/O on Mega (no filesystem -- works on Due with SD card)


12. Customizing Pool Sizes

Edit the BPP_EMBEDDED section of config.h. For the Due:

// Comfortable settings for Arduino Due (96 KB)
#define PROGRAM_MEMORY_SIZE   8192L    // 8 KB
#define VARIABLE_MEMORY_SIZE  4096L    // 4 KB
#define SCRATCH_MEMORY_SIZE   2048L    // 2 KB
#define MAX_STRING_POOL       8192L    // 8 KB
#define MAX_ARRAY_ELEMENTS    1024     // ~16 KB

For the Mega (extreme minimization):
#define PROGRAM_MEMORY_SIZE   1024L    // 1 KB
#define VARIABLE_MEMORY_SIZE  512L     // 512 bytes
#define SCRATCH_MEMORY_SIZE   256L     // 256 bytes
#define MAX_STRING_POOL       512L     // 512 bytes
#define MAX_PROGRAM_LINES     32
#define MAX_STACK_DEPTH       8
#define MAX_NAMED_VARS        0
#define MAX_DIM_ARRAYS        0
#define MAX_ARRAY_ELEMENTS    0
#define GFX_WIDTH             0
#define GFX_HEIGHT            0


13. Adding GPIO Access

Register GPIO devices before calling basicpp_main():

#include "vdev.h"

static int gpio_write(VDev *d, const char *data, int len) {
    int pin = (int)(intptr_t)d->user_data;
    int value = (data[0] == '1') ? HIGH : LOW;
    digitalWrite(pin, value);
    return 0;
}

void register_gpio(int pin, const char *name) {
    pinMode(pin, OUTPUT);
    VDev dev;
    memset(&dev, 0, sizeof(dev));
    dev.name = name;
    dev.dev_class = VDCLASS_GPIO;
    dev.dev_caps = VDCAP_WRITE;
    dev.dev_write = gpio_write;
    dev.user_data = (void *)(intptr_t)pin;
    vdev_register(&dev);
}

From BASIC:
OPEN "LED:" FOR OUTPUT AS #1
PRINT #1, "1"     ' LED ON
PRINT #1, "0"     ' LED OFF
CLOSE #1

17. Troubleshooting

Upload fails ("Board not found")
Check your USB cable (data cable, not charge-only). Verify the
correct board is selected in Tools > Board.

"Not enough memory"
Reduce pool sizes in config.h. Use the ultra-minimal config for
Mega. The Due should work with default BPP_EMBEDDED settings.

Serial shows garbage characters
Verify baud rate matches (115200). Check line ending settings
in Serial Monitor.

Crash during deep recursion
Reduce MAX_STACK_DEPTH. Arduino has limited C stack space.

Compiler error: "multiple definition"
Arduino IDE compiles ALL .c files in the sketch folder. Remove
files you do not need from the source/ directory.
