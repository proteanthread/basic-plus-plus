vnet Virtual Network Sockets Subsystem (libserver)
======================================================================

The vnet library provides TCP/UDP socket networking, network channel
streams, and non-blocking I/O polling.


FEATURES
----------------------------------------------------------------------

  - Non-blocking socket communication.
  - Sockets open as standard BASIC channels (OPEN "N:TCP://...").
  - Security capability checked (CAP_NET).


C17 INTERFACE
----------------------------------------------------------------------

    VNetSocket *vnet_connect(const char *host, int port, int proto);
    VNetSocket *vnet_listen(int port, int backlog);
    int vnet_send(VNetSocket *sock, const void *buf, size_t len);
    int vnet_recv(VNetSocket *sock, void *buf, size_t max_len);
    void vnet_close(VNetSocket *sock);
