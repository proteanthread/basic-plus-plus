1. DESCRIPTION & USAGE
------------------------------------------------------------------------------
Encodes a double-precision floating-point number into an 8-byte fielded binary
string.

------------------------------------------------------------------------------
2. SYNTAX
------------------------------------------------------------------------------

------------------------------------------------------------------------------

------------------------------------------------------------------------------
