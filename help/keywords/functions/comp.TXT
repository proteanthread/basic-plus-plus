------------------------------------------------------------------------------
1. DESCRIPTION & USAGE
------------------------------------------------------------------------------
Compares two numeric expressions a and b; returns -1 if a < b, 0 if a == b,
and 1 if a > b.

------------------------------------------------------------------------------
2. SYNTAX
------------------------------------------------------------------------------
