------------------------------------------------------------------------------
1. DESCRIPTION & USAGE
------------------------------------------------------------------------------
Packs binary data values into a binary string according to format template
fmt$.

------------------------------------------------------------------------------
2. SYNTAX
------------------------------------------------------------------------------
    PACK$(fmt$, val1 [, val2, ...])

------------------------------------------------------------------------------
3. CODE EXAMPLE
------------------------------------------------------------------------------
    10 Val = PACK$(fmt$, val1 [, val2, ...])
