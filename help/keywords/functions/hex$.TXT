------------------------------------------------------------------------------
1. DESCRIPTION & USAGE
------------------------------------------------------------------------------
HEX$(x) returns hexadecimal string of number x (GW-BASIC); HEX(s$) decodes hex
string to raw binary byte string (Wang 3300).

------------------------------------------------------------------------------
2. SYNTAX
------------------------------------------------------------------------------
    HEX$(x) | HEX(hex_str$)

------------------------------------------------------------------------------
3. CODE EXAMPLE
------------------------------------------------------------------------------
    10 Val = HEX$(10) | HEX(he10_str$)
    20 PRINT "Result: "; Val
