------------------------------------------------------------------------------
1. DESCRIPTION & USAGE
------------------------------------------------------------------------------
Performs linear interpolation between a and b using weight t (a + (b - a) *
t).

------------------------------------------------------------------------------
2. SYNTAX
------------------------------------------------------------------------------
