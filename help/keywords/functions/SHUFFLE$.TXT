------------------------------------------------------------------------------
1. DESCRIPTION & USAGE
------------------------------------------------------------------------------
Returns a copy of str$ with all characters randomly scrambled using
Fisher-Yates shuffle.

------------------------------------------------------------------------------
2. SYNTAX
------------------------------------------------------------------------------
    SHUFFLE$(str$ [, seed])

------------------------------------------------------------------------------
3. CODE EXAMPLE
------------------------------------------------------------------------------
    10 Val = SHUFFLE$(str$ [, seed])
