BASIC++ FUNCTION REFERENCE: UBOUND
======================================================================

1. SYNTAX & DESCRIPTION
  result = UBOUND(arrayname [, dimension])

Returns the highest valid subscript index for the specified dimension of an array.

2. PARAMETERS & RETURN VALUES
- arrayname: The name of the declared array.
- dimension: Optional 1-based dimension index (default: 1).
- Returns: Integer representing the upper bound.

3. ERROR CODES
- Error 9 (ERR_SUBSCRIPT_OUT_OF_RANGE): Array does not exist or dimension out of range.

4. EXAMPLES
  10 DIM A(100)
  20 PRINT UBOUND(A)    : REM Outputs: 100
