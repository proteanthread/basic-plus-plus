LGT Common (Base-10) Logarithm Function
======================================================================

The LGT function computes the base-10 logarithm log10(x).


SYNTAX
----------------------------------------------------------------------

    result# = LGT(numeric_expression)


DOMAIN
----------------------------------------------------------------------

  - x > 0 (Error 5 if <= 0).


CODE EXAMPLES
----------------------------------------------------------------------

    10 PRINT LGT(10)   : REM Outputs 1
