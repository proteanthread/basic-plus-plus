------------------------------------------------------------------------------
1. DESCRIPTION & USAGE
------------------------------------------------------------------------------
Reads a record from a random-access file or captures a screen rectangle into a
memory array.

------------------------------------------------------------------------------
2. SYNTAX
------------------------------------------------------------------------------
    GET [#]file_num [, record_number] | GET (x1, y1)-(x2, y2), array_name

------------------------------------------------------------------------------
3. CODE EXAMPLE
------------------------------------------------------------------------------
