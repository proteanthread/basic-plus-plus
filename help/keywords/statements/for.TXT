------------------------------------------------------------------------------
1. DESCRIPTION & USAGE
------------------------------------------------------------------------------
Initiates a counter-controlled loop block executing statements until var
reaches end.

------------------------------------------------------------------------------
2. SYNTAX
------------------------------------------------------------------------------
    FOR var = start TO end [STEP step]

------------------------------------------------------------------------------
3. CODE EXAMPLE
------------------------------------------------------------------------------
    10 FOR I = 1 TO 5
    20   PRINT "Iteration: "; I
    30 NEXT I

------------------------------------------------------------------------------
4. ERROR CONDITIONS
------------------------------------------------------------------------------
Error 2: Syntax Error, Error 13: Type Mismatch, Error 26: FOR Without NEXT
