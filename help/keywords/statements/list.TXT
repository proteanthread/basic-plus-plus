LIST Program Source Listing Command
===================================

Lists program source lines from memory to the active console screen.


SYNTAX
----------------------------------------------------------------------

    LIST [start_line%] - [end_line%]


OPERATIONAL NOTES
----------------------------------------------------------------------

  Supports single line, range, and open-ended range specifiers.


CODE EXAMPLES
----------------------------------------------------------------------

    LIST        : REM List all lines
    LIST 100-200 : REM List lines 100 through 200
