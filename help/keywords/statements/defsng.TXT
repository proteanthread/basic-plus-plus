DEFSNG Define Single-Precision Default Type
======================================================================

The DEFSNG statement declares that all variable identifiers beginning
with the specified letter(s) or ranges default to single-precision float.


SYNTAX
----------------------------------------------------------------------

    DEFSNG letter_range [, letter_range2, ...]


OPERATIONAL RULES
----------------------------------------------------------------------

  - Declares single-precision float for matching variable names.
  - Overridden by explicit suffixes (%, #, $).


ERROR CODES
----------------------------------------------------------------------

  Error Code  Name                  Condition
  ----------  --------------------  ----------------------------------
  2           ERR_SYNTAX_ERROR      Invalid letter range syntax


CODE EXAMPLES
----------------------------------------------------------------------

    10 DEFSNG A-Z
    20 X = 1.2345
    30 PRINT X
