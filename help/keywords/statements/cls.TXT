------------------------------------------------------------------------------
1. DESCRIPTION & USAGE
------------------------------------------------------------------------------
Clears screen and moves cursor to (1, 1), optionally setting foreground and
background colors.

------------------------------------------------------------------------------
2. SYNTAX
------------------------------------------------------------------------------
    CLS [[fg] [, bg]]

------------------------------------------------------------------------------
3. CODE EXAMPLE
------------------------------------------------------------------------------
    10 SCREEN 0 : WIDTH 80
    20 COLOR 14, 1
    30 CLS
