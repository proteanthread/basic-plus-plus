------------------------------------------------------------------------------
1. DESCRIPTION & USAGE
------------------------------------------------------------------------------
Dynamically binds an external dynamic shared library (DLL/.so) C symbol for
direct calling in BASIC++.

------------------------------------------------------------------------------
2. SYNTAX
------------------------------------------------------------------------------

------------------------------------------------------------------------------
3. CODE EXAMPLE
------------------------------------------------------------------------------
