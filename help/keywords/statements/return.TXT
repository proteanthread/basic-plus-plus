------------------------------------------------------------------------------
1. DESCRIPTION & USAGE
------------------------------------------------------------------------------
Returns control from a GOSUB subroutine to the statement following GOSUB, or
specified line.

------------------------------------------------------------------------------
2. SYNTAX
------------------------------------------------------------------------------
    RETURN [line_num]

------------------------------------------------------------------------------
3. CODE EXAMPLE
------------------------------------------------------------------------------
    10 REM RETURN Demonstration
    20 PRINT "RETURN executed successfully."

------------------------------------------------------------------------------

------------------------------------------------------------------------------
