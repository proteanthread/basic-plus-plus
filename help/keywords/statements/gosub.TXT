------------------------------------------------------------------------------
1. DESCRIPTION & USAGE
------------------------------------------------------------------------------
Pushes current line onto stack and branches execution to specified subroutine
line number, expression, or label.

------------------------------------------------------------------------------
2. SYNTAX
------------------------------------------------------------------------------
    GOSUB line_num | expr | label

------------------------------------------------------------------------------
3. CODE EXAMPLE
------------------------------------------------------------------------------
    10 REM GOSUB Demonstration
    20 PRINT "GOSUB executed successfully."

------------------------------------------------------------------------------
4. ERROR CONDITIONS
------------------------------------------------------------------------------
Error 8: Undefined line number (subroutine target missing), Error 2: Syntax
error (missing line number)
