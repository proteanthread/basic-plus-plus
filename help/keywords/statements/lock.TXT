------------------------------------------------------------------------------
1. DESCRIPTION & USAGE
------------------------------------------------------------------------------
Locks a file on disk (Apple /// Business BASIC) or locks a file channel/record
range (QuickBASIC).

------------------------------------------------------------------------------
2. SYNTAX
------------------------------------------------------------------------------
    LOCK filepath$ | LOCK [#]file_num [, [record_start] [TO record_end]]

------------------------------------------------------------------------------
