------------------------------------------------------------------------------
1. DESCRIPTION & USAGE
------------------------------------------------------------------------------
Pre-compiles the current program in memory Ahead-Of-Time (AOT) into JIT
bytecode blocks.

------------------------------------------------------------------------------
2. SYNTAX
------------------------------------------------------------------------------
