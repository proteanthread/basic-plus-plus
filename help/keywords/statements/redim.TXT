------------------------------------------------------------------------------
1. DESCRIPTION & USAGE
------------------------------------------------------------------------------
Changes the dimensions and size of dynamic arrays, optionally preserving
existing data.

------------------------------------------------------------------------------
2. SYNTAX
------------------------------------------------------------------------------
    REDIM [PRESERVE] array_name(subscripts...)

------------------------------------------------------------------------------
3. CODE EXAMPLE
------------------------------------------------------------------------------
    10 DIM Arr(10)
    20 Arr(5) = 100
    30 PRINT "Arr(5) = "; Arr(5)

------------------------------------------------------------------------------
4. ERROR CONDITIONS
------------------------------------------------------------------------------
Error 2: Syntax Error, Error 9: Subscript out of range
