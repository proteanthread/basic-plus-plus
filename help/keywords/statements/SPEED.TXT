------------------------------------------------------------------------------
1. DESCRIPTION & USAGE
------------------------------------------------------------------------------
Configures console output throttling speed. Values <= 255 set Apple II delay
scale (0..255); values > 255 or SPEED& set baud rate in bps (45.45 up to
115200+).

------------------------------------------------------------------------------
2. SYNTAX
------------------------------------------------------------------------------
    SPEED [=] rate | SPEED% = val% | SPEED& = rate&
