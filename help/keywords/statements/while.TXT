------------------------------------------------------------------------------
1. DESCRIPTION & USAGE
------------------------------------------------------------------------------
Executes a series of statements in a loop as long as condition evaluates to
non-zero (true).

------------------------------------------------------------------------------
2. SYNTAX
------------------------------------------------------------------------------
    WHILE condition

------------------------------------------------------------------------------
3. CODE EXAMPLE
------------------------------------------------------------------------------
    10 C = 1
    20 WHILE C <= 3
    30   PRINT C : C = C + 1
    40 WEND

------------------------------------------------------------------------------
4. ERROR CONDITIONS
------------------------------------------------------------------------------
Error 2: Syntax Error, Error 30: WHILE Without WEND
