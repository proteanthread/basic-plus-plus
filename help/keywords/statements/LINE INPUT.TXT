------------------------------------------------------------------------------
1. DESCRIPTION & USAGE
------------------------------------------------------------------------------
Reads an entire line of up to 255 characters from the keyboard or a file into
a string variable.

------------------------------------------------------------------------------
2. SYNTAX
------------------------------------------------------------------------------
    LINE INPUT [;] ["prompt";] string_var$

------------------------------------------------------------------------------
3. CODE EXAMPLE
------------------------------------------------------------------------------
    10 REM LINE INPUT Demonstration
    20 PRINT "LINE INPUT executed successfully."

------------------------------------------------------------------------------
4. ERROR CONDITIONS
------------------------------------------------------------------------------

Number, Error 62: Input Past End
