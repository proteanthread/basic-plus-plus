------------------------------------------------------------------------------
1. DESCRIPTION & USAGE
------------------------------------------------------------------------------
Evaluates boolean expression and executes THEN clause if false, ELSE clause if
true (DEC / Tymshare).

------------------------------------------------------------------------------
2. SYNTAX
------------------------------------------------------------------------------
