------------------------------------------------------------------------------
1. DESCRIPTION & USAGE
------------------------------------------------------------------------------
Executes a series of statements that reference the members of a single object
or UDT.

------------------------------------------------------------------------------
2. SYNTAX
------------------------------------------------------------------------------
    WITH object 
 .member = expression 
 ... 
 END WITH

------------------------------------------------------------------------------
3. CODE EXAMPLE
------------------------------------------------------------------------------
    10 REM WITH Demonstration
