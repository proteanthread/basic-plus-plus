1. DESCRIPTION & USAGE
------------------------------------------------------------------------------
Dynamically associates a disk file specification or I/O device with an I/O
path descriptor or channel (HP-3000 / HP-9845).

------------------------------------------------------------------------------
2. SYNTAX
------------------------------------------------------------------------------
