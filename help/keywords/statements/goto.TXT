------------------------------------------------------------------------------
1. DESCRIPTION & USAGE
------------------------------------------------------------------------------
Unconditionally transfers execution to the specified program line number,
expression, or label.

------------------------------------------------------------------------------
2. SYNTAX
------------------------------------------------------------------------------

------------------------------------------------------------------------------
3. CODE EXAMPLE
------------------------------------------------------------------------------
    10 REM GOTO Demonstration

------------------------------------------------------------------------------

------------------------------------------------------------------------------
