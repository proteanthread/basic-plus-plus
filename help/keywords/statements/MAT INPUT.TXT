------------------------------------------------------------------------------
1. DESCRIPTION & USAGE
------------------------------------------------------------------------------
Reads numeric or string matrix elements from console input or an open file
stream (SDS 940 / DEC PDP-10 Super BASIC).

------------------------------------------------------------------------------
2. SYNTAX
------------------------------------------------------------------------------
    MAT INPUT [#file_num,] array_name [(num_rows [, num_cols])]

------------------------------------------------------------------------------
3. CODE EXAMPLE
------------------------------------------------------------------------------
    10 Val = MAT INPUT [#file_num,] array_name [(num_rows [, num_cols])]
    20 PRINT "Result: "; Val
