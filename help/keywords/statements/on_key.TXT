------------------------------------------------------------------------------
1. DESCRIPTION & USAGE
------------------------------------------------------------------------------
Establishes an asynchronous interrupt handler for function key presses, or
toggles/customizes row 25 function key labels.

------------------------------------------------------------------------------
2. SYNTAX
------------------------------------------------------------------------------
    ON KEY(n) GOSUB line_label | KEY(n) {ON|OFF|STOP} | KEY ON | KEY OFF | KEY n, string

------------------------------------------------------------------------------
3. CODE EXAMPLE
------------------------------------------------------------------------------
