------------------------------------------------------------------------------
1. DESCRIPTION & USAGE
------------------------------------------------------------------------------
Randomly shuffles array elements or string characters in-place using
Fisher-Yates algorithm.

------------------------------------------------------------------------------
2. SYNTAX
------------------------------------------------------------------------------
    SHUFFLE arr[()] [, seed] | SHUFFLE (arr [, seed]) | SHUFFLE str$ [, seed]

------------------------------------------------------------------------------
3. CODE EXAMPLE
------------------------------------------------------------------------------
    10 Val = SHUFFLE arr[()] [, seed] | SHUFFLE (arr [, seed]) | SHUFFLE str$ [, seed]
    20 PRINT "Result: "; Val
