======================================================================
  1. PURPOSE
======================================================================

This document tracks the completeness and accuracy of the BASIC++ documentation suite. Each documentation file should contain topic-specific technical content that is unique to its subject, not shared boilerplate.


======================================================================
  2. DOCUMENTATION STRUCTURE
======================================================================

The documentation is organized in two parallel directories:

- **docs/** ? Markdown files (.md) with full formatting, code blocks, and tables.
- **help/** ? Plaintext files (.TXT) mirroring the content of docs/ with markdown syntax stripped.

Every .md file in docs/ must have a corresponding .TXT file in help/ with identical technical content.

======================================================================
  4. AUDIT CRITERIA
======================================================================

Each document is evaluated against these criteria:

1. **Unique Content** ? The document contains prose specific to its topic, not duplicated from other documents.
2. **Technical Accuracy** ? Facts, code examples, error codes, and source file references match the v6.5.2 engine.
3. **Completeness** ? The document covers its topic thoroughly, not just superficially.
4. **Help Mirror Parity** ? The .TXT file matches the .md file in content (formatting differences are expected).
5. **Version Currency** ? References use v6.5.2 details (engine/ paths, BppError codes, BppKeywordId values), not legacy v5 details.
