CLOCK$

1. Syntax & Parameters
CLOCK$

- Parameters: None.
- Return Type: String (Format: YYYY-MM-DD HH:MM:SS)

2. Description & Usage
The CLOCK$ system variable retrieves the current system date and time as a fully formatted, human-readable string. 
It combines the functionality of DATE$ and TIME$ into a single, unified ISO 8601-like timestamp representation.
This variable is particularly useful for timestamping log files, database entries, or any application that requires a precise recording of when an event occurred. 
It is evaluated dynamically at runtime, ensuring that every invocation captures the exact system time at that specific moment of execution.

3. Code Examples
`basic
10 PRINT "Current Timestamp: "; CLOCK$
20 OPEN "app.log" FOR APPEND AS #1
30 PRINT #1, "[" + CLOCK$ + "] Application started."
40 CLOSE #1
`

5. Implementation Details
When the parser encounters KWCLOCKFUNC during expression evaluation (around line 1415 in parser_expr.c), it queries the underlying C standard library time() and localtime() functions. 
A buffer of 64 characters is allocated on the C stack. It formats the system time using sprintf with the pattern "%04d-%02d-%02d %02d:%02d:%02d", extracting tm->tmyear + 1900, tm->tmmon + 1, tm->tmmday, tm->tmhour, tm->tmmin, and tm->tmsec from the struct tm populated by localtime(). 
The resulting 19-character string is then dynamically pushed into the string pool via strpoolstore(&rt->strpool, buf, 19), and a BVal of type string is pushed onto the expression value stack (valstack).

If the system time is unavailable or localtime() returns a corrupted structure, the behavior relies on the standard library's fallback mechanisms, which could result in epoch timestamps.

7. Historical Context
CLOCK$ is an extended feature in BASIC++ that does not exist in standard GW-BASIC or QBASIC. In legacy dialects, developers were forced to concatenate DATE$ and TIME$ manually (e.g., DATE$ + " " + TIME$). CLOCK$ provides a standardized, locale-independent timestamp format that aligns more closely with modern logging and database standards.
