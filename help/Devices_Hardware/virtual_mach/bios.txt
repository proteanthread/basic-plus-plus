=== BIOS STATEMENT HELP ===
Syntax:
  BIOS <int_num%>

Description:
  Executes an emulated x86 BIOS/DOS software interrupt. The CPU registers
  are set using standard integer variables before the call and updated
  upon return.

Register Variables:
  AX%      Accumulator register (AH=high byte, AL=low byte)
  BX%      Base register (BH=high byte, BL=low byte)
  CX%      Count register (CH=high byte, CL=low byte)
  DX%      Data register (DH=high byte, DL=low byte)
  FLAGS%   CPU status flags (e.g. Carry Flag is bit 0)

Common Interrupts:
  &H10     Video Services (AH=00h set mode, AH=02h set cursor, etc.)
  &H12     Get Conventional Memory Size (returns size in AX% in KB)
  &H16     Keyboard Services (AH=00h read key, AH=01h check key)
  &H1A     System Time/Ticks (AH=00h read clock ticks)
  &H21     MS-DOS Services (AH=09h write string, AH=3Dh open file)

Example:
  10 AX% = &H1200
  20 BIOS &H12
  30 PRINT "Conventional memory size:"; AX%; "KB"
