Commands (Direct Mode)

| Command / Syntax | Description |
|:---|:---|
| ALIAS "name" = KEYWORD | Define keyword alias (e.g. ALIAS "AFFICHER" = PRINT) |
| ALIAS CLEAR "name" | Remove custom alias |
| ALIAS CLEAR ALL | Remove all custom aliases |
| ALIAS LIST | List all active aliases |
| BACKTRACE | Show GOSUB/FOR/WHILE call stack backtrace |
| BLOAD "filename", address | Load binary file into memory at specific address |
| BSAVE "filename", address, length | Save memory range to binary file |
| BRUN "filename" | Load and run binary P-Code program |
| BIOS "name" | Switch active mock BIOS profile (e.g. "IBMPC") |
| BYE | Exit the interpreter |
| CHECK | Analyze program syntax currently in memory |
| COMPILE "src.bas", "dest.bpp" | Transpile BASIC source to bytecode |
| CONT | Continue program execution from STOP/BREAK |
| COPY "src", "dest" | Copy a file |
| DELETE n1-n2 | Delete line range from program |
| DIALECT "code" | Switch BASIC dialect (e.g. "GWBS", "SQLB", "QBAS") |
| DIR [pattern] | List directory filenames only (short format) |
| DUMP | Dump variables or memory state |
| FILES [pattern] | List directory with sizes and details |
| HELP [topic] | Show help reference for interpreter or keyword |
| LIST [n1-n2] | Display program lines |
| LOAD "filename" | Load program from disk |
| MEMMAP "name" | Select active memory map profile (e.g. "QL", "C64") |
| MERGE "filename" | Merge program from disk into current program |
| MODULE LOAD "filename" | Load extension module |
| MODULE LIST | List all loaded modules |
| MOVE "src", "dest" | Move or rename a file |
| NEW | Clear program and variables from memory |
| OVERRIDE keyword "text" | Intercept and rewrite keyword behaviour |
| OVERRIDE keyword CLEAR | Restore default keyword behaviour |
| OVERRIDE LIST | List all active keyword overrides |
| OVERRIDE RESET | Clear all active overrides |
| RENAME "old", "new" | Rename a .BAS or .BPP file |
| RENUM [new_start[, increment]] | Renumber program lines |
| RUN [line] | Execute program from memory |
| SAVE ["filename"] | Save program to disk |
| SCOPE keyword hook | Set keyword access control or GOSUB hooks |
| SELFTEST | Run built-in validation suite |
| SYSTEM | Exit BASIC++ interpreter |
| TROFF | Disable line trace output |
| TRON | Enable line trace output |
| VERIFY "filename" | Verify syntax of program file on disk |
| VARS [ENV \| SYSTEM \| ALL] | List variables or environment state |
