
Porting the Portable Mock BIOS Subsystem
========================================
=========================================
Version 4.5.0

This document describes how to extract and port the BASIC++ Portable Mock BIOS Subsystem (mock_bios.c and mock_bios.h) into other external projects—such as bare-metal kernels, standalone x86/8086 emulators, legacy interpreter environments, or educational simulation tools.

---


1. Overview & Architecture
--------------------------

The Portable Mock BIOS is designed with a strict isolation pattern. It contains zero dependencies on the BASIC++ interpreter core (such as RuntimeState, BValue, or compiler modules). It communicates with the host system and the guest virtual memory space solely through client-supplied callback function pointers stored inside the MockBiosContext structure.

       +---------------------------------------------+
       |             Your External Project           |
       |  (Emulator, Compiler, or Operating Kernel)  |
       +----------------------------+----------------+
                                    |
                    Context Struct  |  Callback
                       & Config     |  Routines
                                    v
       +---------------------------------------------+
       |        Portable Mock BIOS Subsystem         |
       |               (mock_bios.c)                 |
       +-----+------------------+---------------+-----+
             |                  |               |
             v                  v               v
       +-----------+      +-----------+   +-----------+
       |    BDA    |      |    IVT    |   | Port I/O  |
       | Emulation |      | Setup/INT |   | (PPI/PIT) |
       +-----------+      +-----------+   +-----------+

---


2. The MockBiosContext Structure
----------------------------------

Every API function in the mock BIOS requires a pointer to a MockBiosContext structure. This structure holds state information and defines the host-guest bridge callbacks:

typedef struct MockBiosContext {
    /* Guest Memory Access */
    uint8_t (*read_mem)(void *user_data, uint32_t addr);
    void (*write_mem)(void *user_data, uint32_t addr, uint8_t val);

    /* Host Peripheral Interface */
    int (*vdev_inkey)(void *user_data);
    void (*vdev_sleep)(void *user_data, int ms);
    void (*vdev_printer_out)(void *user_data, uint8_t ch);

    /* Guest CPU registers */
    void (*get_registers)(void *user_data, uint32_t *ax, uint32_t *bx, uint32_t *cx, uint32_t *dx, uint32_t *flags);
    void (*set_registers)(void *user_data, uint32_t ax, uint32_t bx, uint32_t cx, uint32_t dx, uint32_t flags);

    void *user_data;       /* Arbitrary client context payload pointer */
    MockBiosModel model;   /* Active emulation: PC, XT, AT, PCjr, MSDOS */

    /* Persistent internal states */
    int key_buffer;
    uint8_t cmos_idx;
    uint8_t cmos_regs[64];
    uint8_t ppi_port_b;
    uint8_t pit_counter;
    uint8_t crtc_index;
    uint8_t crtc_regs[32];
} MockBiosContext;

3. Emulated Memory Mappings
---------------------------

When mock_bios_init_mem is called, it populates standard IBM PC signatures and data tables inside the guest's 1 MB segment:


3.1. Interrupt Vector Table (IVT)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Points all 256 vector registers (0x0000:0x0000 to 0x0000:0x03FF) to standard ROM service segment boundaries at 0xF000 with offset values starting at 0x1000 + (int_num * 16).


3.2. BIOS Data Area (BDA)
~~~~~~~~~~~~~~~~~~~~~~~~~
Pre-populates the memory segment 0x0040:0x0000 with:
*   0x0400 (COM1-COM4): Standard base addresses (0x03F8, 0x02F8, etc.).
*   0x0408 (LPT1-LPT3): Base addresses (0x0378, 0x0278, etc.).
   0x0410 (Equipment Word): Emulates keyboard, diskette count, and screen settings.
   0x0413 (Conventional RAM): Returns conventional size (e.g. 640 KB -> 0x0280).
   0x0449 (Video Mode): Video mode tracking columns, active page, and CRT controller base port addresses.
   0x046C (Tick Counters): Standard timer ticks.


3.3. Extended ROM Signatures
~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Depending on MockBiosModel:
*   PCjr (BIOSMODELPCJR): Registers cartridge signature headers 55AAh at segment D000h (0xD0000).
*   XT (BIOSMODELXT) / AT (BIOSMODELAT): Registers hard disk BIOS extension signatures 55AAh at segment C800h (0xC8000).
*   Model Bytes: Places the specific system model identifier signature at 0xFFFFE (PC = 0xFF, XT = 0xFE, AT = 0xFC, PCjr = 0xFD).

4. Emulated Ports & Interrupts
------------------------------


4.1. I/O Ports
~~~~~~~~~~~~~~
If your external project supports IN and OUT cpu operations, route port ranges to mock_bios_in and mock_bios_out:
   PPI System Control (Port 61h): Speaker gate, sound toggle, keyboard flags.
   PIT Timers (Ports 40h-43h): Ticks and counter loops.
   CGA Register Indexing (Ports 3D4h-3D5h): Cursor tracking.
   CMOS RTC (Ports 70h-71h): CMOS index tracking. Emulates CMOS Real-Time Clock minutes, seconds, hours, and conventional/extended memory sizes on AT models.


4.2. Interrupts (mock_bios_interrupt)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Enables dynamic BIOS routines execution:
   INT 10h: Video services (Mode queries, set cursor, write teletype char).
   INT 11h/12h: Equipment list and RAM size queries.
   INT 13h: Disk Reset/Sector reads.
   INT 15h: Delay wait loops & extended memory size detection.
   INT 16h: Blocking/non-blocking keyboard key checks.
   INT 17h: LPT printer streams (mirrored on stdout/stderr and written to PRINTER.BIN/TXT).
   INT 1Ah: Tick timer clock and RTC dates reads.
   INT 21h: MS-DOS services (String output, character input/output, key status, DOS version, program termination).
*   INT 23h: MS-DOS Control-C exit handler.

5. Integration Code Example
---------------------------

Below is a complete, minimal compilation template showing how to bridge an external project memory segment and registers to the Portable Mock BIOS subsystem:

#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include "virtual/mock_bios.h"

/* Dummy project memory segment (1 MB) and CPU registers */
uint8_t guest_ram[1048576];
uint32_t cpu_ax, cpu_bx, cpu_cx, cpu_dx, cpu_flags;

/* Guest Memory Callbacks */
uint8_t read_mem_cb(void *user_data, uint32_t addr) {
    if (addr < 1048576) return guest_ram[addr];
    return 0;
}

void write_mem_cb(void *user_data, uint32_t addr, uint8_t val) {
    if (addr < 1048576) guest_ram[addr] = val;
}

/* Host Timing/Input Callbacks */
int inkey_cb(void *user_data) {
    /* Poll host stdin / keyboard buffer here */
    return 0; 
}

void sleep_cb(void *user_data, int ms) {
    /* Perform platform-specific sleep/wait */
}

void printer_cb(void *user_data, uint8_t ch) {
    putchar(ch);
    fflush(stdout);
}

/* Guest CPU register Callbacks */
void get_registers_cb(void *user_data, uint32_t *ax, uint32_t *bx, uint32_t *cx, uint32_t *dx, uint32_t *flags) {
    *ax = cpu_ax;
    *bx = cpu_bx;
    *cx = cpu_cx;
    *dx = cpu_dx;
    *flags = cpu_flags;
}

void set_registers_cb(void *user_data, uint32_t ax, uint32_t bx, uint32_t cx, uint32_t dx, uint32_t flags) {
    cpu_ax = ax;
    cpu_bx = bx;
    cpu_cx = cx;
    cpu_dx = dx;
    cpu_flags = flags;
}

int main(void)
{
    MockBiosContext bios;
    memset(&bios, 0, sizeof(bios));

    /* Initialize callbacks and target model */
    bios.read_mem = read_mem_cb;
    bios.write_mem = write_mem_cb;
    bios.vdev_inkey = inkey_cb;
    bios.vdev_sleep = sleep_cb;
    bios.vdev_printer_out = printer_cb;
    bios.get_registers = get_registers_cb;
    bios.set_registers = set_registers_cb;
    bios.user_data = NULL;

    /* Initialize memory maps for IBM AT */
    mock_bios_init_mem(&bios, guest_ram, sizeof(guest_ram), BIOS_MODEL_AT);
    printf("Mock BIOS initialized successfully. AT Model Signature: 0x%02X\n", guest_ram[0xFFFFE]);

    /* Test INP port operation */
    uint8_t ppi_val = mock_bios_in(&bios, 0x61);
    printf("PPI System Control Port B value: 0x%02X\n", ppi_val);

    /* Test Interrupt call (e.g. Get RAM size INT 12h) */
    cpu_ax = 0;
    mock_bios_interrupt(&bios, 0x12);
    printf("Conventional Memory Size (AX): %d KB\n", cpu_ax);

    return 0;
}
