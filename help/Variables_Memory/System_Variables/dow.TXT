DOW

1. Syntax & Parameters
`basic
DOW

`
Parameters:

2. Description & Usage
The DOW (Day Of Week) keyword returns a numeric value from 1 to 7 corresponding to the current day of the week. Depending on the dialect, 1 may represent Sunday or Monday. It is strictly a read-only variable/function.
Usage scenarios include execution timing, random seed initialization, calendar calculations, and strictly emulating historical time behaviors across different dialects.

3. Code Examples
`basic
10 W = DOW
20 IF W = 1 THEN PRINT "It is Sunday!"
`

5. Implementation Details
Tokenized as KWDOW. Evaluation relies on the <time.h> structure tmwday. Must ensure that the return value correctly maps to the 1-7 range expected by the dialect (usually Sunday=1, Saturday=7). Any failure in evaluation will result in an ERRSYNTAX if the keyword falls through parserexpr.c without an explicit handler.
Troubleshooting: If execution yields a syntax error or a type mismatch, ensure the dialect parser explicitly supports the token in parser_expr.c. Memory allocation issues during string polling (for $ variants) will trigger an OOM panic.
