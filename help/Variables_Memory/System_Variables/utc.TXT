UTC

1. Syntax & Parameters

Syntax:
`basic
UTC
`
Parameters:
- None. UTC is a read-only Numeric System Variable.

2. Description & Usage

Returns the current timezone offset from UTC in seconds (e.g., -21600.0 for UTC-06:00, or 19800.0 for UTC+05:30).
Because it is a system variable, it does not require parentheses. It is read-only; you cannot assign a value to it.

3. Code Examples

Example:
`basic
PRINT "UTC offset in seconds: "; UTC
`
