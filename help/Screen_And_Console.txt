==============================================================================
BASIC++ v6.5.2 SCREEN AND CONSOLE OPERATIONS ARCHITECTURE
==============================================================================

The authoritative specification for text display modes, cursor control,
color attributes, text windows, and console I/O in BASIC++ v6.5.2.


1. TEXT MODE CONFIGURATION

BASIC++ provides comprehensive console manipulation functions across
standard terminals, virtual consoles, and graphical windowing interfaces:

* SCREEN 0: Selects text display mode (default startup mode). Text mode
  operates on a grid of character cells containing ASCII characters and
  color attributes.
* WIDTH cols [, rows]: Configures console text grid dimensions.
  Standard widths include 40 (compact), 80 (standard), and 132 (wide).
* CLS [mode]: Clears console display buffer, repositions cursor to home
  (row 1, col 1), or clears a designated viewport.


2. CURSOR POSITIONING AND INSPECTION

* LOCATE [row] [, [col] [, [visible] [, [start] [, stop]]]]: Positions
  the text cursor at 1-based coordinates (row, col). Optional parameters
  configure cursor visibility (0 = hidden, 1 = visible) and hardware
  scan-line cursor shape.
* CSRLIN: Built-in function returning current vertical cursor row
  (1-based integer).
* POS(dummy): Built-in function returning current horizontal cursor
  column (1-based integer).


3. COLORS AND TEXT VIEWPORTS

* COLOR [foreground] [, [background] [, border]]: Configures active
  text attributes using standard 16-color CGA/EGA/VGA color palettes
  (foreground 0-15, background 0-7).
* VIEW PRINT [top TO bottom]: Establishes a scrolling text viewport
  between lines top and bottom. Text output inside viewport scrolls
  independently while leaving header and status lines fixed.


4. EXAMPLE: FORMATTED TEXT CONSOLE SCREEN

    10 SCREEN 0 : WIDTH 80 : CLS
    20 COLOR 14, 1 : LOCATE 1, 1
    30 PRINT "================ BASIC++ SYSTEM CONSOLE ================"
    40 VIEW PRINT 3 TO 22
    50 COLOR 15, 0 : CLS
    60 FOR I = 1 TO 25
    70   PRINT "Processing log event item #"; I
    80 NEXT I
    90 COLOR 7, 0 : LOCATE 24, 1
    100 PRINT "Status: Ready";
