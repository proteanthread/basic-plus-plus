BASIC++ V6.5.2 LIBRARY SYSTEM AND MICRO-LIBRARY ARCHITECTURE

The architectural reference defining the accumulative 11-modular library
spectrum, micro-library compilation targets, and linkage points across
BASIC++ editions.


1. THE 11-MODULAR LIBRARY ARCHITECTURE

BASIC++ is compiled as a chain of 11 static micro-libraries linked
accumulatively (libboot through libadvanced, plus libinterop_core). Subsystems
are structured with unidirectional dependencies: any library in the chain
depends only on layers below it.

Executable targets link at specific layers in the spectrum:
- iot.exe  : Links up to libkernel (2 MB pool, micro-REPL).
- bs.exe   : Links up to libscript (64 MB pool, batch runner with file I/O).
- bpp.exe  : Links up to libcore (384 MB pool, headless terminal REPL).
- baspp.exe: Links up to libadvanced (640 MB pool, SDL2 graphics).


2. LIBRARY CHAIN SPECIFICATIONS

Layer 1: libboot (Bootstrap Controller)
- Source: engine/src/bootstrap/boot.c, common/common.c.
- Role: Coordinates the 9-phase initialization sequence (boot_engine()).
- Dependencies: None (Freestanding C17).

Layer 2: libplatform (Operating System Abstraction)
- Source: engine/src/platform/plat_console.c, plat_fs.c, plat_sys.c,
  plat_time.c, plat_thread.c, plat_dl.c, plat_net.c, plat_regex.c.
- Role: Encapsulates all Win32, POSIX, and bare-metal OS APIs.
- Rule: Zero OS-specific headers may appear above this layer.

Layer 3: libkernel (Virtual Machine Core)
- Source: engine/src/vm/context.c, lexer/lexer.c, memory/memory.c,
  security/security.c, bios/bios_pc.c, device/vdev.c.
- Role: Lexer, memory arena, security sandbox, BIOS, and virtual device bus.

Layer 4: libengine (Evaluator and Parser)
- Source: engine/src/eval/eval.c, rpn.c, parser/parser.c, vm/exec.c,
  runtime/variables.c, strings.c.
- Role: AST evaluator, RPN expression engine, procedure dispatch, variables.

Layer 5: libhardware (Hardware Emulation)
- Source: engine/src/device/bgi/bgi_core.c, bgi_raster.c, device/fujinet.c.
- Role: Segmented memory (vmem), BGI software rasterizer, FujiNet bus.

Layer 6: libserver (Networking and Sockets)
- Source: engine/src/device/vnet.c, server/gemini.c, server/task.c.
- Role: TCP/UDP network sockets (VNet), Gemini/Gopher clients, tasks, crypto.

Layer 7: libscript (Filesystem and Batch Execution)
- Source: engine/src/bootstrap/server/server.c, statements/filesystem/.
- Role: File sector handling, random records, batch script processing.

Layer 8: libcore (REPL and Formatter)
- Source: engine/src/bootstrap/iot/iot.c, runtime/numfmt.c, metadata.c.
- Role: Terminal REPL engine, PRINT USING mask parser, metadata registry.

Layer 9: libflex (Dynamic Metaprogramming)
- Source: engine/src/scope/scope.c, module/module.c, statements/metaprog/.
- Role: ALIAS, OVERRIDE, SCOPE, and external module loader.

Layer 10: libstandard (TUI Workstation and Editor)
- Source: engine/src/editor/tui_multiplexer.c, editor_buffer.c, debug/dap.c.
- Role: Multi-window TUI editor multiplexer and DAP debug server.

Layer 11: libadvanced (Desktop Graphics and Multimedia)
- Source: engine/src/bootstrap/desktop/desktop.c, device/gfx.c.
- Role: SDL2/OpenGL windowing, 2D/3D graphics, audio streaming, joystick.
