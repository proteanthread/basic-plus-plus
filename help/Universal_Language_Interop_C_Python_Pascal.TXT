UNIVERSAL LANGUAGE INTEROP (SUPERSEDED)
==============================================================================

This document has been replaced by Language_Interop.

The title was misleading: it grouped C, Python and Pascal as three comparably
supported languages. They are not. C interop is real in both directions;
Pascal reaches BASIC++ through the C ABI and has no dedicated bridge; and
PYTHON$ returns the literal string "None" for every input.

Language_Interop states which is which, with the source evidence, and adds
assembler, COM, JSON-RPC, IPC and WASM.
