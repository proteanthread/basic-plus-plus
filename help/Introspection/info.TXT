INFO Statement Reference
======================================================================

The INFO statement displays real-time runtime diagnostics, memory
allocation statistics, virtual device metrics, security levels, and
engine version telemetry directly to the virtual console.


SYNTAX
----------------------------------------------------------------------

    INFO


DESCRIPTION
----------------------------------------------------------------------

INFO provides a comprehensive runtime dashboard for developers. It
interrogates the VMContext, MemoryContext, StringContext, and
VDevContext structures to output an instantaneous snapshot of system
resource consumption:
  1. Engine Version & Identity (v6.5.2 "Phoenix", Standard/Lite/Server).
  2. Active Dialect Mode (GW-BASIC, QBASIC, ECMA-116, Super BASIC).
  3. Memory Metrics (Program storage, variable space, string heap).
  4. Stack Depth (Active call frames vs maximum limit).
  5. Security & Sandbox Level (Level 0 OPEN to Level 5 RESTRICTED).
  6. Virtual Devices (Active registered devices and open channels).

Output Format:
    ==================================================================
    BASIC++ v6.5.2 Standard Edition (64-Bit) -- System Information
    ==================================================================
    Dialect:              GW-BASIC (GWBS)
    Memory Pool:          640.00 MB Total (671,088,640 bytes)
      - Program Storage:  128.00 MB
      - Variable Space:   128.00 MB
      - String Heap:      256.00 MB
    Call Stack:           0 / 1023 frames active
    Security Level:       0 (OPEN)
    Active Devices:       8 registered
    Open Channels:        0 / 16 active
    ==================================================================
    Ok


CODE EXAMPLES
----------------------------------------------------------------------

    INFO


ENGINE IMPLEMENTATION (system.c & vm/context.c)
----------------------------------------------------------------------

In engine/src/statements/system/system.c, stmt_info_handler gathers
metrics via engine accessor APIs:
  - mem_get_total_free(), mem_get_total_used()
  - str_get_total_allocated(), str_get_string_count()
  - var_get_count()
  - vdev_get_registered_count()

Dispatched via vdev_printf(vm_get_vdev(vm), ...).


ERROR CODES
----------------------------------------------------------------------

  Error Code  Name                  Condition
  ----------  --------------------  ----------------------------------
  2           ERR_SYNTAX_ERROR      Trailing arguments passed to INFO


CROSS-REFERENCES
----------------------------------------------------------------------

  - VER: Displays concise engine and program version numbers.
  - MEMMAP$: Queries active BIOS memory map model name.
  - HELP: Queries interactive documentation.
  - CATALOG: Lists language keyword categories.


PROPOSED EXPANSION OR CHANGES
----------------------------------------------------------------------

  1. INFO$ Function: Introduce INFO$("MEMORY") or INFO$("STACK") for
     programmatic telemetry queries in BASIC scripts.
  2. Benchmark Metrics: Include CPU cycle estimates in the dashboard.
