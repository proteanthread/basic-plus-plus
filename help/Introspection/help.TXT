HELP Statement Reference
======================================================================

The HELP statement provides interactive, on-demand documentation and
keyword syntax introspection directly within the BASIC++ environment.


SYNTAX
----------------------------------------------------------------------

    HELP
    HELP topic_or_keyword$
    HELP "category_name"


PARAMETERS
----------------------------------------------------------------------

  topic_or_keyword$ - (Optional) A string or unquoted identifier
                      specifying the keyword or function to look up.
  If called without arguments, HELP displays the master help index.


DESCRIPTION
----------------------------------------------------------------------

The HELP facility queries the built-in system metadata blocks and
static keyword documentation registries (help_data.h). It formats and
prints syntax definitions, parameter descriptions, usage notes, error
codes, and category classifications directly to the active VCon.

    > HELP PEEK
    ==================================================================
    KEYWORD:      PEEK
    CATEGORY:     Memory & Segment
    SYNTAX:       byte% = PEEK(address%)
    DESCRIPTION:  Reads a single byte (0-255) from the active segment.
    ERROR CODES:  Error 5: Illegal Function Call, Error 13: Mismatch
    ==================================================================
    Ok


CODE EXAMPLES
----------------------------------------------------------------------

Example 1: General Help Directory
    HELP

Example 2: Inspecting Specific Keyword Syntax
    HELP "CIRCLE"

Example 3: Filter by Category
    HELP "Variables & Memory"


ENGINE IMPLEMENTATION (help.c & help_data.h)
----------------------------------------------------------------------

In engine/src/statements/system/help.c:
  1. Searches g_help_entries[] in help_data.h via platform_strcasecmp.
  2. Queries dynamically registered micro-library metadata blocks.
  3. Emits formatted text using vdev_printf(vm_get_vdev(vm), ...) to
     ensure terminal/SDL consistency.


ERROR CODES
----------------------------------------------------------------------

  Error Code  Name                  Condition
  ----------  --------------------  ----------------------------------
  13          ERR_TYPE_MISMATCH     Argument evaluates to numeric type
