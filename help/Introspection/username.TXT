USERNAME Statement & Function Reference
======================================================================

The USERNAME statement and USERNAME$ built-in function provide access
to the operating system username of the current user account running
the interpreter.


SYNTAX
----------------------------------------------------------------------

Statement Syntax:
    USERNAME

Function Syntax:
    user$ = USERNAME$


RETURN VALUE (USERNAME$)
----------------------------------------------------------------------

  - Returns a string (VAL_STRING) containing the username.
  - Defaults safely to "user" if the username cannot be queried.


DESCRIPTION
----------------------------------------------------------------------

The USERNAME statement immediately prints the active username to the
virtual console (VCon).

The USERNAME$ function returns the username as an evaluated string
value for use in greeting messages or file path constructions.


CODE EXAMPLES
----------------------------------------------------------------------

Example 1: Console Statement Invocation
    > USERNAME
    rtdos
    Ok

Example 2: User-Specific Save File Path
    100 PrefFile$ = "C:/Users/" + USERNAME$ + "/mygame.cfg"
    110 PRINT "Saving user settings to: "; PrefFile$


ENGINE IMPLEMENTATION (system.c & eval_builtins.c)
----------------------------------------------------------------------

Statement: In engine/src/statements/system/system.c, queries the
platform username and emits it to VCon.

Function: In engine/src/eval/eval_builtins.c (lines 832-842):
    const char *env_val = getenv("USER");
    if (!env_val) env_val = getenv("USERNAME");
    if (!env_val) env_val = "user";
    res.as.string = str_create(vm_get_str(vm), env_val, strlen(env_val));
