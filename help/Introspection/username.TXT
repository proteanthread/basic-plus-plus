USERNAME

Syntax & Parameters
USERNAME

(No parameters required.)

Description & Usage
Print the current system username to the console. This command evaluates system state immediately and outputs the string directly to standard output. It does not return a string value that can be assigned to a variable (for that, use USERNAME$).

Code Examples
`basic
USERNAME
`

Internal C-Source Mapping
- Parser: piparseusername in source/help/parser_help.c (or equivalent location).
- Execution: Direct console output using gw_printf.

Implementation Details
The command invokes platform-specific APIs (gethostname, GetUserName, getcwd, etc.) to retrieve the required environment string, and immediately flushes the result to the attached output buffer. It bypasses the AST expression stack entirely, preventing side-effects on RuntimeState *rt.

Historical Context
These commands were introduced in BASIC++ to provide quick POSIX/DOS-like shell introspection without requiring PRINT USERNAME$().
