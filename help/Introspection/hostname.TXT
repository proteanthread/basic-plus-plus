HOSTNAME Statement & Function Reference
======================================================================

The HOSTNAME statement and HOSTNAME$ built-in function provide access
to the network hostname of the host machine.


SYNTAX
----------------------------------------------------------------------

Statement Syntax:
    HOSTNAME

Function Syntax:
    host$ = HOSTNAME$


RETURN VALUE (HOSTNAME$)
----------------------------------------------------------------------

  - Returns a string (VAL_STRING) containing the network hostname.
  - Defaults safely to "localhost" if the hostname cannot be queried.


DESCRIPTION
----------------------------------------------------------------------

The HOSTNAME statement immediately prints the host system's network
hostname to the active virtual console (VCon).

The HOSTNAME$ function returns the hostname as an evaluated string
value for assignment to variables or network telemetry packets.


CODE EXAMPLES
----------------------------------------------------------------------

Example 1: Console Statement Invocation
    > HOSTNAME
    workstation-win11
    Ok

Example 2: Telemetry Packet Formatting
    100 NodeID$ = HOSTNAME$
    110 Timestamp$ = TIME$
    120 Packet$ = "NODE=" + NodeID$ + ";TIME=" + Timestamp$
    130 PRINT Packet$


ENGINE IMPLEMENTATION (system.c & eval_builtins.c)
----------------------------------------------------------------------

Statement: In engine/src/statements/system/system.c, queries the
platform hostname and emits it to VCon.

Function: In engine/src/eval/eval_builtins.c (lines 822-831):
    const char *env_val = getenv("HOSTNAME");
    if (!env_val) env_val = getenv("COMPUTERNAME");
    if (!env_val) env_val = "localhost";
    res.as.string = str_create(vm_get_str(vm), env_val, strlen(env_val));
