MEMMAP$ Function Reference
======================================================================

The MEMMAP$ built-in string function returns the identifier name of
the currently active virtual BIOS hardware memory map architecture.


SYNTAX
----------------------------------------------------------------------

    model$ = MEMMAP$


RETURN VALUE
----------------------------------------------------------------------

  - Returns a string (VAL_STRING) representing the active profile:
    "IBM_PC"   - Standard 1981 IBM PC 5150 (CGA / MDA)
    "IBM_XT"   - IBM PC/XT 5160 (Fixed disk BDA, 640KB RAM)
    "IBM_AT"   - IBM PC/AT 5170 (286 real mode, EGA/VGA)
    "IBM_PCJR" - IBM PCjr (16-color graphics, 3-voice audio)
    "(None)"   - If virtual BIOS is disabled (SUPPORT_BIOS=0).


DESCRIPTION
----------------------------------------------------------------------

In BASIC++ v6.5.2, the virtual BIOS layer (libbios) virtualizes
authentic IBM PC x86 memory layouts (IVT 0x0000, BDA 0x0400, Video RAM
0xA000 / 0xB800, ROM BIOS 0xF000).

MEMMAP$ allows programs to inspect the active architecture dynamically
before making model-specific memory accesses or BIOS calls:

    10 ModelName$ = MEMMAP$
    20 PRINT "Active Architecture: "; ModelName$
    30 IF ModelName$ = "IBM_PCJR" THEN PRINT "PCjr Audio Available!"


CODE EXAMPLES
----------------------------------------------------------------------

    100 SELECT CASE MEMMAP$
    110     CASE "IBM_PCJR" : CALL INIT_PCJR_AUDIO
    120     CASE "IBM_AT"   : CALL INIT_VGA_256_COLOR
    130     CASE ELSE       : CALL INIT_STANDARD_CGA
    140 END SELECT


ENGINE IMPLEMENTATION (eval_builtins.c & bios.c)
----------------------------------------------------------------------

In engine/src/eval/eval_builtins.c:
  Queries bios_get_model(vm_get_bios(vm)) and maps the enum to
  string constants ("IBM_PC", "IBM_XT", "IBM_AT", "IBM_PCJR").


ERROR CODES
----------------------------------------------------------------------

  Error Code  Name                  Condition
  ----------  --------------------  ----------------------------------
  13          ERR_TYPE_MISMATCH     Arguments passed to MEMMAP$

PROPOSED EXPANSION OR CHANGES
----------------------------------------------------------------------

  1. Custom Architecture Registry: Allow custom models (TANDY_1000)
     to register custom memory map descriptors.
  2. MEMMAP(segment%): Retrieve the base address of a segment.
