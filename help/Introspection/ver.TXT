VER Statement Reference
======================================================================

The VER statement displays the current BASIC++ engine build version,
target architecture, and the active program version tag (set via
VERSION) to the virtual console.


SYNTAX
----------------------------------------------------------------------

    VER


DESCRIPTION
----------------------------------------------------------------------

The VER statement outputs version telemetry for the running
environment. It displays both:
  1. Host Engine Version: The compiled version of the BASIC++
     interpreter (BASIC++ v6.5.2 (64-Bit)).
  2. Program Version Tag: The application version string embedded via
     the VERSION "x.y.z" statement. (Displays (None) if unset).

Output Format:
    ==================================================================
    BASIC++ Engine Version:  6.5.2 (Modern / 64-Bit)
    Program Version Tag:   1.4.0-Release
    ==================================================================
    Ok


CODE EXAMPLES
----------------------------------------------------------------------

Example 1: Tagging a Program and Querying Version
    10 VERSION "2.1.0-Production"
    20 PRINT "Running Application..."
    30 VER

Example 2: Interactive Query
    > VER
    BASIC++ Engine Version:  6.5.2 (Modern / 64-Bit)
    Program Version Tag:   (None)


ENGINE IMPLEMENTATION (version.c)
----------------------------------------------------------------------

In engine/src/statements/system/version.c:
  1. Retrieves program tag via mem_get_program_version().
  2. Dispatches formatted output via vdev_printf().


ERROR CODES
----------------------------------------------------------------------

  Error Code  Name                  Condition
  ----------  --------------------  ----------------------------------
  2           ERR_SYNTAX_ERROR      Trailing arguments passed to VER


CROSS-REFERENCES
----------------------------------------------------------------------

  - VERSION: Tags the active program with a version string.
  - INFO: Displays complete system metrics and memory telemetry.
  - HELP: Interactive keyword documentation.


PROPOSED EXPANSION OR CHANGES
----------------------------------------------------------------------

  1. VER$ Builtin Function: Expose ver$ = VER$ returning the version
     string for automated logging.
  2. Build Hash Verification: Output git commit hash with VER FULL.
