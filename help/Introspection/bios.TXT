BIOS Introspection & Hardware State Reference
======================================================================

The BIOS introspection facilities in BASIC++ v6.5.2 (libkernel /
libhardware) provide runtime visibility into virtualized real-mode
x86 BIOS registers, memory map layouts, interrupt vector tables, and
retro hardware profiles.


INTROSPECTIVE FUNCTIONS & FEATURES
======================================================================

1. Active Architecture Query (MEMMAP$):
    Returns "IBM_PC", "IBM_XT", "IBM_AT", "IBM_PCJR", or "(None)".

2. Register State Inspection:
    BIOS interrupts execute against standard BASIC integer variables:
      - AX% : Accumulator (AH% = AX% \ 256, AL% = AX% AND 255)
      - BX% : Base register
      - CX% : Count register
      - DX% : Data register
      - FLAGS% : Status flags (Carry flag bit 0 indicates error)

    100 REM Query Video Mode via INT 10h, AH=0Fh
    110 AX% = &H0F00
    120 BIOS &H10
    130 CurrentMode% = AX% AND 255
    140 TextColumns% = (AX% \ 256) AND 255
    150 PRINT "Video Mode: "; CurrentMode%; " Columns: "; TextColumns%

3. BIOS Data Area (BDA) Memory Map Introspection:
    Segment &H0040 contains standard PC hardware status words:
      - PEEK(&H0010) : Equipment list word
      - PEEK(&H0013) : Base memory size in KB
      - PEEK(&H0017) : Keyboard shift flags (Caps/Num Lock)

    10 DEF SEG = &H0040
    20 ShiftFlags% = PEEK(&H0017)
    30 IF (ShiftFlags% AND 64) THEN PRINT "Caps Lock is ON"


ERROR CODES
----------------------------------------------------------------------

  Error Code  Name                  Condition
  ----------  --------------------  ----------------------------------
  5           ERR_ILLEGAL_FUNCTION  Invalid interrupt number
  57          ERR_DEVICE_IO_ERROR   BIOS subsystem not initialized
  70          ERR_PERMISSION_DENIED Sandbox restricts BIOS execution
