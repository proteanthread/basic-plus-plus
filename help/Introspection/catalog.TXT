CATALOG Statement Reference
======================================================================

The CATALOG statement lists the master inventory of all built-in
keywords, statements, and mathematical/string functions in BASIC++
v6.5.2, organized by functional category.


SYNTAX
----------------------------------------------------------------------

    CATALOG
    CATALOG "category_name"


PARAMETERS
----------------------------------------------------------------------

  "category_name" - (Optional) A string expression filtering the
                    catalogue output to a specific functional category.
  If invoked without arguments, CATALOG prints all categories.


STANDARD CATEGORIES
----------------------------------------------------------------------

  1. Control Flow: Branching, loops, events (IF, FOR, DO, ON ERROR).
  2. Variables & Memory: Allocations, segments (DIM, DEF SEG, PEEK).
  3. Strings: Substring analysis, formatting (LEFT$, MID$, OCT$, HEX$).
  4. Math: Arithmetic, trigonometry, matrices (SIN, COS, LOG, MAT).
  5. Input / Output: Console, printer, serial (PRINT, LOCATE, LPOS).
  6. Graphics & Sound: BGI graphics, audio (SCREEN, PSET, PLAY).
  7. Filesystem: File handles, directories (OPEN, CLOSE, GET, PUT).
  8. Devices & Network: Sockets, virtual devices (VDEV, MOUNT, NET).
  9. Debug & Testing: Tracing, breakpoints (TRON, TROFF, DEBUG).
  10. System & Environ: Timers, environment (TIME$, DATE$, JIFFIES).


CODE EXAMPLES
----------------------------------------------------------------------

Example 1: Full System Catalogue
    CATALOG

Example 2: Filtering by Category
    CATALOG "Graphics & Sound"


ENGINE IMPLEMENTATION (help.c)
----------------------------------------------------------------------

In engine/src/statements/system/help.c, stmt_catalog_handler parses
optional category filters and iterates through g_help_entries in
help_data.h, displaying items formatted to VCon.


ERROR CODES
----------------------------------------------------------------------

  Error Code  Name                  Condition
  ----------  --------------------  ----------------------------------
  13          ERR_TYPE_MISMATCH     Argument is a numeric type


CROSS-REFERENCES

PROPOSED EXPANSION OR CHANGES
----------------------------------------------------------------------

  1. JSON Catalogue Export: Support CATALOG --json or CATALOG$().
  2. Columnar Screen Formatting: Dynamically format columns based on
