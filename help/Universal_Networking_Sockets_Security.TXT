UNIVERSAL PEER-TO-PEER, BSD SOCKETS, EVENT TRAPPING & WIRELESS IOT SUBSYSTEM

BASIC++ provides a comprehensive, low-latency, event-driven networking stack
designed for modern microcontrollers (ESP32, RP2040, ARM Cortex-M), desktop
operating systems (Windows, Linux, macOS), and embedded gateways.


1. ARCHITECTURAL PRINCIPLES

1. Vendor-Agnostic P2P Architecture (PEER.*): Replaces vendor-locked
   protocols (such as raw ESP-NOW) with a universal framing protocol
   operating across 802.11 action frames, Unix domain datagrams, or UDP.
2. Standard BSD Sockets Layer (SOCK.*): Provides non-blocking stream (TCP)
   and datagram (UDP) socket handles with POLL%, BIND, LISTEN, ACCEPT%,
   SEND, and RECV$.
3. Event-Driven Trapping: Asynchronous event triggers for incoming packets
   (ON NET, ON PEER, ON SNIFF) and port knocking (ON PORT(p)).
4. Packet Sniffing: Zero-copy packet filter enabling Wi-Fi management frame
   analysis, raw Ethernet monitoring, and RSSI inspection.
5. Physical Wireless Radios: Integrated statements for Wi-Fi SoftAP mode,
   Bluetooth Classic SPP, Bluetooth Low Energy (BLE), and NFC/RFID.


2. UNIVERSAL PEER-TO-PEER SUBSYSTEM (PEER.*)

Statement / Command  Syntax                    Description
-------------------  ------------------------  -------------------------------
PEER.INIT            PEER.INIT [channel%]      Initializes peer subsystem
PEER.ADD             PEER.ADD peer_id$ [, ch]  Registers destination MAC/node
PEER.SEND            PEER.SEND peer_id$, data$ Transmits payload to peer
PEER.RECV            PEER.RECV var$            Retrieves received frame
PEER ON/OFF/STOP     PEER ON / OFF / STOP      Enables/disables interrupts

Example:

    10 PEER.INIT 1
    20 PEER.ADD "FF:FF:FF:FF:FF:FF"    ' Register broadcast MAC address
    30 PEER.SEND "FF:FF:FF:FF:FF:FF", "PING_BEACON"
    40 PEER ON                         ' Enable event interrupts


3. LOW-LEVEL BSD SOCKET SUBSYSTEM (SOCK.*)

Function / Stmt  Syntax                   Type       Description
---------------  -----------------------  ---------  -------------------------
SOCK.OPEN%       SOCK.OPEN%(proto$)       INTEGER    Allocates socket handle
SOCK.BIND        SOCK.BIND h%, port%      Statement  Binds handle to port
SOCK.LISTEN      SOCK.LISTEN h%, backlog  Statement  Enters listening mode
SOCK.ACCEPT%     SOCK.ACCEPT%(listen_h%)  INTEGER    Accepts connection
SOCK.SEND        SOCK.SEND h%, data$      Statement  Transmits payload data
SOCK.RECV$       SOCK.RECV$(h%, max%)     STRING     Reads incoming bytes
SOCK.CLOSE       SOCK.CLOSE h%            Statement  Closes socket descriptor


4. PHYSICAL WIRELESS & IOT RADIOS

Wi-Fi SoftAP & Scanning:
- WIFI.AP ssid$, password$ [, channel [, max_conn]]: Configures SoftAP.
- WIFI.SCAN: Scans surrounding BSSIDs and prints detected SSIDs and RSSI.
- WIFI.SNIFF ON [, channel]: Enables raw 802.11 packet sniffer.
- WIFI.SNIFF OFF: Disables packet sniffing.

Bluetooth Classic & BLE Beacons:
- BT.START name$: Initializes Bluetooth Classic Serial Port Profile.
- BT.CONNECT mac$: Connects to remote Bluetooth device.
- BLE.ADV.START name$, uuid$: Advertises a BLE GATT service beacon.
- BLE.ADV.STOP: Stops BLE beacon advertising.

NFC & RFID Peripheral Subsystem:
- NFC.INIT [i2c_addr]: Initializes external NFC/RFID reader.
- NFC.SCAN card_uid$: Scans for passive ISO14443A cards and gets UID.
- NFC.READ block_num, var$: Reads 16-byte memory block from card.
- NFC.WRITE block_num, data$: Writes data to card memory block.
