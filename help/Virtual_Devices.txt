VIRTUAL DEVICES IN BASIC++
==========================
Version 0.21.0

The Virtual Device (VDev) system is BASIC++'s hardware
abstraction layer.  All I/O flows through VDevs, enabling
custom devices, output redirection, and device emulation.

This guide covers the architecture, every built-in device
in detail, and provides complete tutorials for building
your own devices to access the file system, serial ports,
network sockets, printers, clipboard, audio, pipes, and
any other modern hardware.

=====================================================================
1. ARCHITECTURE
=====================================================================

Every I/O operation in BASIC++ goes through a VDev.  The
interpreter core NEVER calls printf, fgets, fopen, or any
C stdio function directly.  All I/O is routed through
function pointers inside VDev structures:

  +-------------------+      +-------------------+
  |   BASIC Program   |      |   BASIC Program   |
  |   PRINT "Hello"   |      |   INPUT A$        |
  +--------+----------+      +--------+----------+
           |                           |
           v                           v
  +--------+----------+      +--------+----------+
  |   VM Dispatcher    |      |   VM Dispatcher    |
  |   OP_PRINT handler |      |   OP_INPUT handler |
  +--------+----------+      +--------+----------+
           |                           |
           v                           v
  +--------+--------------------------+----------+
  |            VDev Convenience Layer            |
  |   vdev_puts(CON, "Hello\n")                  |
  |   vdev_gets(CON, buf, 255)                   |
  +--------+--------------------------+----------+
           |                           |
           v                           v
  +--------+----------+      +--------+----------+
  |   CON: Device      |      |   CON: Device      |
  |   dev_puts(d, s)   |      |   dev_gets(d,b,n)  |
  +--------+----------+      +--------+----------+
           |                           |
           v                           v
  +--------+--------------------------+----------+
  |           Host Operating System              |
  |   fputs(stdout) / WriteConsole()             |
  |   fgets(stdin)  / ReadConsole()              |
  +--------------------------------------------- +

Key design principle: because every byte flows through
function pointers, you can intercept, redirect, log,
transform, or replace ANY I/O operation by simply
swapping the function pointer.  The BASIC program
never knows the difference.


=====================================================================
2. BUILT-IN DEVICES
=====================================================================


---------------------------------------------------------------------
2.1  CON: (Console Device) - Slot 0
---------------------------------------------------------------------

  Purpose: Primary user-facing I/O.
  Read:    stdin (keyboard)
  Write:   stdout (screen)

  All PRINT output, all INPUT prompts, INKEY$, CLS,
  LOCATE, COLOR — everything the user sees and types
  goes through CON:.

  Function pointers installed at boot:

    dev_putc  = con_putc     putchar(ch)
    dev_puts  = con_puts     fputs(s, stdout)
    dev_flush = con_flush    fflush(stdout)
    dev_cls   = con_cls      system("cls") or ESC[2J
    dev_getc  = con_getc     getchar()
    dev_gets  = con_gets     fgets(buf, max, stdin)
    dev_open  = NULL         (not applicable)
    dev_close = NULL         (not applicable)
    user_data = NULL

  CLS implementation is platform-aware:
    Windows/DOS: system("cls")
    Linux/POSIX: printf("\033[2J\033[H")

  The CON: device is the ONLY device that handles both
  input and output simultaneously.


---------------------------------------------------------------------
2.2  ERR: (Error Device) - Slot 1
---------------------------------------------------------------------

  Purpose: Diagnostic and error output.
  Read:    Not supported (returns EOF)
  Write:   stderr

  Error messages, LPRINT output, and diagnostics go here.
  Because stderr is separate from stdout, error messages
  don't corrupt program output when piping:

    basicpp myprog.bas > output.txt 2> errors.txt

  Function pointers:

    dev_putc  = err_putc     fputc(ch, stderr)
    dev_puts  = err_puts     fputs(s, stderr)
    dev_flush = err_flush    fflush(stderr)
    dev_cls   = NULL         (not applicable)
    dev_getc  = NULL         (returns -1)
    dev_gets  = NULL         (returns -1)
    dev_open  = NULL
    dev_close = NULL
    user_data = NULL


---------------------------------------------------------------------
2.3  FILE: (File I/O Device) - Slot 2
---------------------------------------------------------------------

  Purpose: File system access for BASIC programs.
  Manages 8 file channels (#1 through #8).

  The FILE: device uses the user_data field to store a
  FILE* pointer.  It supports open, close, read, write,
  and flush operations.

  Function pointers:

    dev_putc  = file_putc    fputc(ch, FILE*)
    dev_puts  = file_puts    fputs(s, FILE*)
    dev_flush = file_flush   fflush(FILE*)
    dev_cls   = NULL
    dev_getc  = file_getc    fgetc(FILE*)
    dev_gets  = file_gets    fgets(buf, max, FILE*)
    dev_open  = file_open    fopen(path, mode)
    dev_close = file_close   fclose(FILE*)
    user_data = FILE*        (current open file pointer)

  Note: The FILE: device in slot 2 is used for SAVE/LOAD
  operations (one file at a time).  BASIC file channels
  (#1-#8) have their own internal FileChannel table managed
  by fileio.c — they do NOT use separate VDev slots.


=====================================================================
3. THE VDEV INTERFACE
=====================================================================


---------------------------------------------------------------------
3.1  The VDev Structure
---------------------------------------------------------------------

  Every device is described by a single C structure:

    struct VDev {
        const char *name;                          /* "CON:" */

        /* Output operations */
        int  (*dev_putc)(VDev *d, int ch);         /* write char */
        int  (*dev_puts)(VDev *d, const char *s);  /* write string */
        int  (*dev_flush)(VDev *d);                /* flush buffers */
        int  (*dev_cls)(VDev *d);                  /* clear/reset */

        /* Input operations */
        int  (*dev_getc)(VDev *d);                 /* read char */
        int  (*dev_gets)(VDev *d, char *buf, int max); /* read line */

        /* File operations */
        int  (*dev_open)(VDev *d, const char *path,
                         const char *mode);        /* open resource */
        int  (*dev_close)(VDev *d);                /* close */

        /* State */
        void *user_data;                           /* opaque state */
    };

  KEY RULES:
    - Set unused function pointers to NULL.
    - The convenience functions (vdev_putc, vdev_puts, etc.)
      safely handle NULL function pointers by returning -1.
    - The 'self' pointer (d) is always passed as the first
      argument, allowing the device to access its own
      user_data and state.
    - user_data is yours — cast it to whatever you need
      (FILE*, socket handle, buffer pointer, struct, etc.)


---------------------------------------------------------------------
3.2  Function Pointer Signatures
---------------------------------------------------------------------

  All function pointers follow consistent conventions:

  Return values:
    0   = success
    -1  = error / unsupported / EOF
    ch  = the character (for putc, on success)

  int dev_putc(VDev *d, int ch)
    Write one character to the device.
    Returns 0 on success, -1 on error.
    The character is an unsigned byte (0-255).

  int dev_puts(VDev *d, const char *s)
    Write a null-terminated string to the device.
    Returns 0 on success, -1 on error.
    Does NOT automatically append a newline.

  int dev_flush(VDev *d)
    Flush any internal buffers to the underlying medium.
    Returns 0 on success, -1 on error.
    May be called frequently — keep it fast.

  int dev_cls(VDev *d)
    Clear the device / reset to initial state.
    For screens: clear display, move cursor to 1,1.
    For buffers: discard contents.
    Returns 0 on success, -1 if not applicable.

  int dev_getc(VDev *d)
    Read one character from the device.
    Blocking — waits until a character is available.
    Returns the character (0-255), or -1 on EOF/error.

  int dev_gets(VDev *d, char *buf, int max)
    Read a line of text into buf (max-1 chars + null).
    Blocking — waits for a complete line (terminated by
    newline or EOF).
    Returns 0 on success, -1 on EOF/error.

  int dev_open(VDev *d, const char *path, const char *mode)
    Open a resource.  'path' and 'mode' are device-dependent.
    For files: path = filename, mode = "r"/"w"/"a"/"rb"/etc.
    For serial: path = "COM3" or "/dev/ttyS0", mode = "9600,8,N,1"
    For network: path = "host:port", mode = "tcp"/"udp"
    Returns 0 on success, -1 on error.

  int dev_close(VDev *d)
    Close the device / release resources.
    Returns 0 on success, -1 on error.
    After close, user_data should be set to NULL.


---------------------------------------------------------------------
3.3  Convenience Functions
---------------------------------------------------------------------

  Never call dev_putc() directly through the function pointer.
  Instead, use the convenience wrappers in vdev.c — they
  handle NULL devices and NULL function pointers safely:

  int vdev_putc(VDev *d, int ch)
    Safe wrapper: returns -1 if d is NULL or dev_putc is NULL.

  int vdev_puts(VDev *d, const char *s)
    Safe wrapper for string output.

  int vdev_printf(VDev *d, const char *fmt, ...)
    Formatted output.  Internally calls vsprintf into a 1024-byte
    buffer, then routes through dev_puts.  Maximum 1023 chars per
    call.

  int vdev_getc(VDev *d)
    Safe wrapper for character input.

  int vdev_gets(VDev *d, char *buf, int max)
    Safe wrapper for line input.

  int vdev_flush(VDev *d)
    Safe wrapper for flush.

  int vdev_cls(VDev *d)
    Safe wrapper for clear/reset.

  USAGE:
    VDev *con = vdev_get(VDEV_CON);
    vdev_puts(con, "Hello, World!\n");
    vdev_printf(con, "Value = %d\n", 42);


---------------------------------------------------------------------
3.4  Platform-Specific Functions
---------------------------------------------------------------------

  These standalone functions don't go through a VDev —
  they are direct platform calls used by specific BASIC
  statements:

  void vdev_beep(void)
    Emit an audible beep.
    Windows: Beep(800, 200) via kernel32.
    Linux/DOS: putchar('\a') (ASCII BEL).
    Used by: BEEP statement, error notification.

  void vdev_sound(int freq_hz, int duration_ms)
    Play a tone at a specific frequency and duration.
    Windows: Beep(freq, ms) via kernel32.
    Linux/DOS: putchar('\a') (best-effort fallback).
    freq_hz: 37-32767 Hz.
    duration_ms: 1-30000 milliseconds.
    Used by: SOUND statement.

  void vdev_sleep(int duration_ms)
    Pause execution for the given number of milliseconds.
    Windows: Sleep(ms) via kernel32.
    Linux: (no-op in current C89 implementation).
    Used by: SOUND 0,n (silence/pause) and PLAY rests.

  int vdev_inkey(void)
    Non-blocking keyboard read.
    Windows: _kbhit() + _getch() from <conio.h>.
    Linux: returns 0 (stub — requires termios extension).
    Returns the character code, or 0 if no key is pressed.
    Used by: INKEY$ function.


=====================================================================
4. DEVICE SLOTS AND REGISTRATION
=====================================================================

BASIC++ maintains a static table of 16 device slots:

  Slot   ID           Name    Status
  ----   --------     ----    ------
  0      VDEV_CON     CON:    Built-in (always present)
  1      VDEV_ERR     ERR:    Built-in (always present)
  2      VDEV_FILE    FILE:   Built-in (always present)
  3      VDEV_USER+0  (user)  Available
  4      VDEV_USER+1  (user)  Available
  5      VDEV_USER+2  (user)  Available
  ...    ...          ...     ...
  15     VDEV_USER+12 (user)  Available

  13 user slots are available for custom devices.

Registration:

  int slot = vdev_register(&my_device);

  vdev_register() copies the VDev structure into the next
  available slot and returns the slot number.  Returns -1
  if all 13 user slots are full.

  After registration, access the device by slot:

  VDev *dev = vdev_get(slot);
  vdev_puts(dev, "Hello from my device!\n");

  You can also access by the known slot number:

  VDev *dev = vdev_get(VDEV_USER);   /* slot 3 */

Slot lifetime:
  - Slots are allocated at registration and never freed.
  - There is no vdev_unregister() function.
  - To "disable" a device, set all its function pointers
    to NULL (the convenience functions will return -1).
  - The device table is cleared on vdev_init() (boot only).

5. CREATING A CUSTOM DEVICE (STEP-BY-STEP)
=====================================================================


---------------------------------------------------------------------
5.1  Tutorial 1: Logging Device
---------------------------------------------------------------------

  A logging device that writes all output to a file while
  passing it through to the console.  Useful for capturing
  a transcript of a BASIC++ session.

  COMPLETE C CODE:

    /* vdev_log.c - Logging VDev for BASIC++ */
    #include <stdio.h>
    #include <string.h>
    #include "vdev.h"

    static FILE *log_fp = NULL;

    /* Open the log file on first use */
    static void log_ensure_open(void)
    {
        if (log_fp == NULL) {
            log_fp = fopen("basicpp.log", "a");
        }
    }

    static int log_putc(VDev *d, int ch)
    {
        VDev *con;
        (void)d;
        log_ensure_open();
        if (log_fp) {
            fputc(ch, log_fp);
            fflush(log_fp);
        }
        /* Pass through to real console */
        con = vdev_get(VDEV_CON);
        return (con && con->dev_putc) ? con->dev_putc(con, ch) : -1;
    }

    static int log_puts(VDev *d, const char *s)
    {
        VDev *con;
        (void)d;
        log_ensure_open();
        if (log_fp) {
            fputs(s, log_fp);
            fflush(log_fp);
        }
        /* Pass through to real console */
        con = vdev_get(VDEV_CON);
        return (con && con->dev_puts) ? con->dev_puts(con, s) : -1;
    }

    static int log_flush(VDev *d)
    {
        (void)d;
        if (log_fp) fflush(log_fp);
        return vdev_flush(vdev_get(VDEV_CON));
    }

    static int log_close(VDev *d)
    {
        (void)d;
        if (log_fp) { fclose(log_fp); log_fp = NULL; }
        return 0;
    }

    void vdev_log_register(void)
    {
        VDev dev;
        memset(&dev, 0, sizeof(dev));
        dev.name      = "LOG:";
        dev.dev_putc  = log_putc;
        dev.dev_puts  = log_puts;
        dev.dev_flush = log_flush;
        dev.dev_close = log_close;
        vdev_register(&dev);
    }

  USAGE IN MAIN.C:

    extern void vdev_log_register(void);
    /* After vdev_init() */
    vdev_log_register();

  Now all output through the LOG: device goes to both
  the screen and basicpp.log.

  TO LOG ALL OUTPUT (replace CON:):

    Instead of registering as a separate device, you can
    replace CON:'s function pointers directly:

    VDev *con = vdev_get(VDEV_CON);
    /* Save originals */
    static int (*orig_putc)(VDev*, int);
    static int (*orig_puts)(VDev*, const char*);
    orig_putc = con->dev_putc;
    orig_puts = con->dev_puts;
    /* Install interceptors */
    con->dev_putc = log_putc;
    con->dev_puts = log_puts;

5.2  Tutorial 2: Null Device (Discard All Output)
---------------------------------------------------------------------

  A null device that silently discards all output and
  returns EOF on all input.  Useful for benchmarking,
  suppressing output, or unit testing.

    static int null_putc(VDev *d, int ch)
    {
        (void)d; (void)ch;
        return 0;  /* success, but discarded */
    }

    static int null_puts(VDev *d, const char *s)
    {
        (void)d; (void)s;
        return 0;  /* success, but discarded */
    }

    static int null_getc(VDev *d)
    {
        (void)d;
        return -1;  /* always EOF */
    }

    static int null_gets(VDev *d, char *buf, int max)
    {
        (void)d; (void)buf; (void)max;
        return -1;  /* always EOF */
    }

    void vdev_null_register(void)
    {
        VDev dev;
        memset(&dev, 0, sizeof(dev));
        dev.name     = "NUL:";
        dev.dev_putc = null_putc;
        dev.dev_puts = null_puts;
        dev.dev_getc = null_getc;
        dev.dev_gets = null_gets;
        vdev_register(&dev);
    }


---------------------------------------------------------------------
5.3  Tutorial 3: Tee Device (Mirror Output to Two Targets)
---------------------------------------------------------------------

  A tee device sends output to TWO devices simultaneously.
  Uses user_data to store the second device's slot ID.

    typedef struct {
        int primary_slot;    /* first target device slot */
        int secondary_slot;  /* second target device slot */
    } TeeState;

    static TeeState tee_state = { VDEV_CON, -1 };

    static int tee_putc(VDev *d, int ch)
    {
        TeeState *ts = (TeeState *)d->user_data;
        VDev *a = vdev_get(ts->primary_slot);
        VDev *b = vdev_get(ts->secondary_slot);
        if (a && a->dev_putc) a->dev_putc(a, ch);
        if (b && b->dev_putc) b->dev_putc(b, ch);
        return 0;
    }

    static int tee_puts(VDev *d, const char *s)
    {
        TeeState *ts = (TeeState *)d->user_data;
        VDev *a = vdev_get(ts->primary_slot);
        VDev *b = vdev_get(ts->secondary_slot);
        if (a && a->dev_puts) a->dev_puts(a, s);
        if (b && b->dev_puts) b->dev_puts(b, s);
        return 0;
    }

    /* Register: output to CON and ERR simultaneously */
    void vdev_tee_register(void)
    {
        VDev dev;
        tee_state.primary_slot   = VDEV_CON;
        tee_state.secondary_slot = VDEV_ERR;
        memset(&dev, 0, sizeof(dev));
        dev.name      = "TEE:";
        dev.dev_putc  = tee_putc;
        dev.dev_puts  = tee_puts;
        dev.user_data = &tee_state;
        vdev_register(&dev);
    }


---------------------------------------------------------------------
5.4  Tutorial 4: Memory Buffer Device
---------------------------------------------------------------------

  A device that writes output into an in-memory buffer.
  Useful for building strings from output, or for test
  harnesses that need to capture and inspect output.

    #define MEMBUF_SIZE 16384

    typedef struct {
        char  buf[MEMBUF_SIZE];
        int   pos;    /* current write position */
        int   rpos;   /* current read position */
    } MemBufState;

    static MemBufState membuf = { {0}, 0, 0 };

    static int membuf_putc(VDev *d, int ch)
    {
        MemBufState *s = (MemBufState *)d->user_data;
        if (s->pos < MEMBUF_SIZE - 1) {
            s->buf[s->pos++] = (char)ch;
            s->buf[s->pos]   = '\0';
        }
        return 0;
    }

    static int membuf_puts(VDev *d, const char *str)
    {
        MemBufState *s = (MemBufState *)d->user_data;
        while (*str && s->pos < MEMBUF_SIZE - 1) {
            s->buf[s->pos++] = *str++;
        }
        s->buf[s->pos] = '\0';
        return 0;
    }

    static int membuf_cls(VDev *d)
    {
        MemBufState *s = (MemBufState *)d->user_data;
        s->pos  = 0;
        s->rpos = 0;
        s->buf[0] = '\0';
        return 0;
    }

    static int membuf_getc(VDev *d)
    {
        MemBufState *s = (MemBufState *)d->user_data;
        if (s->rpos >= s->pos) return -1;
        return (unsigned char)s->buf[s->rpos++];
    }

    void vdev_membuf_register(void)
    {
        VDev dev;
        memset(&dev, 0, sizeof(dev));
        dev.name      = "MEM:";
        dev.dev_putc  = membuf_putc;
        dev.dev_puts  = membuf_puts;
        dev.dev_cls   = membuf_cls;
        dev.dev_getc  = membuf_getc;
        dev.user_data = &membuf;
        vdev_register(&dev);
    }

    /* Utility: access captured output from C code */
    const char *vdev_membuf_contents(void) { return membuf.buf; }
    int         vdev_membuf_length(void)   { return membuf.pos;  }
    void        vdev_membuf_clear(void)    { membuf.pos = 0; membuf.rpos = 0; membuf.buf[0] = '\0'; }


---------------------------------------------------------------------
5.5  Tutorial 5: Input Playback Device
---------------------------------------------------------------------

  A device that plays back pre-recorded input, as if the
  user were typing.  Perfect for automated testing.

    #define MAX_SCRIPT_LINES 256

    typedef struct {
        const char *lines[MAX_SCRIPT_LINES];
        int         count;
        int         current;
    } ScriptState;

    static ScriptState script = { {NULL}, 0, 0 };

    static int script_gets(VDev *d, char *buf, int max)
    {
        ScriptState *s = (ScriptState *)d->user_data;
        int len, i;
        if (s->current >= s->count) return -1;  /* EOF */
        len = (int)strlen(s->lines[s->current]);
        if (len >= max) len = max - 1;
        for (i = 0; i < len; i++) buf[i] = s->lines[s->current][i];
        buf[len] = '\0';
        s->current++;
        return 0;
    }

    static int script_getc(VDev *d)
    {
        static int line_pos = 0;
        ScriptState *s = (ScriptState *)d->user_data;
        if (s->current >= s->count) return -1;
        if (s->lines[s->current][line_pos] == '\0') {
            line_pos = 0;
            s->current++;
            return '\n';
        }
        return (unsigned char)s->lines[s->current][line_pos++];
    }

    /* Load script: call before running the BASIC program */
    void vdev_script_load(const char **lines, int count)
    {
        int i;
        script.count = (count > MAX_SCRIPT_LINES)
                       ? MAX_SCRIPT_LINES : count;
        script.current = 0;
        for (i = 0; i < script.count; i++)
            script.lines[i] = lines[i];
    }

    void vdev_script_register(void)
    {
        VDev dev;
        memset(&dev, 0, sizeof(dev));
        dev.name      = "SCRIPT:";
        dev.dev_getc  = script_getc;
        dev.dev_gets  = script_gets;
        dev.user_data = &script;
        vdev_register(&dev);
    }

  USAGE:

    const char *test_input[] = {
        "John Smith",          /* response to first INPUT */
        "42",                  /* response to second INPUT */
        "Y"                    /* response to third INPUT */
    };
    vdev_script_load(test_input, 3);
    vdev_script_register();

    /* Replace CON:'s input to use the script */
    VDev *con = vdev_get(VDEV_CON);
    VDev *scr = vdev_get(VDEV_USER);  /* script device */
    con->dev_getc = scr->dev_getc;
    con->dev_gets = scr->dev_gets;


=====================================================================
6. ACCESSING THE FILE SYSTEM
=====================================================================


---------------------------------------------------------------------
6.1  How FILE: Channels Work
---------------------------------------------------------------------

  BASIC++ provides 8 file channels (#1 through #8) managed
  by the fileio.c subsystem.  These are separate from the
  VDev slot 2 (FILE:) — the slot 2 device handles SAVE/LOAD,
  while the 8 channels handle OPEN/CLOSE/PRINT#/INPUT#.

  Channel lifecycle:

    OPEN "data.txt" FOR INPUT AS #1    Open channel 1
    INPUT #1, A$                       Read from channel 1
    CLOSE #1                           Close channel 1

  Each channel is a FileChannel structure:

    struct FileChannel {
        FILE *fp;            /* C file pointer */
        int   mode;          /* CLOSED/INPUT/OUTPUT/APPEND/RANDOM/BINARY */
        int   record_len;    /* for RANDOM mode (default 128) */
        char  record_buf[];  /* record buffer (256 bytes) */
        FieldMap fields[];   /* FIELD mappings (up to 16) */
        int   field_count;
        long  current_rec;   /* current record number */
    };


---------------------------------------------------------------------
6.2  Sequential File Access
---------------------------------------------------------------------

  OUTPUT mode — create/overwrite a file:

    OPEN "output.txt" FOR OUTPUT AS #1
    PRINT #1, "Line one"
    PRINT #1, "Line two"
    PRINT #1, "Value = "; 42
    CLOSE #1

  INPUT mode — read from a file:

    OPEN "output.txt" FOR INPUT AS #1
    WHILE NOT EOF(1)
      LINE INPUT #1, A$
      PRINT A$
    WEND
    CLOSE #1

  APPEND mode — add to end of file:

    OPEN "output.txt" FOR APPEND AS #1
    PRINT #1, "Line three (appended)"
    CLOSE #1

  Multiple simultaneous files:

    OPEN "source.txt" FOR INPUT AS #1
    OPEN "dest.txt" FOR OUTPUT AS #2
    WHILE NOT EOF(1)
      LINE INPUT #1, A$
      PRINT #2, UCASE$(A$)
    WEND
    CLOSE #1
    CLOSE #2

  Comma-delimited data:

    ' Writing
    OPEN "data.csv" FOR OUTPUT AS #1
    FOR I = 1 TO 10
      PRINT #1, I; ","; I * I; ","; SQR(I)
    NEXT
    CLOSE #1

    ' Reading
    OPEN "data.csv" FOR INPUT AS #1
    WHILE NOT EOF(1)
      INPUT #1, N, SQUARE, ROOT
      PRINT N, SQUARE, ROOT
    WEND
    CLOSE #1


---------------------------------------------------------------------
6.3  Random-Access Files
---------------------------------------------------------------------

  Random-access files use fixed-length records.  You can
  read or write any record by number, in any order.

  OPEN "database.dat" FOR RANDOM AS #1 LEN = 64
  FIELD #1, 20 AS N$, 10 AS PHONE$, 30 AS ADDR$, 4 AS AGE$

  ' Write record 1
  LSET N$ = "John Smith"
  LSET PHONE$ = "555-1234"
  LSET ADDR$ = "123 Main Street"
  LSET AGE$ = MKI$(30)
  PUT #1, 1

  ' Read record 1
  GET #1, 1
  PRINT N$
  PRINT PHONE$
  PRINT ADDR$
  PRINT CVI(AGE$)

  CLOSE #1

  Key functions:
    FIELD #n, w AS v$, ...   Map variables to record buffer
    LSET v$ = expr$          Left-justify into field
    RSET v$ = expr$          Right-justify into field
    PUT #n, rec              Write record buffer to file
    GET #n, rec              Read record from file into buffer
    MKI$(n)                  Convert integer to 2-byte string
    MKS$(n)                  Convert single to 4-byte string
    MKD$(n)                  Convert double to 8-byte string
    CVI(s$)                  Convert 2-byte string to integer
    CVS(s$)                  Convert 4-byte string to single
    CVD(s$)                  Convert 8-byte string to double
    LOC(n)                   Current record number
    LOF(n)                   Length of file in bytes


---------------------------------------------------------------------
6.4  Binary File Access
---------------------------------------------------------------------

  Binary mode provides raw byte-level access to files.
  No record structure, no line endings — just bytes.

  OPEN "image.bin" FOR BINARY AS #1

  ' Read 4 bytes starting at position 1
  GET #1, 1, header$

  ' Write bytes at position 100
  PUT #1, 100, CHR$(0) + CHR$(255) + CHR$(128)

  ' Read file size
  PRINT LOF(1)

  ' Seek and read
  SEEK #1, 512
  GET #1, , byte$

  CLOSE #1

  Binary mode is essential for:
  - Reading/writing image files
  - Parsing binary data formats
  - Interfacing with hardware data files
  - Memory dumps (BSAVE/BLOAD)


---------------------------------------------------------------------
6.5  File Locking
---------------------------------------------------------------------

  For multi-user or multi-process access, LOCK and UNLOCK
  prevent concurrent writes:

  OPEN "shared.dat" FOR RANDOM AS #1 LEN = 128
  LOCK #1, 5 TO 10          ' Lock records 5-10
  GET #1, 5
  ' ... modify record ...
  PUT #1, 5
  UNLOCK #1, 5 TO 10        ' Release lock
  CLOSE #1

  Locking is advisory on most platforms — it depends on
  the OS supporting POSIX or Windows file locking.


---------------------------------------------------------------------
6.6  Building a Custom File System Device
---------------------------------------------------------------------

  The built-in FILE: device uses C stdio (fopen/fclose).
  You can replace it with a custom implementation to
  access non-standard file systems:

  SCENARIO: Read from a ZIP archive as if it were a
  directory of files.

    #include <stdio.h>
    #include <string.h>
    #include "vdev.h"
    /* Hypothetical ZIP library */
    #include "minizip.h"

    typedef struct {
        void  *zip_handle;       /* ZIP archive handle */
        void  *entry_handle;     /* current file entry */
        char   entry_name[256];  /* current file name */
    } ZipDevState;

    static ZipDevState zstate;

    static int zip_open(VDev *d, const char *path,
                        const char *mode)
    {
        ZipDevState *z = (ZipDevState *)d->user_data;
        /* path format: "archive.zip/filename.txt" */
        char *slash = strchr(path, '/');
        if (!slash) return -1;

        /* Open archive */
        *slash = '\0';
        z->zip_handle = zip_open_file(path);
        *slash = '/';
        if (!z->zip_handle) return -1;

        /* Open entry within archive */
        strncpy(z->entry_name, slash + 1,
                sizeof(z->entry_name) - 1);
        z->entry_handle = zip_open_entry(
            z->zip_handle, z->entry_name);
        if (!z->entry_handle) {
            zip_close_file(z->zip_handle);
            z->zip_handle = NULL;
            return -1;
        }
        return 0;
    }

    static int zip_getc(VDev *d)
    {
        ZipDevState *z = (ZipDevState *)d->user_data;
        unsigned char ch;
        if (!z->entry_handle) return -1;
        if (zip_read_entry(z->entry_handle, &ch, 1) != 1)
            return -1;
        return ch;
    }

    static int zip_close(VDev *d)
    {
        ZipDevState *z = (ZipDevState *)d->user_data;
        if (z->entry_handle) zip_close_entry(z->entry_handle);
        if (z->zip_handle) zip_close_file(z->zip_handle);
        z->entry_handle = NULL;
        z->zip_handle   = NULL;
        return 0;
    }

    void vdev_zip_register(void)
    {
        VDev dev;
        memset(&dev, 0, sizeof(dev));
        dev.name      = "ZIP:";
        dev.dev_open  = zip_open;
        dev.dev_getc  = zip_getc;
        dev.dev_close = zip_close;
        dev.user_data = &zstate;
        vdev_register(&dev);
    }


---------------------------------------------------------------------
6.7  Directory Listing Device
---------------------------------------------------------------------

  A device that reads directory entries as if they were
  lines of text — each call to dev_gets returns the next
  filename.

    #include <stdio.h>
    #include <string.h>
    #include "vdev.h"

    /* Platform-specific directory reading */
    #if defined(_WIN32) || defined(_WIN64)
    #include <windows.h>
    typedef struct {
        HANDLE           hFind;
        WIN32_FIND_DATAA fdata;
        int              first;
    } DirState;

    static int dir_open(VDev *d, const char *path,
                        const char *mode)
    {
        DirState *s = (DirState *)d->user_data;
        char pattern[260];
        (void)mode;
        sprintf(pattern, "%s\\*", path);
        s->hFind = FindFirstFileA(pattern, &s->fdata);
        s->first = 1;
        return (s->hFind == INVALID_HANDLE_VALUE) ? -1 : 0;
    }

    static int dir_gets(VDev *d, char *buf, int max)
    {
        DirState *s = (DirState *)d->user_data;
        if (s->hFind == INVALID_HANDLE_VALUE) return -1;
        if (!s->first) {
            if (!FindNextFileA(s->hFind, &s->fdata))
                return -1;
        }
        s->first = 0;
        strncpy(buf, s->fdata.cFileName, max - 1);
        buf[max - 1] = '\0';
        return 0;
    }

    static int dir_close(VDev *d)
    {
        DirState *s = (DirState *)d->user_data;
        if (s->hFind != INVALID_HANDLE_VALUE) {
            FindClose(s->hFind);
            s->hFind = INVALID_HANDLE_VALUE;
        }
        return 0;
    }

    #else  /* POSIX */
    #include <dirent.h>
    typedef struct {
        DIR *dp;
    } DirState;

    static int dir_open(VDev *d, const char *path,
                        const char *mode)
    {
        DirState *s = (DirState *)d->user_data;
        (void)mode;
        s->dp = opendir(path);
        return (s->dp == NULL) ? -1 : 0;
    }

    static int dir_gets(VDev *d, char *buf, int max)
    {
        DirState *s = (DirState *)d->user_data;
        struct dirent *ent;
        if (!s->dp) return -1;
        ent = readdir(s->dp);
        if (!ent) return -1;
        strncpy(buf, ent->d_name, max - 1);
        buf[max - 1] = '\0';
        return 0;
    }

    static int dir_close(VDev *d)
    {
        DirState *s = (DirState *)d->user_data;
        if (s->dp) { closedir(s->dp); s->dp = NULL; }
        return 0;
    }
    #endif

    static DirState dir_state;

    void vdev_dir_register(void)
    {
        VDev dev;
        memset(&dev, 0, sizeof(dev));
        dev.name      = "DIR:";
        dev.dev_open  = dir_open;
        dev.dev_gets  = dir_gets;
        dev.dev_close = dir_close;
        dev.user_data = &dir_state;
        vdev_register(&dev);
    }

6.8  File Watcher Device
---------------------------------------------------------------------

  A device that polls a file for changes and provides
  new data as it appears (like Unix 'tail -f').

    typedef struct {
        FILE *fp;
        long  last_pos;
    } TailState;

    static TailState tail_state = { NULL, 0 };

    static int tail_open(VDev *d, const char *path,
                         const char *mode)
    {
        TailState *s = (TailState *)d->user_data;
        (void)mode;
        s->fp = fopen(path, "r");
        if (!s->fp) return -1;
        fseek(s->fp, 0, SEEK_END);
        s->last_pos = ftell(s->fp);
        return 0;
    }

    static int tail_gets(VDev *d, char *buf, int max)
    {
        TailState *s = (TailState *)d->user_data;
        long current_size;
        if (!s->fp) return -1;

        /* Check for new data */
        fseek(s->fp, 0, SEEK_END);
        current_size = ftell(s->fp);
        if (current_size <= s->last_pos) return -1;

        fseek(s->fp, s->last_pos, SEEK_SET);
        if (fgets(buf, max, s->fp) == NULL) return -1;
        s->last_pos = ftell(s->fp);
        return 0;
    }

    static int tail_close(VDev *d)
    {
        TailState *s = (TailState *)d->user_data;
        if (s->fp) { fclose(s->fp); s->fp = NULL; }
        return 0;
    }

---------------------------------------------------------------------
7.1  Serial Port Device (RS-232 / COM / ttyS)
---------------------------------------------------------------------

  Enables BASIC++ programs to communicate with serial
  devices: modems, microcontrollers (Arduino), GPS
  receivers, laboratory instruments, etc.

  PLATFORM-SPECIFIC IMPLEMENTATION:

  Windows: Uses CreateFile("COM3", ...) + ReadFile/WriteFile
  Linux:   Uses open("/dev/ttyUSB0", ...) + termios
  FreeDOS: Uses INT 14h (BIOS serial) or direct port I/O

  COMPLETE WINDOWS IMPLEMENTATION:

    #if defined(_WIN32)
    #include <windows.h>

    typedef struct {
        HANDLE hPort;
    } SerialState;

    static SerialState ser_state = { INVALID_HANDLE_VALUE };

    static int ser_open(VDev *d, const char *path,
                        const char *mode)
    {
        SerialState *s = (SerialState *)d->user_data;
        DCB dcb;
        COMMTIMEOUTS timeouts;

        s->hPort = CreateFileA(path,
            GENERIC_READ | GENERIC_WRITE,
            0, NULL, OPEN_EXISTING,
            FILE_ATTRIBUTE_NORMAL, NULL);
        if (s->hPort == INVALID_HANDLE_VALUE) return -1;

        /* Parse mode: "9600,8,N,1" */
        memset(&dcb, 0, sizeof(dcb));
        dcb.DCBlength = sizeof(dcb);
        GetCommState(s->hPort, &dcb);
        dcb.BaudRate  = 9600;     /* default */
        dcb.ByteSize  = 8;
        dcb.Parity    = NOPARITY;
        dcb.StopBits  = ONESTOPBIT;

        /* Parse baud rate from mode string */
        if (mode && mode[0]) {
            dcb.BaudRate = (DWORD)atol(mode);
        }

        SetCommState(s->hPort, &dcb);

        /* Set timeouts: 1 second read timeout */
        timeouts.ReadIntervalTimeout = 100;
        timeouts.ReadTotalTimeoutMultiplier = 10;
        timeouts.ReadTotalTimeoutConstant = 1000;
        timeouts.WriteTotalTimeoutMultiplier = 10;
        timeouts.WriteTotalTimeoutConstant = 1000;
        SetCommTimeouts(s->hPort, &timeouts);
        return 0;
    }

    static int ser_putc(VDev *d, int ch)
    {
        SerialState *s = (SerialState *)d->user_data;
        DWORD written;
        unsigned char c = (unsigned char)ch;
        if (s->hPort == INVALID_HANDLE_VALUE) return -1;
        WriteFile(s->hPort, &c, 1, &written, NULL);
        return (written == 1) ? 0 : -1;
    }

    static int ser_puts(VDev *d, const char *str)
    {
        SerialState *s = (SerialState *)d->user_data;
        DWORD written;
        DWORD len = (DWORD)strlen(str);
        if (s->hPort == INVALID_HANDLE_VALUE) return -1;
        WriteFile(s->hPort, str, len, &written, NULL);
        return (written == len) ? 0 : -1;
    }

    static int ser_getc(VDev *d)
    {
        SerialState *s = (SerialState *)d->user_data;
        DWORD bytesRead;
        unsigned char c;
        if (s->hPort == INVALID_HANDLE_VALUE) return -1;
        if (!ReadFile(s->hPort, &c, 1, &bytesRead, NULL))
            return -1;
        if (bytesRead == 0) return -1;
        return c;
    }

    static int ser_gets(VDev *d, char *buf, int max)
    {
        int i = 0;
        int ch;
        while (i < max - 1) {
            ch = ser_getc(d);
            if (ch < 0) break;
            buf[i++] = (char)ch;
            if (ch == '\n') break;
        }
        buf[i] = '\0';
        return (i > 0) ? 0 : -1;
    }

    static int ser_close(VDev *d)
    {
        SerialState *s = (SerialState *)d->user_data;
        if (s->hPort != INVALID_HANDLE_VALUE) {
            CloseHandle(s->hPort);
            s->hPort = INVALID_HANDLE_VALUE;
        }
        return 0;
    }

    void vdev_serial_register(void)
    {
        VDev dev;
        memset(&dev, 0, sizeof(dev));
        dev.name      = "SER:";
        dev.dev_putc  = ser_putc;
        dev.dev_puts  = ser_puts;
        dev.dev_getc  = ser_getc;
        dev.dev_gets  = ser_gets;
        dev.dev_open  = ser_open;
        dev.dev_close = ser_close;
        dev.user_data = &ser_state;
        vdev_register(&dev);
    }
    #endif

  USAGE FROM C CODE:

    VDev *ser = vdev_get(VDEV_USER);
    ser->dev_open(ser, "COM3", "9600");
    vdev_puts(ser, "AT\r\n");          /* Send AT command */
    char buf[256];
    vdev_gets(ser, buf, 256);          /* Read response */
    printf("Modem says: %s\n", buf);
    ser->dev_close(ser);

7.2  Network Socket Device (TCP/IP)
---------------------------------------------------------------------

  Enables BASIC++ to make TCP connections (HTTP requests,
  telnet, chat servers, etc.)

  WINDOWS IMPLEMENTATION (Winsock2):

    #if defined(_WIN32)
    #include <winsock2.h>
    #include <ws2tcpip.h>
    #pragma comment(lib, "ws2_32.lib")

    typedef struct {
        SOCKET sock;
        int    initialized;
    } NetState;

    static NetState net_state = { INVALID_SOCKET, 0 };

    static void net_wsa_init(NetState *s)
    {
        WSADATA wsa;
        if (!s->initialized) {
            WSAStartup(MAKEWORD(2, 2), &wsa);
            s->initialized = 1;
        }
    }

    static int net_open(VDev *d, const char *path,
                        const char *mode)
    {
        /* path = "host:port" */
        NetState *s = (NetState *)d->user_data;
        struct addrinfo hints, *res;
        char host[256], port[16];
        char *colon;
        (void)mode;

        net_wsa_init(s);

        strncpy(host, path, sizeof(host) - 1);
        host[sizeof(host) - 1] = '\0';
        colon = strchr(host, ':');
        if (!colon) return -1;
        *colon = '\0';
        strncpy(port, colon + 1, sizeof(port) - 1);

        memset(&hints, 0, sizeof(hints));
        hints.ai_family   = AF_INET;
        hints.ai_socktype = SOCK_STREAM;
        if (getaddrinfo(host, port, &hints, &res) != 0)
            return -1;

        s->sock = socket(res->ai_family, res->ai_socktype,
                         res->ai_protocol);
        if (s->sock == INVALID_SOCKET) {
            freeaddrinfo(res);
            return -1;
        }
        if (connect(s->sock, res->ai_addr,
                    (int)res->ai_addrlen) != 0) {
            closesocket(s->sock);
            s->sock = INVALID_SOCKET;
            freeaddrinfo(res);
            return -1;
        }
        freeaddrinfo(res);
        return 0;
    }

    static int net_putc(VDev *d, int ch)
    {
        NetState *s = (NetState *)d->user_data;
        char c = (char)ch;
        if (s->sock == INVALID_SOCKET) return -1;
        return (send(s->sock, &c, 1, 0) == 1) ? 0 : -1;
    }

    static int net_puts(VDev *d, const char *str)
    {
        NetState *s = (NetState *)d->user_data;
        int len = (int)strlen(str);
        if (s->sock == INVALID_SOCKET) return -1;
        return (send(s->sock, str, len, 0) == len) ? 0 : -1;
    }

    static int net_getc(VDev *d)
    {
        NetState *s = (NetState *)d->user_data;
        char c;
        if (s->sock == INVALID_SOCKET) return -1;
        if (recv(s->sock, &c, 1, 0) != 1) return -1;
        return (unsigned char)c;
    }

    static int net_gets(VDev *d, char *buf, int max)
    {
        int i = 0, ch;
        while (i < max - 1) {
            ch = net_getc(d);
            if (ch < 0) break;
            buf[i++] = (char)ch;
            if (ch == '\n') break;
        }
        buf[i] = '\0';
        return (i > 0) ? 0 : -1;
    }

    static int net_close(VDev *d)
    {
        NetState *s = (NetState *)d->user_data;
        if (s->sock != INVALID_SOCKET) {
            closesocket(s->sock);
            s->sock = INVALID_SOCKET;
        }
        return 0;
    }

    void vdev_net_register(void)
    {
        VDev dev;
        memset(&dev, 0, sizeof(dev));
        dev.name      = "NET:";
        dev.dev_putc  = net_putc;
        dev.dev_puts  = net_puts;
        dev.dev_getc  = net_getc;
        dev.dev_gets  = net_gets;
        dev.dev_open  = net_open;
        dev.dev_close = net_close;
        dev.user_data = &net_state;
        vdev_register(&dev);
    }
    #endif

  USAGE:

    VDev *net = vdev_get(VDEV_USER);
    net->dev_open(net, "example.com:80", "tcp");
    vdev_puts(net, "GET / HTTP/1.0\r\nHost: example.com\r\n\r\n");
    char buf[1024];
    while (vdev_gets(net, buf, 1024) == 0) {
        printf("%s", buf);
    }
    net->dev_close(net);

7.3  Printer Device (LPT / CUPS / Spooler)
---------------------------------------------------------------------

  Route LPRINT output to a real printer.

  SIMPLE FILE-BASED IMPLEMENTATION:

  On most systems, printing means writing to a file and
  then sending that file to the print spooler.

    typedef struct {
        FILE *spool;       /* spool file */
        char  spool_name[256];
    } PrinterState;

    static PrinterState prn_state;

    static int prn_open(VDev *d, const char *path,
                        const char *mode)
    {
        PrinterState *s = (PrinterState *)d->user_data;
        (void)mode;
        strncpy(s->spool_name, path, sizeof(s->spool_name) - 1);
        s->spool = fopen(path, "w");
        return (s->spool) ? 0 : -1;
    }

    static int prn_putc(VDev *d, int ch)
    {
        PrinterState *s = (PrinterState *)d->user_data;
        if (!s->spool) return -1;
        return (fputc(ch, s->spool) != EOF) ? 0 : -1;
    }

    static int prn_puts(VDev *d, const char *str)
    {
        PrinterState *s = (PrinterState *)d->user_data;
        if (!s->spool) return -1;
        return (fputs(str, s->spool) != EOF) ? 0 : -1;
    }

    static int prn_close(VDev *d)
    {
        PrinterState *s = (PrinterState *)d->user_data;
        char cmd[512];
        if (s->spool) {
            fclose(s->spool);
            s->spool = NULL;
            /* Send to spooler */
            #if defined(_WIN32)
            sprintf(cmd, "print /d:LPT1 \"%s\"",
                    s->spool_name);
            #else
            sprintf(cmd, "lpr \"%s\"", s->spool_name);
            #endif
            system(cmd);
        }
        return 0;
    }

  DIRECT DEVICE ACCESS (Windows):

    /* Write directly to LPT1 */
    static int prn_win_open(VDev *d, const char *path,
                            const char *mode)
    {
        PrinterState *s = (PrinterState *)d->user_data;
        (void)mode;
        s->spool = fopen(path, "w");  /* "LPT1" on Windows */
        return (s->spool) ? 0 : -1;
    }

7.4  Clipboard Device (Copy/Paste)
---------------------------------------------------------------------

  Read from and write to the system clipboard.

  WINDOWS IMPLEMENTATION:

    #if defined(_WIN32)
    #include <windows.h>

    static int clip_puts(VDev *d, const char *s)
    {
        HGLOBAL hMem;
        char *mem;
        int len = (int)strlen(s);
        (void)d;

        if (!OpenClipboard(NULL)) return -1;
        EmptyClipboard();
        hMem = GlobalAlloc(GMEM_MOVEABLE, len + 1);
        if (!hMem) { CloseClipboard(); return -1; }
        mem = (char *)GlobalLock(hMem);
        memcpy(mem, s, len + 1);
        GlobalUnlock(hMem);
        SetClipboardData(CF_TEXT, hMem);
        CloseClipboard();
        return 0;
    }

    static int clip_gets(VDev *d, char *buf, int max)
    {
        HANDLE hData;
        char *text;
        int len;
        (void)d;

        if (!OpenClipboard(NULL)) return -1;
        hData = GetClipboardData(CF_TEXT);
        if (!hData) { CloseClipboard(); return -1; }
        text = (char *)GlobalLock(hData);
        if (!text) { CloseClipboard(); return -1; }
        len = (int)strlen(text);
        if (len >= max) len = max - 1;
        memcpy(buf, text, len);
        buf[len] = '\0';
        GlobalUnlock(hData);
        CloseClipboard();
        return 0;
    }
    #endif

7.6  Pipe Device (Inter-Process Communication)
---------------------------------------------------------------------

  Run an external command and read its stdout or write
  to its stdin.  Enables BASIC++ to interact with other
  programs.

    typedef struct {
        FILE *pipe;
    } PipeState;

    static PipeState pipe_state = { NULL };

    static int pipe_open(VDev *d, const char *cmd,
                         const char *mode)
    {
        PipeState *s = (PipeState *)d->user_data;
        if (s->pipe) { pclose(s->pipe); s->pipe = NULL; }
        #if defined(_WIN32)
        s->pipe = _popen(cmd, mode);
        #else
        s->pipe = popen(cmd, mode);
        #endif
        return (s->pipe) ? 0 : -1;
    }

    static int pipe_getc(VDev *d)
    {
        PipeState *s = (PipeState *)d->user_data;
        if (!s->pipe) return -1;
        return fgetc(s->pipe);
    }

    static int pipe_gets(VDev *d, char *buf, int max)
    {
        PipeState *s = (PipeState *)d->user_data;
        if (!s->pipe) return -1;
        return (fgets(buf, max, s->pipe)) ? 0 : -1;
    }

    static int pipe_puts(VDev *d, const char *str)
    {
        PipeState *s = (PipeState *)d->user_data;
        if (!s->pipe) return -1;
        return (fputs(str, s->pipe) != EOF) ? 0 : -1;
    }

    static int pipe_close(VDev *d)
    {
        PipeState *s = (PipeState *)d->user_data;
        if (s->pipe) {
            #if defined(_WIN32)
            _pclose(s->pipe);
            #else
            pclose(s->pipe);
            #endif
            s->pipe = NULL;
        }
        return 0;
    }

  USAGE — read output of a command:

    VDev *pipe = vdev_get(VDEV_USER + n);
    pipe->dev_open(pipe, "dir /b", "r");
    char buf[256];
    while (pipe->dev_gets(pipe, buf, 256) == 0) {
        printf("File: %s", buf);
    }
    pipe->dev_close(pipe);

7.7  Shared Memory Device
---------------------------------------------------------------------

  Map a region of shared memory as a VDev for inter-process
  data exchange.

  WINDOWS IMPLEMENTATION:

    #if defined(_WIN32)
    #include <windows.h>

    typedef struct {
        HANDLE hMap;
        char  *view;
        int    size;
        int    pos;
    } ShmState;

    static ShmState shm_state;

    static int shm_open(VDev *d, const char *name,
                        const char *mode)
    {
        ShmState *s = (ShmState *)d->user_data;
        int size = 4096;
        (void)mode;

        s->hMap = CreateFileMappingA(INVALID_HANDLE_VALUE,
                     NULL, PAGE_READWRITE, 0, size, name);
        if (!s->hMap) return -1;
        s->view = (char *)MapViewOfFile(s->hMap,
                     FILE_MAP_ALL_ACCESS, 0, 0, size);
        if (!s->view) {
            CloseHandle(s->hMap);
            s->hMap = NULL;
            return -1;
        }
        s->size = size;
        s->pos  = 0;
        return 0;
    }

    static int shm_putc(VDev *d, int ch)
    {
        ShmState *s = (ShmState *)d->user_data;
        if (!s->view || s->pos >= s->size - 1) return -1;
        s->view[s->pos++] = (char)ch;
        return 0;
    }

    static int shm_getc(VDev *d)
    {
        ShmState *s = (ShmState *)d->user_data;
        if (!s->view || s->pos >= s->size) return -1;
        return (unsigned char)s->view[s->pos++];
    }

    static int shm_close(VDev *d)
    {
        ShmState *s = (ShmState *)d->user_data;
        if (s->view) UnmapViewOfFile(s->view);
        if (s->hMap) CloseHandle(s->hMap);
        s->view = NULL;
        s->hMap = NULL;
        return 0;
    }
    #endif

7.8  GPIO Device (Raspberry Pi / Embedded)
---------------------------------------------------------------------

  Access GPIO pins on a Raspberry Pi or embedded Linux
  system through the sysfs interface.

    /* Linux sysfs GPIO implementation */
    #if defined(__linux__)

    typedef struct {
        int pin;
        FILE *value_fp;
    } GpioState;

    static GpioState gpio_state;

    static int gpio_open(VDev *d, const char *path,
                         const char *mode)
    {
        GpioState *s = (GpioState *)d->user_data;
        FILE *fp;
        char filename[256];

        s->pin = atoi(path);

        /* Export the pin */
        fp = fopen("/sys/class/gpio/export", "w");
        if (fp) { fprintf(fp, "%d", s->pin); fclose(fp); }

        /* Set direction */
        sprintf(filename, "/sys/class/gpio/gpio%d/direction",
                s->pin);
        fp = fopen(filename, "w");
        if (fp) {
            fputs((mode[0] == 'w') ? "out" : "in", fp);
            fclose(fp);
        }

        /* Open value file */
        sprintf(filename, "/sys/class/gpio/gpio%d/value",
                s->pin);
        s->value_fp = fopen(filename,
            (mode[0] == 'w') ? "w" : "r");
        return (s->value_fp) ? 0 : -1;
    }

    static int gpio_putc(VDev *d, int ch)
    {
        GpioState *s = (GpioState *)d->user_data;
        if (!s->value_fp) return -1;
        fputc((ch ? '1' : '0'), s->value_fp);
        fflush(s->value_fp);
        return 0;
    }

    static int gpio_getc(VDev *d)
    {
        GpioState *s = (GpioState *)d->user_data;
        char buf[4];
        if (!s->value_fp) return -1;
        rewind(s->value_fp);
        if (!fgets(buf, sizeof(buf), s->value_fp)) return -1;
        return (buf[0] == '1') ? 1 : 0;
    }

    static int gpio_close(VDev *d)
    {
        GpioState *s = (GpioState *)d->user_data;
        FILE *fp;
        if (s->value_fp) {
            fclose(s->value_fp);
            s->value_fp = NULL;
        }
        fp = fopen("/sys/class/gpio/unexport", "w");
        if (fp) { fprintf(fp, "%d", s->pin); fclose(fp); }
        return 0;
    }
    #endif

8. INP AND OUT (VIRTUAL I/O PORTS)
=====================================================================

INP and OUT operate on the 64K virtual memory space managed
by the MEMMAP system.  They are aliases for PEEK and POKE:

  X = INP(port)          Identical to X = PEEK(port)
  OUT port, value        Identical to POKE port, value

In the MSDOS memory map, the convention is:
  Ports $0000-$03FF are "I/O space" (overlapping the IVT)
  This matches the 8086's I/O port address space

In other maps (C64, Atari, etc.), INP/OUT are simply
additional syntax for PEEK/POKE since those machines use
memory-mapped I/O rather than a separate port space.

Examples:

  MEMMAP "MSDOS"
  OUT &H3D4, &H0E          ' CRT cursor register
  X = INP(&H3D5)            ' Read cursor position

  MEMMAP "C64"
  OUT &HD418, 15            ' SID volume register
  OUT &HD400, 100           ' SID frequency low byte

  MEMMAP "ATARI8"
  X = INP(&HD20A)            ' Read POKEY random number
  OUT &HD200, 128            ' Set AUDF1 frequency

9.2  Intercepting Output (Middleware Pattern)
---------------------------------------------------------------------

  The middleware pattern lets you wrap an existing device
  with additional behavior without replacing it entirely.

  EXAMPLE — Add timestamps to all console output:

    static int (*original_puts)(VDev*, const char*) = NULL;

    static int timestamped_puts(VDev *d, const char *s)
    {
        char timestamp[32];
        time_t now = time(NULL);
        struct tm *tm = localtime(&now);
        sprintf(timestamp, "[%02d:%02d:%02d] ",
                tm->tm_hour, tm->tm_min, tm->tm_sec);

        /* Write timestamp first (bypass to original) */
        original_puts(d, timestamp);
        /* Then write the actual string */
        return original_puts(d, s);
    }

    void install_timestamp_middleware(void)
    {
        VDev *con = vdev_get(VDEV_CON);
        original_puts = con->dev_puts;
        con->dev_puts = timestamped_puts;
    }

  EXAMPLE — Convert all output to uppercase:

    static int (*orig_putc)(VDev*, int) = NULL;

    static int upper_putc(VDev *d, int ch)
    {
        if (ch >= 'a' && ch <= 'z') ch -= 32;
        return orig_putc(d, ch);
    }

    void install_upper_filter(void)
    {
        VDev *con = vdev_get(VDEV_CON);
        orig_putc = con->dev_putc;
        con->dev_putc = upper_putc;
    }


---------------------------------------------------------------------
9.3  Redirecting Input (Script Playback)
---------------------------------------------------------------------

  Replace CON:'s input functions to feed pre-recorded
  responses.  See Tutorial 5 (Section 5.5) for the full
  implementation.

  Quick approach — redirect from a file:

    static FILE *input_file = NULL;

    static int file_input_gets(VDev *d, char *buf, int max)
    {
        (void)d;
        if (!input_file) return -1;
        if (!fgets(buf, max, input_file)) {
            fclose(input_file);
            input_file = NULL;
            return -1;
        }
        return 0;
    }

    void redirect_input_from_file(const char *filename)
    {
        VDev *con = vdev_get(VDEV_CON);
        input_file = fopen(filename, "r");
        if (input_file) {
            con->dev_gets = file_input_gets;
        }
    }


---------------------------------------------------------------------
9.4  Hot-Swapping Devices
---------------------------------------------------------------------

  You can swap device function pointers at any time during
  program execution.  This enables dynamic routing:

    /* During program execution, swap output destination */
    VDev *con = vdev_get(VDEV_CON);

    /* Save original handlers */
    int (*saved_putc)(VDev*, int)        = con->dev_putc;
    int (*saved_puts)(VDev*, const char*) = con->dev_puts;

    /* Redirect output to ERR: temporarily */
    VDev *err = vdev_get(VDEV_ERR);
    con->dev_putc = err->dev_putc;
    con->dev_puts = err->dev_puts;

    /* ... all PRINT output now goes to stderr ... */

    /* Restore original */
    con->dev_putc = saved_putc;
    con->dev_puts = saved_puts;

10. BUILDING DEVICE MODULES
=====================================================================


---------------------------------------------------------------------
10.1  Module + Device Integration
---------------------------------------------------------------------

  The module system (module.h/module.c) provides a framework
  for packaging device drivers as self-contained, versioned
  units.

  Module class MOD_DEVICE is specifically designed for VDev
  drivers.  The module's init callback registers the device,
  and the cleanup callback can remove it.

  EXAMPLE — Serial Port Module:

    #include "module.h"
    #include "vdev.h"

    /* Forward declaration of device registration */
    extern void vdev_serial_register(void);

    static int serial_init(void *rt)
    {
        (void)rt;
        vdev_serial_register();
        return 0;  /* success */
    }

    static void serial_cleanup(void)
    {
        /* Close any open serial port */
        VDev *ser = vdev_get(VDEV_USER);
        if (ser && ser->dev_close) ser->dev_close(ser);
    }

    static const ModuleInfo serial_module = {
        "SERIAL",                      /* name */
        "1.0",                         /* version */
        "RS-232 serial port driver",   /* description */
        MOD_DEVICE,                    /* class */
        CAP_IO | CAP_SYSTEM,           /* capabilities */
        serial_init,                   /* init callback */
        serial_cleanup                 /* cleanup callback */
    };

    /* Call during boot to make module available */
    void serial_module_register(void)
    {
        module_register(&serial_module);
    }

  From BASIC:

    MODULE "SERIAL"           ' Activate the serial module
    ' The SER: device is now available


---------------------------------------------------------------------
10.2  Capability Flags
---------------------------------------------------------------------

  Each module declares which system resources it needs:

    Flag         Hex    Description
    ----         ---    -----------
    CAP_NONE     0x00   No system access needed
    CAP_MATH     0x01   Mathematical functions
    CAP_STRING   0x02   String manipulation
    CAP_IO       0x04   General I/O operations
    CAP_FILE     0x08   File system access
    CAP_SYSTEM   0x10   System-level operations
    CAP_GRAPHICS 0x20   Graphics device
    CAP_SOUND    0x40   Sound device
    CAP_NETWORK  0x80   Network access

  When security sandboxing is active (Phase 15), modules
  can only be loaded if their capabilities match the
  trust level.  See Q_Security.txt for details.


---------------------------------------------------------------------
10.3  Complete Module Example: Serial Device
---------------------------------------------------------------------

  Here is a complete, compilable module file that packages
  the serial port device (Section 7.1) as a BASIC++ module.

  File: mod_serial.c

    /*
     * mod_serial.c - Serial Port Module for BASIC++
     * Provides SER: virtual device for RS-232 communication.
     *
     * USAGE:
     *   MODULE "SERIAL"
     *   ' Device SER: is now active

     * Requires: Windows (Win32 API) or Linux (termios)
     */

    3. Rebuild basicpp.exe

13. LIMITATIONS AND CONSTRAINTS
=====================================================================

  DEVICE TABLE:
  - Maximum 16 device slots (3 built-in + 13 user)
  - No vdev_unregister() — once registered, always present
  - Device names are for display only (not used for routing)
  - vdev_register() copies the struct — original not retained

  FUNCTION POINTERS:
  - NULL function pointers are safe (convenience functions
    return -1)
  - No error callbacks — errors are silent unless the
    handler explicitly reports them
  - vdev_printf() limited to 1023 characters per call

  FILE CHANNELS:
  - Maximum 8 simultaneous file channels (#1-#8)
  - Maximum 256-byte record length for RANDOM mode
  - Maximum 16 FIELD mappings per channel
  - File locking is advisory (OS-dependent)

  PLATFORM:
  - Serial, network, clipboard, audio, shared memory, and
    GPIO devices are platform-specific (Windows/Linux)
  - No portable C89 implementation exists for these
  - They must be compiled conditionally (#if defined)
  - FreeDOS support is limited to stdio-based devices

  GENERAL:
  - Devices are registered from C code only (not from BASIC)
  - No dynamic device loading at runtime (compile-time only)
  - Device interception modifies global state (not per-program)
  - No thread safety (single-threaded interpreter)

=====================================================================
15. VDEV2 ARCHITECTURE OVERVIEW
=====================================================================

The original VDev (Phase 3) provided character-based I/O through
10 fields: name, putc, puts, flush, cls, getc, gets, open, close,
user_data.  This was sufficient for TTYs, printers, and files.

VDev2 (Phase 16) extends this with 12 new fields:

  METADATA (5 fields):
    dev_class       VDevClass enum — what kind of device
    dev_caps        VDCAP_ bitfield — what it can do
    dev_version     Version string ("1.0")
    dev_description Human-readable description
    dev_req_caps    Required CAP_ flags for security gating

  BINARY I/O (3 fields):
    dev_read(d, buf, len)    Read raw bytes into buffer
    dev_write(d, buf, len)   Write raw bytes from buffer
    dev_seek(d, offset, wh)  Seek to byte position

  CONTROL (1 field):
    dev_ioctl(d, cmd, arg)   Structured control commands

  STATUS (3 fields):
    dev_status(d)            Device health check
    dev_poll(d)              Non-blocking data readiness
    dev_info(d, key)         Key-value metadata queries

All new fields are OPTIONAL.  If set to NULL, the convenience
wrappers (vdev_read, vdev_ioctl, etc.) return -1/NULL safely.
Existing VDev code is 100% backward compatible.

Device table expanded from 16 to 64 slots.
File channels expanded from 8 to 16.
Channels can now route to VDevs via FCHAN_DEVICE mode.


=====================================================================
16. DEVICE CLASS TAXONOMY
=====================================================================

Every VDev2 device declares its class via dev_class:

  Enum                  Code  Category        Examples
  ----                  ----  --------        --------
  VDCLASS_UNKNOWN         0   Unclassified    Legacy VDevs
  VDCLASS_CONSOLE         1   Human I/O       Screen, keyboard
  VDCLASS_FILE            2   Storage         Disk files
  VDCLASS_SERIAL          3   Communication   RS-232, USB-serial
  VDCLASS_PRINTER         4   Output          LPT, PDF, CUPS
  VDCLASS_AUDIO           5   Sound           Speaker, MIDI, WAV
  VDCLASS_NETWORK         6   Networking      TCP, UDP, HTTP, WS
  VDCLASS_GPIO            7   Embedded I/O    RPi pins, LED
  VDCLASS_I2C             8   Embedded Bus    Sensors, displays
  VDCLASS_SPI             9   Embedded Bus    Flash, SD card
  VDCLASS_SENSOR         10   Data Capture    Temp, accel, GPS
  VDCLASS_DISPLAY        11   Visual Output   LCD, OLED, GUI
  VDCLASS_STORAGE        12   Block I/O       SD, USB drive
  VDCLASS_HID            13   Input Device    Touch, joystick
  VDCLASS_CAMERA         14   Video Capture   Webcam, RPi camera
  VDCLASS_BRIDGE         15   MCU Gateway     Arduino, ESP32
  VDCLASS_BLUETOOTH      16   Wireless        BT Classic, BLE
  VDCLASS_CLIPBOARD      17   System          Copy/paste
  VDCLASS_PIPE           18   IPC             Process pipes
  VDCLASS_TIMER          19   Timing          HW/SW timers
  VDCLASS_CUSTOM         99   User-Defined    Anything else

Devices with VDCLASS_UNKNOWN are assumed to be Phase 3 legacy
devices.  They work fine — they just can't be found by class.

Classes are pure metadata.  They do NOT restrict which function
pointers a device implements.  A GPIO device CAN implement
dev_puts if it wants to accept text commands like "1" or "0".


=====================================================================
17. PER-DEVICE CAPABILITY FLAGS (VDCAP_)
=====================================================================

Each device declares what it CAN DO via dev_caps:

  Flag           Bit     Meaning
  ----           ---     -------
  VDCAP_READ    0x0001   Device supports reading
  VDCAP_WRITE   0x0002   Device supports writing
  VDCAP_BINARY  0x0004   Device supports binary I/O
  VDCAP_SEEK    0x0008   Device supports seeking
  VDCAP_ASYNC   0x0010   Device supports non-blocking
  VDCAP_HOTPLUG 0x0020   Device can appear/disappear
  VDCAP_CONTROL 0x0040   Device supports IOCTL2
  VDCAP_STATUS  0x0080   Device has queryable status
  VDCAP_EVENT   0x0100   Device generates events
  VDCAP_DUPLEX  0x0200   Device supports full-duplex
  VDCAP_BLOCK   0x0400   Device does block I/O

  Convenience macros:
  VDCAP_RW       = READ | WRITE
  VDCAP_STREAM   = READ | WRITE | DUPLEX
  VDCAP_FILELIKE = READ | WRITE | BINARY | SEEK

These flags are INFORMATIONAL for the BASIC program.  The
security system uses dev_req_caps (module-level CAP_ flags)
for access control, not VDCAP_ flags.

  Example — a temperature sensor:
    dev_caps = VDCAP_READ | VDCAP_BINARY | VDCAP_STATUS;
    (Read-only, binary data, status queryable)

  Example — a serial port:
    dev_caps = VDCAP_STREAM | VDCAP_BINARY | VDCAP_CONTROL;
    (Bidirectional, raw bytes, configurable)


=====================================================================
18. BINARY I/O (dev_read / dev_write / dev_seek)
=====================================================================

Character I/O (putc/puts/getc/gets) handles text.  Binary I/O
handles raw bytes — essential for:

  - Sensor readings (4-byte float, 2-byte int)
  - Camera frames (64K+ pixel buffers)
  - Block devices (512-byte sectors)
  - Protocol packets (fixed-format headers)
  - Audio samples (16-bit PCM data)

  SIGNATURES:
    int  dev_read(VDev *d, void *buf, int len);
    int  dev_write(VDev *d, const void *buf, int len);
    long dev_seek(VDev *d, long offset, int whence);

  dev_read returns bytes actually read (may be < len).
  dev_write returns bytes actually written.
  dev_seek returns new position, or -1 on error.
  whence: 0=SEEK_SET, 1=SEEK_CUR, 2=SEEK_END

  IMPLEMENTATION EXAMPLE — binary sensor read:

    static int sensor_read(VDev *d, void *buf, int len)
    {
        float temp;
        if (len < (int)sizeof(float)) return -1;
        temp = read_hardware_sensor();
        memcpy(buf, &temp, sizeof(float));
        return sizeof(float);
    }

  From BASIC:
    OPEN "TEMP:" FOR BINARY AS #1
    GET #1, T$, 4
    TEMP = CVS(T$)
    PRINT "Temperature: "; TEMP
    CLOSE #1


=====================================================================
19. IOCTL2 PROTOCOL (dev_ioctl)
=====================================================================

The original IOCTL sent a string command.  IOCTL2 uses
standardized integer codes for structured device control:

  SIGNATURE:
    int dev_ioctl(VDev *d, int cmd, void *arg);

  STANDARD COMMANDS:
    VDIO_RESET        0    Reset device to defaults
    VDIO_GET_STATUS   1    Get status word
    VDIO_SET_BAUD     2    Set baud rate (serial)
    VDIO_SET_PIN      3    Set GPIO pin mode
    VDIO_GET_PIN      4    Get GPIO pin value
    VDIO_SET_ADDR     5    Set I2C/SPI address
    VDIO_SET_TIMEOUT  6    Set timeout in ms
    VDIO_GET_ERROR    7    Get last error code
    VDIO_ENUMERATE    8    List sub-devices
    VDIO_USER       256    First user-defined command

  IMPLEMENTATION EXAMPLE — serial port config:

    static int serial_ioctl(VDev *d, int cmd, void *arg)
    {
        SerialState *ss = (SerialState *)d->user_data;
        switch (cmd) {
        case VDIO_SET_BAUD:
            ss->baud = *(int *)arg;
            configure_uart(ss);
            return 0;
        case VDIO_SET_TIMEOUT:
            ss->timeout_ms = *(int *)arg;
            return 0;
        case VDIO_GET_STATUS:
            *(int *)arg = ss->connected ? 0 : -1;
            return 0;
        default:
            return -1;
        }
    }

  From BASIC (proposed syntax):
    IOCTL #1, 2, 9600       ' Set baud to 9600
    IOCTL #1, 6, 1000       ' Set timeout to 1 second
    IOCTL #1, 0             ' Reset device


=====================================================================
20. STATUS AND POLLING (dev_status / dev_poll)
=====================================================================

  dev_status(d):
    Returns: 0 = device ready
             1 = device busy (try again)
            -1 = device error / offline

  dev_poll(d):
    Returns: 1 = data is available to read
             0 = no data available
            -1 = error

  Together, these enable non-blocking I/O:

    10 OPEN "SENSOR:" FOR INPUT AS #1
    20 WHILE 1
    30   IF POLL(#1) THEN
    40     LINE INPUT #1, R$
    50     PRINT "Sensor: "; R$
    60   END IF
    70   SLEEP 100
    80 WEND

  POLL(#n) maps to vdev_poll() on the channel's VDev.


=====================================================================
21. DEVICE INFO QUERIES (dev_info)
=====================================================================

  SIGNATURE:
    const char *dev_info(VDev *d, const char *key);

  The vdev_info() wrapper handles built-in keys automatically:
    "name"         Returns d->name
    "class"        Returns class name string
    "version"      Returns d->dev_version
    "description"  Returns d->dev_description

  Device-specific keys are delegated to d->dev_info:
    "baud"         Current baud rate (serial device)
    "address"      I2C address (sensor device)
    "resolution"   Camera resolution (camera device)
    "error"        Last error message
    "firmware"     Firmware version (bridge device)

  From BASIC:
    PRINT DEVICEINFO$(3, "description")  ' "Serial port COM1"
    PRINT DEVICEINFO$(5, "baud")         ' "9600"
    PRINT DEVICEINFO$(7, "firmware")     ' "Arduino Uno v1.8"

    vdev_find_by_name("COM1:")           Returns slot ID or -1

23. HOT-PLUG DEVICE PATTERNS
=====================================================================

Devices with VDCAP_HOTPLUG can appear or disappear at runtime
(USB devices, Bluetooth peripherals, etc.).

  Pattern 1: Poll for device availability

    10 ID = -1
    20 WHILE ID < 0
    30   ID = DEVICEFIND("USB:")   ' Wait for USB device
    40   IF ID < 0 THEN
    50     PRINT "Waiting for USB device..."
    60     SLEEP 1000
    70   END IF
    80 WEND
    90 OPEN DEVICE$(ID) FOR RANDOM AS #1

  Pattern 2: Check status before each operation

    10 OPEN "USB:" FOR RANDOM AS #1
    20 IF STATUS(#1) < 0 THEN
    30   PRINT "Device disconnected!"
    40   CLOSE #1
    50   GOTO 10
    60 END IF

24.1  GPIO with PWM (Raspberry Pi)
---------------------------------------------------------------------

  /* mod_gpio.c — GPIO device module for Raspberry Pi */

  #include "vdev.h"
  #include "module.h"

  typedef struct GPIOPin {
      int  pin_number;
      int  direction;    /* 0=input, 1=output */
      int  value;        /* 0 or 1 */
      int  pwm_duty;     /* 0-100 for PWM */
  } GPIOPin;

  static GPIOPin pins[28];  /* RPi has up to 28 GPIO pins */

  static int gpio_write(VDev *d, const void *buf, int len)
  {
      GPIOPin *pin = (GPIOPin *)d->user_data;
      int val = *(const int *)buf;
      (void)len;

      /* Write to /sys/class/gpio/gpioN/value */
      pin->value = val ? 1 : 0;
  #ifdef __linux__
      {
          char path[64];
          FILE *fp;
          sprintf(path, "/sys/class/gpio/gpio%d/value",
                  pin->pin_number);
          fp = fopen(path, "w");
          if (fp) {
              fprintf(fp, "%d", pin->value);
              fclose(fp);
          }
      }
  #endif
      return sizeof(int);
  }

  static int gpio_read(VDev *d, void *buf, int len)
  {
      GPIOPin *pin = (GPIOPin *)d->user_data;
      (void)len;

  #ifdef __linux__
      {
          char path[64], tmp[8];
          FILE *fp;
          sprintf(path, "/sys/class/gpio/gpio%d/value",
                  pin->pin_number);
          fp = fopen(path, "r");
          if (fp) {
              fgets(tmp, sizeof(tmp), fp);
              pin->value = atoi(tmp);
              fclose(fp);
          }
      }
  #endif
      *(int *)buf = pin->value;
      return sizeof(int);
  }

  static int gpio_ioctl(VDev *d, int cmd, void *arg)
  {
      GPIOPin *pin = (GPIOPin *)d->user_data;
      switch (cmd) {
      case VDIO_SET_PIN:  /* Set direction */
          pin->direction = *(int *)arg;
          return 0;
      case VDIO_GET_PIN:  /* Get current value */
          *(int *)arg = pin->value;
          return 0;
      default:
          return -1;
      }
  }

  /* Registration: */
  static int gpio_module_init(void *rt)
  {
      int i;
      (void)rt;
      for (i = 0; i < 28; i++) {
          VDev dev;
          char name[16];
          memset(&dev, 0, sizeof(dev));
          sprintf(name, "GPIO%d:", i);
          pins[i].pin_number = i;
          dev.name = name;  /* NOTE: must be static or strdup'd */
          dev.dev_class = VDCLASS_GPIO;
          dev.dev_caps = VDCAP_RW | VDCAP_BINARY | VDCAP_CONTROL;
          dev.dev_description = "Raspberry Pi GPIO pin";
          dev.dev_req_caps = CAP_GPIO;
          dev.dev_read = gpio_read;
          dev.dev_write = gpio_write;
          dev.dev_ioctl = gpio_ioctl;
          dev.user_data = &pins[i];
          vdev_register(&dev);
      }
      return 0;
  }

  From BASIC:
    MODULE "GPIO"
    10 OPEN "GPIO17:" FOR OUTPUT AS #1
    20 IOCTL #1, 3, 1              ' Set pin 17 to OUTPUT
    30 FOR I = 1 TO 10
    40   PRINT #1, "1" : SLEEP 500 ' LED on
    50   PRINT #1, "0" : SLEEP 500 ' LED off
    60 NEXT I
    70 CLOSE #1

24.2  I2C Sensor Module (Temperature / Humidity)
---------------------------------------------------------------------

  /* mod_i2c.c — I2C bus device for RPi/embedded Linux */

  typedef struct I2CDevice {
      int fd;              /* /dev/i2c-N file descriptor */
      int address;         /* 7-bit I2C address */
      int bus;             /* bus number (0 or 1) */
  } I2CDevice;

  static int i2c_open(VDev *d, const char *path,
                      const char *mode)
  {
      I2CDevice *dev = (I2CDevice *)d->user_data;
      (void)mode;
      /* Parse "I2C:0x48" -> address 0x48 */
      if (path) sscanf(path, "I2C:0x%x", &dev->address);
  #ifdef __linux__
      dev->fd = open("/dev/i2c-1", O_RDWR);
      if (dev->fd < 0) return -1;
      ioctl(dev->fd, I2C_SLAVE, dev->address);
  #endif
      return 0;
  }

  static int i2c_read(VDev *d, void *buf, int len)
  {
      I2CDevice *dev = (I2CDevice *)d->user_data;
  #ifdef __linux__
      return read(dev->fd, buf, len);
  #else
      (void)dev; (void)buf; (void)len;
      return -1;  /* Not available on this platform */
  #endif
  }

  From BASIC:
    MODULE "I2C"
    10 OPEN "I2C:0x48" FOR INPUT AS #1
    20 GET #1, T$, 2
    30 TEMP = CVI(T$) / 256.0
    40 PRINT "Temperature: "; TEMP; " C"
    50 CLOSE #1

24.3  SPI Flash / SD Card Module
---------------------------------------------------------------------

  SPI devices are block-oriented.  The VDev uses:
    dev_read/dev_write for sector transfers
    dev_seek for sector positioning
    dev_ioctl for chip-select and clock configuration

  static int spi_read(VDev *d, void *buf, int len)
  {
      SPIDevice *spi = (SPIDevice *)d->user_data;
  #ifdef __linux__
      struct spi_ioc_transfer tr;
      memset(&tr, 0, sizeof(tr));
      tr.rx_buf = (unsigned long)buf;
      tr.len = len;
      tr.speed_hz = spi->speed;
      ioctl(spi->fd, SPI_IOC_MESSAGE(1), &tr);
  #endif
      return len;
  }

  From BASIC:
    MODULE "SPI"
    10 OPEN "SPI0:" FOR BINARY AS #1
    20 IOCTL #1, 5, 0               ' Chip-select 0
    30 GET #1, SECTOR$, 512         ' Read 512-byte sector
    40 CLOSE #1

25. FUTUREPROOFING CHECKLIST
=====================================================================

When writing a new device module, verify:

  [ ] dev_class is set (not VDCLASS_UNKNOWN)
  [ ] dev_caps accurately describes capabilities
  [ ] dev_description is human-readable
  [ ] dev_req_caps matches what security should check
  [ ] Binary devices implement dev_read/dev_write
  [ ] Configurable devices implement dev_ioctl
  [ ] Event-driven devices implement dev_poll
  [ ] Stateful devices implement dev_status
  [ ] dev_close releases all resources
  [ ] Error returns are -1 (not 0 for failure)
  [ ] Works on at least 2 platforms (or stubs gracefully)
  [ ] Module declares correct CAP_ flags
