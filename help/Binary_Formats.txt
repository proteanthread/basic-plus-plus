BASIC++ v6.5.2 BINARY FORMATS SPECIFICATION

The technical reference for program storage formats, tokenized GW-BASIC
binary files, compiled bytecode structures, and VM state persistence
in BASIC++.


1. ASCII PROGRAM SOURCE FILES (.BAS, .BPP)

The standard program format is plain ASCII text:
- Each line starts with an optional line number followed by statement text.
- Lines terminate with standard CRLF (Windows) or LF (Unix).
- Encoding is UTF-8 on modern platforms and 7-bit ASCII on FreeDOS builds.
- SAVE "FILE.BAS", A writes source text in plain ASCII. LOAD "FILE.BAS" loads
  it back.
- The .bpp extension designates extended BASIC++ programs utilizing modern
  language features.


2. PROTECTED PROGRAM FILES (SAVE ..., P)

SAVE "PROGRAM.BAS", P saves programs in an obfuscated binary format:
- The source text is encrypted with a reversible bitwise mask.
- LIST and EDIT commands are disabled on protected files.
- LOAD decrypts protected files transparently into execution memory.


3. TOKENIZED GW-BASIC BINARIES & DETOK TOOL

Historical Microsoft GW-BASIC stored programs as tokenized binary files where
keywords were replaced by single-byte or two-byte token IDs (beginning with
0xFF).

BASIC++ reads tokenized legacy files via the standalone detok utility:

    detok LEGACY.BAS > CLEAN.BAS

detok maps binary token codes back to standard keyword text, emitting clean
ASCII source loadable by any BASIC++ executable.


4. BYTECODE & COMPILED C17 FORMATS

The native compiler (bppc) emits two distinct binary representations:
1. Compact Bytecode (.bpc): Contains file magic header, version, constant
   pool (strings, numbers), and opcode stream (BppOpcode from
   engine/include/types/types.h). Executed directly via the VM stub.
2. Freestanding C17 Source (.c): Emits strictly conforming freestanding ISO
   C17 code containing compiled AST dispatch tables, static string arenas,
   and VM execution stubs.


5. VM STATE PERSISTENCE (STATESAVE / STATELOAD)

- STATESAVE "state.bin": Serializes complete VM execution state to disk
  (variable tables, arrays, string descriptors, GOSUB/FOR stacks).
- STATELOAD "state.bin": Restores the VM context to the exact snapshot point,
  resuming execution seamlessly.
