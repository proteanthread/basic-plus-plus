BASIC++ SYSTEM AND ENVIRONMENT
================================
Version 2.0.0

This guide covers all system, environment, and OS interaction
commands in BASIC++.


EXITING THE INTERPRETER
=========================

BYE / SYSTEM — Exit BASIC++
------------------------------
  BYE              Exit to operating system
  SYSTEM           Same as BYE

Both commands close all open files, release memory, and
return to the OS.  Any unsaved program is lost.


DIALECT MANAGEMENT
====================

DIALECT — Switch BASIC Dialect
--------------------------------
BASIC++ supports 16 built-in BASIC dialects:

  DIALECT "GWBS"     GW-BASIC (default)
  DIALECT "QBAS"     QBasic
  DIALECT "PATB"     Palo Alto Tiny BASIC
  DIALECT "TRS1"     TRS-80 Level I
  DIALECT "TRS2"     TRS-80 Level II
  DIALECT "AINT"     Applesoft Integer BASIC
  DIALECT "ASFT"     Applesoft Floating-Point BASIC
  DIALECT "ATRI"     Atari BASIC
  DIALECT "C64B"     Commodore 64 BASIC
  DIALECT "COCO"     TRS-80 Color Computer
  DIALECT "EC55"     ECMA-55 Minimal BASIC
  DIALECT "E116"     ECMA-116 Full BASIC
  DIALECT "MBAS"     Microsoft MBASIC (CP/M)
  DIALECT "SINC"     Sinclair ZX Spectrum BASIC
  DIALECT "SBLQ"     Sinclair QL SuperBASIC
  DIALECT "SBAS"     Tymshare SUPER BASIC

Without arguments, DIALECT prints the current dialect:

  DIALECT
  Current dialect: GWBS (GW-BASIC)

DIALECT$ — Read Current Dialect Name
---------------------------------------
  PRINT DIALECT$     ' prints "GWBS"
  IF DIALECT$ = "PATB" THEN PRINT "Tiny BASIC mode"

DIALECT$ is a read-only string variable.


DIRECTORY AND FILE MANAGEMENT
===============================

FILES / DIR — List Directory Contents
----------------------------------------
  FILES              List all files in current directory
  FILES "*.BAS"      List matching files
  DIR                Same as FILES (shorter form)
  DIR "*.BAS"        DIR with pattern

CHDIR — Change Current Directory
-----------------------------------
  CHDIR "C:\GAMES"
  CHDIR ".."         Go up one directory

MKDIR — Create a Directory
-----------------------------
  MKDIR "newdir"

RMDIR — Remove a Directory
-----------------------------
  RMDIR "olddir"     Directory must be empty

KILL / SCRATCH — Delete a File
---------------------------------
  KILL "temp.dat"
  SCRATCH "temp.dat"   SCRATCH is a SBASIC alias for KILL

NAME / RENAME — Rename a File
--------------------------------
  NAME "old.bas" AS "new.bas"     GW-BASIC syntax
  RENAME "old.bas", "new.bas"     Alternative syntax


SHELL AND OS COMMANDS
=======================

SHELL — Execute OS Command
-----------------------------
  SHELL "dir"              Run command, wait for completion
  SHELL "notepad file.txt" Open Notepad

SHELL pauses BASIC++ until the command finishes.

SHELL$ — Capture Command Output
----------------------------------
  A$ = SHELL$("date /t")
  PRINT A$                 ' prints today's date

SHELL$ runs the command and returns its STDOUT as a string.

EXEC — Fire-and-Forget Command
---------------------------------
  EXEC "notepad"

EXEC launches the command without waiting for it to finish.
BASIC++ continues executing immediately.

ERRORLEVEL — Last Shell Exit Code
------------------------------------
  SHELL "command"
  PRINT ERRORLEVEL         ' 0 = success, nonzero = error


ENVIRONMENT VARIABLES
=======================

ENVIRON$ — Read Environment Variable
---------------------------------------
  A$ = ENVIRON$("PATH")
  A$ = ENVIRON$("HOME")
  A$ = ENVIRON$("USERNAME")

Returns the value of the named variable, or empty string
if not found.

ENVIRON — Set Environment Variable
-------------------------------------
  ENVIRON "MYVAR=hello"

Sets an environment variable for the current process.


TIME AND DATE
===============

TIME$ — Current Time String
------------------------------
  PRINT TIME$         ' prints "14:30:45"

Format: HH:MM:SS (24-hour).

DATE$ — Current Date String
------------------------------
  PRINT DATE$         ' prints "06-11-2026"

Format: MM-DD-YYYY.

TIMER — Seconds Since Midnight
---------------------------------
  PRINT TIMER          ' prints 52245.123

Returns a floating-point value.  Useful for timing:

  T = TIMER
  ' ... do work ...
  PRINT "Elapsed:"; TIMER - T; "seconds"

CLOCK$ — Full Timestamp
--------------------------
  PRINT CLOCK$         ' prints "2026-06-11 14:30:45"

Format: YYYY-MM-DD HH:MM:SS.

ALARM$ — Get/Set Alarm Time
------------------------------
  ALARM$ = "23:00:00"
  PRINT ALARM$

(Alarm is advisory only; no interrupt is generated.)


PROGRAM CHAINING
==================

CHAIN — Load and Run Another Program
---------------------------------------
  CHAIN "next.bas"

CHAIN loads the named program and runs it.  By default,
all variables are cleared.

COMMON — Share Variables with CHAIN
--------------------------------------
  COMMON A, B$, C()

Variables listed in COMMON are preserved across CHAIN.
Both the calling and called program must declare the same
COMMON variables.

CHAIN with COMMON example:

  Program 1 (main.bas):
    10 A = 42
    20 B$ = "Hello"
    30 COMMON A, B$
    40 CHAIN "part2.bas"

  Program 2 (part2.bas):
    10 COMMON A, B$
    20 PRINT A, B$     ' prints 42  Hello


SECURITY LEVELS
=================

SECURITY — Set Execution Restrictions
----------------------------------------
  SECURITY 0             OPEN: no restrictions
  SECURITY 1             STANDARD: limited file/shell access
  SECURITY 2             RESTRICTED: no file, shell, or POKE

  SECURITY "OPEN"        Same as SECURITY 0
  SECURITY "STANDARD"    Same as SECURITY 1
  SECURITY "RESTRICTED"  Same as SECURITY 2

  SECURITY LEVEL 1       Alternative syntax

Security is a ONE-WAY RATCHET: you can increase the level
but never decrease it within a session.  This prevents
untrusted code from escaping restrictions.


SLEEP — Pause Execution
=========================

  SLEEP              Pause until keypress
  SLEEP 5            Pause for 5 seconds

SLEEP pauses program execution.  With no argument, it
waits for a keypress.  With a numeric argument, it waits
for the specified number of seconds.


MODULE MANAGEMENT
==================

MODULE — Activate or List Modules
------------------------------------
  MODULE "STDLIB"        Activate standard library module
  MODULE "FUJINET"       Activate FujiNet network module
  MODULE "USB"           Activate USB device module
  MODULE                 List loaded modules

Modules add additional functions, statements, and virtual
devices to the interpreter.  See External_Modules.txt for
full module documentation.


SYSTEM INFORMATION
====================

INFO — Display System State
------------------------------
  INFO

Prints current interpreter state: version, dialect, security
level, loaded modules, memory usage, and platform info.

VER — Display Version
------------------------
  VER

Prints the BASIC++ version string.

SYSTEM — Query Platform Info
------------------------------
  A$ = SYSTEM("OS")        ' "Windows", "Linux", "macOS"
  A$ = SYSTEM("ARCH")      ' "x86_64", "x86", "arm"
  A$ = SYSTEM("VERSION")   ' "2.0.0"
