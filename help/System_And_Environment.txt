==============================================================================
BASIC++ v6.5.2 SYSTEM & ENVIRONMENT ARCHITECTURE
==============================================================================

The authoritative specification for environment variables, command-line
arguments, system clocks, memory inspection, and virtual hardware access
in BASIC++ v6.5.2.


1. OPERATING SYSTEM ENVIRONMENT & ARGUMENTS

BASIC++ provides direct, portable access to host OS environment:

* ENVIRON$("VARIABLE"): Returns value of environment variable, or empty
  string if undefined.
* ENVIRON "VAR=VALUE": Sets or exports an environment variable in active
  process environment.
* COMMAND$: Returns raw command-line argument string passed to script.


2. SYSTEM CLOCK, DATE, AND HIGH-RESOLUTION TIMERS

* DATE$: Returns current host date in MM-DD-YYYY format. Assigning
  DATE$ = "MM-DD-YYYY" sets system date.
* TIME$: Returns current 24-hour clock time in HH:MM:SS format.
  Assigning TIME$ = "HH:MM:SS" sets system clock.
* TIMER: Built-in numeric function returning elapsed seconds since
  midnight with sub-millisecond precision.


3. MEMORY AND HARDWARE ACCESS (VIRTUALIZATION & SAFETY)

In hosted executables (baspp, bpp, bs), direct hardware and physical
memory accesses are safely virtualized within libbios and vmem sandboxes:

* PEEK(address): Reads a byte from virtualized memory at address.
* POKE address, value: Writes byte value to virtualized memory.
* DEF SEG [= segment]: Sets active segment base address for PEEK/POKE.
* INP(port): Reads a byte from virtualized hardware port.
* OUT port, value: Writes byte value to virtualized hardware port.
* FRE(0): Returns remaining free program memory pool size in bytes.


4. PROCESS LIFECYCLE

* SYSTEM [exit_code]: Immediately terminates program execution, reclaims
  VM resources, and returns control to OS with exit_code (default 0).


5. EXAMPLE: ENVIRONMENT AND TIMING INSPECTION

    10 REM System & Environment Demo
    20 PRINT "OS Path:     "; ENVIRON$("PATH")
    30 PRINT "Command arg: "; COMMAND$
    40 PRINT "System Date: "; DATE$; " Time: "; TIME$
    50 Start = TIMER
    60 FOR I = 1 TO 100000 : NEXT I
    70 Elapsed = TIMER - Start
    80 PRINT "Elapsed loop time: "; Elapsed; " seconds"
    90 PRINT "Free memory: "; FRE(0); " bytes"
