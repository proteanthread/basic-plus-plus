CSQR

1. Syntax & Parameters
CSQR(z)

Parameters:
- z: Numeric expression(s).

2. Description & Usage
Returns the square root of a complex number.
Computes the principal square root of z = a + bi.

3. Code Examples
`basic
PRINT CSQR(COMPLEX(-1, 0))
`

4. Internal C-Source Mapping
Implemented in: builtinsmath.c, builtincsqr.

5. Implementation Details
Calculates magnitude r and angle t = atan2(b, a). Returns sqrt(r)(cos(t/2) + isin(t/2)).
Always returns a numeric (float or integer or complex). Ensures type-safety through the BValue API.
If arguments are of incorrect type, standard BASIC++ type conversions or errors apply.
