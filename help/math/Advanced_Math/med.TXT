MED

1. Syntax & Parameters
MED(expression1, expression2, [...])
- expression: A numeric value or variable.

2. Description & Usage
Returns the median (middle value) of a series of numeric expressions. If an even number of arguments is provided, it returns the arithmetic average of the two middle values.
This function operates safely on scalar numbers and handles standard type coercions implicitly.

3. Code Examples
`basic
10 PRINT MED(5, 2, 9)
20 PRINT MED(1, 10, 3, 8)
`

4. Internal C-Source Mapping
Implemented in builtinsmath.c via the builtinmed() function.
This function integrates into the FCAT_MATH built-in registry.

5. Implementation Details
Uses a C89-compatible insertion sort algorithm on a local double array. Max 64 values are allowed due to a fixed buffer size (MEDMAXVALS 64). If more are passed, the parser/evaluator caps it or it will trigger a safety boundary. The result is calculated as vals[n / 2] for odd counts, or (vals[n / 2 - 1] + vals[n / 2]) / 2.0 for even counts.
Troubleshooting: If execution yields a runtime error, verify the memory bounds and that argument parsing aligns with minargs and maxargs constraints in funcreg_add(). Avoid providing null pointers or uninitialized BValues to the handler.
