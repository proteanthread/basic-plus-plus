==============================================================================
BASIC++ v6.5.2 USING ALIASES ARCHITECTURE
==============================================================================

The authoritative specification for keyword aliasing, syntax renaming,
operator re-mapping, and identifier synonyms in BASIC++ v6.5.2.


1. THE ALIAS STATEMENT

The ALIAS statement creates an alternative name for an existing keyword,
statement, function, or operator (engine/src/statements/introspection/
alias.c).

The alias behaves identically to the original keyword: it is an exact
syntactic synonym evaluated through the primary parser dispatch table,
not a text substitution macro. The original keyword remains fully
accessible.


2. SYNTAX AND OPERATIONS

A. Keyword Aliasing:
    ALIAS new_name = original_keyword

Creates new_name as a synonym for original_keyword. Both identifiers are
case-insensitive.

B. Operator Aliasing:
    ALIAS OPER new_op = original_op

Maps an alternative operator token to an existing operator.

C. Alias Management:
* ALIAS LIST: Displays all currently active alias mappings.
* ALIAS CLEAR: Removes all user-defined aliases and restores defaults.


3. PROTECTED SYSTEM KEYWORDS

To prevent unrecoverable VM corruption, core control flow and
introspection keywords cannot be aliased or overridden:

* SCOPE, ALIAS, KEYWORD, OVERRIDE
* REM, END, STOP, NEW, RUN, CLEAR

Attempting to redefine any protected keyword generates Error 13:
Permission Denied.


4. USE CASES

* Natural Language Localization: French, Spanish, or German synonyms.
* Dialect Parity: Mapping vintage dialect synonyms (e.g., CLS to HOME).
* Shorthand Typing: Creating concise shortcuts for interactive commands.


5. EXAMPLE: KEYWORD SYNONYMS

    10 REM Alias Statement Demo
    20 ALIAS DISPLAY = PRINT
    30 ALIAS ASK = INPUT
    40 DISPLAY "Hello from aliased DISPLAY statement!"
    50 ASK "Enter your name: ", UserName$
    60 DISPLAY "Welcome, "; UserName$
    70 ALIAS CLEAR
