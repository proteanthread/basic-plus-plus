NWRITE Statement Reference
======================================================================

The NWRITE statement transmits a raw binary or text payload from a
string expression over an active network socket I/O channel.


SYNTAX
----------------------------------------------------------------------

    NWRITE channel%, payload_string$


PARAMETERS
----------------------------------------------------------------------

  channel%        - Active network socket channel number (1..16).
  payload_string$ - String expression containing data to send.


CODE EXAMPLES
----------------------------------------------------------------------

    10 OPEN "TCP:example.com:80" AS #1
    20 Req$ = "GET / HTTP/1.1" + CHR$(13) + CHR$(10) + _
              "Host: example.com" + CHR$(13) + CHR$(10) + _
              "Connection: close" + CHR$(13) + CHR$(10) + CHR$(13) + CHR$(10)
    30 NWRITE 1, Req$
    40 WHILE NOT NEOF(1)
    50     PRINT NREAD$(1, 512);
    60 WEND
    70 CLOSE #1


ENGINE IMPLEMENTATION (vnet.c)
----------------------------------------------------------------------

In engine/src/server/vnet.c:
  Calls native send() on the socket handle, handling partial writes.
