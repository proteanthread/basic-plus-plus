NCONNECTED Function Reference
======================================================================

The NCONNECTED built-in function returns a boolean flag indicating
whether a network socket I/O channel is currently connected.


SYNTAX
----------------------------------------------------------------------

    is_connected% = NCONNECTED(channel%)


PARAMETERS & RETURN VALUE
----------------------------------------------------------------------

  channel% - Active network socket channel number (1..16).
  - Returns -1 (true) if socket is connected.
  - Returns 0 (false) if disconnected, closed, or resetting.


CODE EXAMPLES
----------------------------------------------------------------------

    10 OPEN "TCP:game.server.local:7777" AS #1
    20 IF NCONNECTED(1) THEN PRINT "Connected!"
    30 CLOSE #1
