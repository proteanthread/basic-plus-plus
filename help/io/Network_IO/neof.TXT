NEOF Function Reference
======================================================================

The NEOF built-in function returns a boolean flag indicating whether
the remote endpoint of a network socket channel has closed the stream.


SYNTAX
----------------------------------------------------------------------

    is_eof% = NEOF(channel%)


PARAMETERS & RETURN VALUE
----------------------------------------------------------------------

  channel% - Active network socket channel number (1..16).
  - Returns -1 (true) if stream is closed/terminated by remote peer.
  - Returns 0 (false) while stream remains open.


CODE EXAMPLES
----------------------------------------------------------------------

    10 OPEN "HTTP://api.example.com/data.txt" AS #1
    20 WHILE NOT NEOF(1)
    30     PRINT NREAD$(1, 256);
    40 WEND
    50 CLOSE #1


ENGINE IMPLEMENTATION (vnet.c)
----------------------------------------------------------------------
