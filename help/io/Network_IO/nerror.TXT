NERROR Function Reference
======================================================================

The NERROR built-in function returns the operating system socket error
code encountered by an active network I/O channel.


SYNTAX
----------------------------------------------------------------------

    err_code% = NERROR(channel%)


PARAMETERS & RETURN VALUE
----------------------------------------------------------------------

  channel% - Active network socket channel number (1..16).
  - Returns raw OS socket error code (WSAGetLastError() / errno), or 0.


CODE EXAMPLES
----------------------------------------------------------------------

    10 OPEN "TCP:127.0.0.1:9999" AS #1
    20 IF NOT NCONNECTED(1) THEN
    30     PRINT "Socket Error: "; NERROR(1)
    40 END IF
    50 CLOSE #1


ENGINE IMPLEMENTATION (vnet.c)
----------------------------------------------------------------------

In engine/src/server/vnet.c:
  Retrieves stored WSAGetLastError() or errno from VNetChannelContext.
