NJSONQUERY_STR

1. Syntax & Parameters
val$ = NJSONQUERY$(jsonstring$, jsonpath$)

2. Description & Usage
Extracts a specific value from a JSON string using a path query. Highly useful for processing REST API responses directly in BASIC++. Edge Cases: If the JSON is malformed or the path doesn't exist, returns an empty string.

3. Code Examples
`basic
10 DATA$ = "{\"user\": \"admin\"}"
20 PRINT NJSONQUERY$(DATA$, "user")
`

4. Internal C-Source Mapping
Mapped in source/io/builtinsnet.c via builtinnjsonquery_str().

5. Implementation Details
Parser Expectation: Two string arguments. Returns String. Mutability: Mutates String Pool. Execution Path: Feeds the string payload into the internal lightweight JSON parser, traverses the AST based on the path, and returns the leaf node as a string. Troubleshooting: Remember to escape double quotes in string literals when defining JSON manually.
