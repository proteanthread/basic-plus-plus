NJSONQUERY$ Function Reference
======================================================================

The NJSONQUERY$ built-in string function parses and queries structured
JSON data received over a network I/O channel using a JSONPath query.


SYNTAX
----------------------------------------------------------------------

    field_val$ = NJSONQUERY$(channel%, json_path$)


PARAMETERS & RETURN VALUE
----------------------------------------------------------------------

  channel%   - Active network socket channel number (1..16).
  json_path$ - JSONPath query string (e.g. "status", "user.name").
  - Returns the extracted string value, or "" if not found.


CODE EXAMPLES
----------------------------------------------------------------------

    10 OPEN "HTTP://api.weather.local/current" AS #1
    20 Temp$ = NJSONQUERY$(1, "current.temperature_c")
    30 City$ = NJSONQUERY$(1, "location.city")
    40 PRINT "Weather in "; City$; ": "; Temp$; " C"
    50 CLOSE #1


ENGINE IMPLEMENTATION (vnet.c & json.c)
----------------------------------------------------------------------

In engine/src/server/vnet.c:
  Parses body into an ephemeral AST node via libserver/json.c and
  resolves the path without keeping intermediate DOM trees.
