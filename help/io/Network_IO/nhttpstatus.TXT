NHTTPSTATUS Function Reference
======================================================================

The NHTTPSTATUS built-in function returns the HTTP/HTTPS response status
code received from a remote web server on an active network channel.


SYNTAX
----------------------------------------------------------------------

    http_code% = NHTTPSTATUS(channel%)


COMMON HTTP STATUS CODES
----------------------------------------------------------------------

  200: OK (Success)
  301: Moved Permanently
  400: Bad Request
  401: Unauthorized
  404: Not Found
  500: Internal Server Error


CODE EXAMPLES
----------------------------------------------------------------------

    10 OPEN "HTTP://api.example.com/status" AS #1
    20 Status% = NHTTPSTATUS(1)
    30 IF Status% = 200 THEN PRINT "Success!"
    40 CLOSE #1


ENGINE IMPLEMENTATION (vnet.c)
----------------------------------------------------------------------

In engine/src/server/vnet.c:
  Parses the HTTP response status line (HTTP/1.1 200 OK) and returns
  the parsed integer status code.
