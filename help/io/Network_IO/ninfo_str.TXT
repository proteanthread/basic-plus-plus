NINFO$ Function Reference
======================================================================

The NINFO$ built-in string function queries connection metadata
(remote IP, port numbers, protocol) from an active network channel.


SYNTAX
----------------------------------------------------------------------

    info_val$ = NINFO$(channel%, property_name$)


PROPERTIES
----------------------------------------------------------------------

  "PEER_IP"    - Remote host IP address string (e.g. "192.168.1.50").
  "PEER_PORT"  - Remote host port number string (e.g. "8080").
  "LOCAL_IP"   - Local bound interface IP string.
  "LOCAL_PORT" - Local bound port number string.
  "PROTOCOL"   - Protocol string (TCP, UDP, HTTP, HTTPS).


CODE EXAMPLES
----------------------------------------------------------------------

    10 OPEN "TCP:SERVER:9000" AS #1
    20 PRINT "Peer: "; NINFO$(1, "PEER_IP"); ":"; NINFO$(1, "PEER_PORT")
    30 CLOSE #1


ENGINE IMPLEMENTATION (vnet.c)
----------------------------------------------------------------------

In engine/src/server/vnet.c:
  Calls getpeername() / getsockname() and formats via inet_ntop().


ERROR CODES
----------------------------------------------------------------------

  Error Code  Name                  Condition
  ----------  --------------------  ----------------------------------
  5           ERR_ILLEGAL_FUNCTION  Unrecognized property name
  52          ERR_BAD_FILE_NUMBER   Channel not open
