NBYTESWAITING Function Reference
======================================================================

The NBYTESWAITING built-in function returns the number of unread bytes
currently buffered and waiting in a network socket channel.


SYNTAX
----------------------------------------------------------------------

    bytes_available% = NBYTESWAITING(channel%)


PARAMETERS & RETURN VALUE
----------------------------------------------------------------------

  channel% - Active network socket channel number (1..16).
  - Returns number of bytes ready to read without blocking.


CODE EXAMPLES
----------------------------------------------------------------------

    10 OPEN "TCP:127.0.0.1:8080" AS #1
    20 DO
    30     Avail% = NBYTESWAITING(1)
    40     IF Avail% > 0 THEN PRINT "Data: "; NREAD$(1, Avail%)
    50     _DELAY 0.05
    60 LOOP UNTIL NEOF(1)
    70 CLOSE #1


ENGINE IMPLEMENTATION (vnet.c)
----------------------------------------------------------------------

In engine/src/server/vnet.c:
  Invokes ioctl(FIONREAD) / ioctlsocket(FIONREAD) on the native socket.
