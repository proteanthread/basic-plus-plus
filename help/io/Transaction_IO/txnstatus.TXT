TXNSTATUS Function Reference
======================================================================

The TXNSTATUS built-in function returns the lifecycle status code of
an active atomic transaction.


SYNTAX
----------------------------------------------------------------------

    txn_state% = TXNSTATUS(transaction_id%)


TRANSACTION STATE CODES
----------------------------------------------------------------------

  0: INACTIVE  - Unallocated or closed
  1: ACTIVE    - In-flight / mutations buffered
  2: COMMITTED - Successfully committed to disk
  3: ABORTED   - Rolled back / aborted


CODE EXAMPLES
----------------------------------------------------------------------

    10 Txn% = 1
    20 State% = TXNSTATUS(Txn%)
    30 IF State% = 1 THEN PRINT "In progress..."


ENGINE IMPLEMENTATION (kv.c & eval_builtins.c)
----------------------------------------------------------------------

In engine/src/server/kv.c:
  Queries state enum in KVTransactionContext.


ERROR CODES
----------------------------------------------------------------------

  Error Code  Name                  Condition
  ----------  --------------------  ----------------------------------
  5           ERR_ILLEGAL_FUNCTION  Transaction ID out of range
