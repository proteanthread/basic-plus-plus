BIOFILL Statement Reference
======================================================================

The BIOFILL statement populates a contiguous byte range of a block I/O
channel or virtual device buffer with a specified constant byte value.


SYNTAX
----------------------------------------------------------------------

    BIOFILL channel%, offset&, length&, byte_value%


PARAMETERS
----------------------------------------------------------------------

  channel%    - Active block channel number (1..16).
  offset&     - Starting byte offset (0-based).
  length&     - Number of bytes to fill.
  byte_value% - Integer byte value (0..255).


CODE EXAMPLES
----------------------------------------------------------------------

    10 OPEN "disk.img" FOR BLOCK AS #1
    20 BIOFILL 1, 0, 512, 0
    30 CLOSE #1


ENGINE IMPLEMENTATION (vdev.c)
----------------------------------------------------------------------

In engine/src/device/vdev.c:
  Executes direct memset() across the mapped channel buffer.


ERROR CODES
----------------------------------------------------------------------

  Error Code  Name                  Condition
  ----------  --------------------  ----------------------------------
  5           ERR_ILLEGAL_FUNCTION  byte_value not in 0..255
  52          ERR_BAD_FILE_NUMBER   Channel not open
