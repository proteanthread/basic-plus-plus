BIOCHECKSUM Function Reference
======================================================================

The BIOCHECKSUM built-in function calculates an integer CRC32 or
Adler32 checksum over a specified byte range of a binary block I/O
channel or virtual block device.


SYNTAX
----------------------------------------------------------------------

    checksum& = BIOCHECKSUM(channel%, offset&, length&)
    checksum& = BIOCHECKSUM(channel%, offset&, length&, algorithm%)


PARAMETERS & ALGORITHMS
----------------------------------------------------------------------

  channel%   - Active block device channel number (1..16).
  offset&    - Starting byte offset (0-based).
  length&    - Contiguous bytes to checksum.
  algorithm% - 0: IEEE 802.3 CRC32 (Default).
               1: Fast Adler-32.


CODE EXAMPLES
----------------------------------------------------------------------

    10 OPEN "firmware.bin" FOR BLOCK AS #1
    20 Size& = BIOSIZE(1)
    30 CRC& = BIOCHECKSUM(1, 0, Size&, 0)
    40 PRINT "Firmware CRC32: &H"; HEX$(CRC&)
    50 CLOSE #1


ENGINE IMPLEMENTATION (vdev.c & crypto.c)
----------------------------------------------------------------------

In engine/src/device/vdev.c:
  Reads channel memory directly via vdev_read_block() and computes
  hash via crypto_crc32() without intermediate string copies.


ERROR CODES
----------------------------------------------------------------------

  Error Code  Name                  Condition
  ----------  --------------------  ----------------------------------
  5           ERR_ILLEGAL_FUNCTION  Invalid algorithm or negative offset
  52          ERR_BAD_FILE_NUMBER   Channel not open or not block mode
