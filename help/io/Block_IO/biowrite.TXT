BIOWRITE Statement Reference
======================================================================

The BIOWRITE statement writes a raw binary byte payload from a string
expression directly into a block I/O channel at a specified offset.


SYNTAX
----------------------------------------------------------------------

    BIOWRITE channel%, offset&, byte_data$


PARAMETERS
----------------------------------------------------------------------

  channel%   - Active block channel number (1..16).
  offset&    - Starting destination byte offset (0-based).
  byte_data$ - String expression containing binary payload to write.


CODE EXAMPLES
----------------------------------------------------------------------

    10 OPEN "disk.img" FOR BLOCK AS #1
    20 Sig$ = CHR$(&H55) + CHR$(&HAA)
    30 BIOWRITE 1, 510, Sig$
    40 CLOSE #1


ENGINE IMPLEMENTATION (vdev.c)
----------------------------------------------------------------------

In engine/src/device/vdev.c:
  Invokes vdev_write_block() to write bytes directly to block storage.


ERROR CODES
----------------------------------------------------------------------

  Error Code  Name                  Condition
  ----------  --------------------  ----------------------------------
  52          ERR_BAD_FILE_NUMBER   Channel not open
  70          ERR_PERMISSION_DENIED Medium is write-protected
