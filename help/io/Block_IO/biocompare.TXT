BIOCOMPARE Function Reference
======================================================================

The BIOCOMPARE built-in function performs a fast byte-by-byte comparison
between two block I/O channels or virtual device memory buffers.


SYNTAX
----------------------------------------------------------------------

    diff% = BIOCOMPARE(chan1%, offset1&, chan2%, offset2&, length&)


PARAMETERS & RETURN VALUE
----------------------------------------------------------------------

  chan1%, chan2%     - Active block channel numbers (1..16).
  offset1&, offset2& - Starting byte offsets in each channel.
  length&            - Number of contiguous bytes to compare.
  - Returns 0 if identical, or non-zero byte difference on mismatch.


CODE EXAMPLES
----------------------------------------------------------------------

    10 OPEN "master.img" FOR BLOCK AS #1
    20 OPEN "backup.img" FOR BLOCK AS #2
    30 Diff% = BIOCOMPARE(1, 0, 2, 0, 512)
    40 IF Diff% = 0 THEN PRINT "Match!"
    50 CLOSE #1 : CLOSE #2


ENGINE IMPLEMENTATION (vdev.c)
----------------------------------------------------------------------

In engine/src/device/vdev.c:
  Executes direct memcmp() across mapped channel buffers.
