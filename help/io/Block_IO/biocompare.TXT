BIOCOMPARE

1. Syntax & Parameters
result = BIOCOMPARE(device1id, device2id, num_bytes)

2. Description & Usage
Performs a high-speed, byte-by-byte comparison between two block devices or memory buffers up to numbytes. It is highly optimized for verifying data integrity, disk cloning validation, or memory bank comparisons without having to stream the data into BASIC++ variables first. Edge Cases: If numbytes exceeds the boundary of either device, the interpreter will truncate the comparison to the smallest available boundary. If device IDs are invalid, it throws a Device Not Ready error.

3. Code Examples
`basic
10 REM Verify disk sector clone
20 RESULT = BIOCOMPARE(1, 2, 512)
30 IF RESULT = 0 THEN PRINT "CLONE PERFECT" ELSE PRINT "DATA MISMATCH"
`

4. Internal C-Source Mapping
Mapped in source/io/builtinsblock.c via builtinbiocompare(). Registered in builtins.c.

5. Implementation Details
Parser Expectation: Evaluates two integer device IDs and an integer byte count. Mutability: Strictly read-only operation; neither device is mutated. Execution Path: Bypasses string pool and directly maps to memcmp over the Virtual Device (VDev) buffer pointers. Troubleshooting: If it always returns mismatch, ensure the read cursors for both devices are properly reset via BIOSEEK before comparison.

8. Manual Testing Guide
1. Launch basicpp-console.exe.
2. Open two block devices (e.g. memory banks) as device 1 and 2.
3. Write identical data to both.
4. Run PRINT BIOCOMPARE(1, 2, 256).
5. Verify output is 0.
