BIOREAD$ Function Reference
======================================================================

The BIOREAD$ built-in string function reads a raw binary byte block
from a block I/O channel directly into a string expression.


SYNTAX
----------------------------------------------------------------------

    block_data$ = BIOREAD$(channel%, offset&, length&)


PARAMETERS & RETURN VALUE
----------------------------------------------------------------------

  channel% - Active block channel number (1..16).
  offset&  - Starting byte offset (0-based).
  length&  - Number of bytes to read.
  - Returns a string containing the binary payload.


CODE EXAMPLES
----------------------------------------------------------------------

    10 OPEN "disk.vhd" FOR BLOCK AS #1
    20 Header$ = BIOREAD$(1, 0, 8)
    30 IF Header$ = "conectix" THEN PRINT "Valid VHD image header!"
    40 CLOSE #1


ENGINE IMPLEMENTATION (vdev.c & eval_builtins.c)
----------------------------------------------------------------------

In engine/src/device/vdev.c:
  Invokes vdev_read_block() and packages the buffer directly into a
  reference-counted string via str_create_len().


ERROR CODES
----------------------------------------------------------------------

  Error Code  Name                  Condition
  ----------  --------------------  ----------------------------------
  52          ERR_BAD_FILE_NUMBER   Channel not open
  62          ERR_INPUT_PAST_END    Reading past medium bounds


CROSS-REFERENCES
----------------------------------------------------------------------

  - BIOCOPY.md: Direct channel block copy.
