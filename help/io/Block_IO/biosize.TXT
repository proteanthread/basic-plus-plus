BIOSIZE Function Reference
======================================================================

The BIOSIZE built-in function returns the total storage capacity or
file size in bytes of an active block I/O channel.


SYNTAX
----------------------------------------------------------------------

    size_in_bytes& = BIOSIZE(channel%)


PARAMETERS & RETURN VALUE
----------------------------------------------------------------------

  channel% - Active block channel number (1..16).
  - Returns total byte capacity of the block medium.


CODE EXAMPLES
----------------------------------------------------------------------

    10 OPEN "floppy.img" FOR BLOCK AS #1
    20 TotalBytes& = BIOSIZE(1)
    30 PRINT "Total: "; TotalBytes&; " bytes ("; TotalBytes& / 512; " sectors)"
    40 CLOSE #1


ENGINE IMPLEMENTATION (vdev.c)
----------------------------------------------------------------------

In engine/src/device/vdev.c:
  Calls vdev_get_block_size(vdev, channel) from the VDev bus.


ERROR CODES
----------------------------------------------------------------------

  Error Code  Name                  Condition
  ----------  --------------------  ----------------------------------
  52          ERR_BAD_FILE_NUMBER   Channel not open
