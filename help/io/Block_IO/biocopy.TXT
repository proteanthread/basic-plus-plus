BIOCOPY Statement Reference
======================================================================

The BIOCOPY statement executes a high-speed direct block memory transfer
between two block I/O channels or virtual devices.


SYNTAX
----------------------------------------------------------------------

    BIOCOPY src_chan%, src_off&, dst_chan%, dst_off&, length&


PARAMETERS
----------------------------------------------------------------------

  src_chan%, dst_chan% - Open block channel numbers (1..16).
  src_off&, dst_off&   - Starting byte offsets in channels.
  length&              - Number of bytes to copy.


CODE EXAMPLES
----------------------------------------------------------------------

    10 OPEN "source.img" FOR BLOCK AS #1
    20 OPEN "target.img" FOR BLOCK AS #2
    30 BIOCOPY 1, 0, 2, 0, 512
    40 CLOSE #1 : CLOSE #2


ENGINE IMPLEMENTATION (vdev.c)
----------------------------------------------------------------------

In engine/src/device/vdev.c:
  Uses optimized memcpy() between device memory contexts.
