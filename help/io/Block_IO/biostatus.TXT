BIOSTATUS Function Reference
======================================================================

The BIOSTATUS built-in function queries the hardware status, readiness
flags, and error state bitmask of an active block I/O channel.


SYNTAX
----------------------------------------------------------------------

    status_mask% = BIOSTATUS(channel%)


STATUS BITMASK TABLE
----------------------------------------------------------------------

  Bit  Value  Meaning
  ---  -----  -------------------------------------
  --   0      Device Ready / OK
  0    1      Device Busy
  1    2      Write Protected / Read-Only
  2    4      CRC / Data Error
  3    8      Seek Fault / Sector Not Found
  7    128    General Hardware Fault


CODE EXAMPLES
----------------------------------------------------------------------

    10 OPEN "flash.bin" FOR BLOCK AS #1
    20 Status% = BIOSTATUS(1)
    30 IF (Status% AND 2) THEN PRINT "Media is Read-Only!"
    40 CLOSE #1
