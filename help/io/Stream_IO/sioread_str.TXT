SIOREAD$ Function Reference
======================================================================

The SIOREAD$ built-in string function reads a specified maximum number
of bytes from an active stream I/O channel into a string expression.


SYNTAX
----------------------------------------------------------------------

    stream_chunk$ = SIOREAD$(channel%, byte_count%)


PARAMETERS & RETURN VALUE
----------------------------------------------------------------------

  channel%   - Active stream channel number (1..16).
  byte_count% - Number of bytes to read.
  - Returns a string of length <= byte_count%.


CODE EXAMPLES
----------------------------------------------------------------------

    10 OPEN "binary.dat" FOR INPUT AS #1
    20 Header$ = SIOREAD$(1, 16)
    30 PRINT "Header len: "; LEN(Header$)
    40 CLOSE #1


ENGINE IMPLEMENTATION (vdev.c)
----------------------------------------------------------------------

In engine/src/device/vdev.c:
  Reads directly from stream channel input buffer.


ERROR CODES
----------------------------------------------------------------------

  Error Code  Name                  Condition
  ----------  --------------------  ----------------------------------
  52          ERR_BAD_FILE_NUMBER   Channel not open
  62          ERR_INPUT_PAST_END    Reading past end of stream
