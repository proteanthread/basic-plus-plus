SIOSTATUS Function Reference
======================================================================

The SIOSTATUS built-in function returns the operating state and error
flags of an active stream I/O channel.


SYNTAX
----------------------------------------------------------------------

    status% = SIOSTATUS(channel%)


STATUS CODES
----------------------------------------------------------------------

  0: Stream Ready / OK
  1: Stream EOF
  2: Stream Error / Fault


CODE EXAMPLES
----------------------------------------------------------------------

    10 OPEN "device.stream" AS #1
    20 Status% = SIOSTATUS(1)
    30 IF Status% = 0 THEN PRINT "Stream OK!"
    40 CLOSE #1
