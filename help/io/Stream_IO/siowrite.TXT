SIOWRITE Statement Reference
======================================================================

The SIOWRITE statement writes a string or raw binary payload to an
active stream I/O channel.


SYNTAX
----------------------------------------------------------------------

    SIOWRITE channel%, payload_string$


PARAMETERS
----------------------------------------------------------------------

  channel%        - Active stream channel number (1..16).
  payload_string$ - String expression containing data to write.


CODE EXAMPLES
----------------------------------------------------------------------

    10 OPEN "output.txt" FOR OUTPUT AS #1
    20 SIOWRITE 1, "Hello from BASIC++!" + CHR$(10)
    30 SIOFLUSH 1
    40 CLOSE #1


ENGINE IMPLEMENTATION (vdev.c)
----------------------------------------------------------------------

In engine/src/device/vdev.c:
  Writes bytes directly into the stream channel output buffer.


ERROR CODES
----------------------------------------------------------------------

  Error Code  Name                  Condition
  ----------  --------------------  ----------------------------------
  52          ERR_BAD_FILE_NUMBER   Channel not open
  13          ERR_TYPE_MISMATCH     Argument error


CROSS-REFERENCES
