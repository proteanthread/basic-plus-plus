SIOREADLN$ Function Reference
======================================================================

The SIOREADLN$ built-in string function reads a line of text terminated
by a newline (CRLF or LF) from an active stream I/O channel.


SYNTAX
----------------------------------------------------------------------

    line_text$ = SIOREADLN$(channel%)


PARAMETERS & RETURN VALUE
----------------------------------------------------------------------

  channel% - Active stream channel number (1..16).
  - Returns string containing line text without trailing newlines.


CODE EXAMPLES
----------------------------------------------------------------------

    10 OPEN "config.ini" FOR INPUT AS #1
    20 WHILE NOT EOF(1)
    30     PRINT SIOREADLN$(1)
    40 WEND
    50 CLOSE #1


ENGINE IMPLEMENTATION (vdev.c)
----------------------------------------------------------------------

In engine/src/device/vdev.c:
  Scans buffer for \n and returns reference-counted string slice.


ERROR CODES
----------------------------------------------------------------------

  Error Code  Name                  Condition
  ----------  --------------------  ----------------------------------

  62          ERR_INPUT_PAST_END    Reading past end of stream
