SIOAVAIL Function Reference
======================================================================

The SIOAVAIL built-in function returns the number of bytes available
to read from a stream I/O channel without blocking.


SYNTAX
----------------------------------------------------------------------

    bytes_avail% = SIOAVAIL(channel%)


PARAMETERS & RETURN VALUE
----------------------------------------------------------------------

  channel% - Active stream channel number (1..16).
  - Returns number of buffered bytes ready to read.


CODE EXAMPLES
----------------------------------------------------------------------

    10 OPEN "stream.pipe" FOR INPUT AS #1
    20 IF SIOAVAIL(1) > 0 THEN PRINT SIOREADLN$(1)
    30 CLOSE #1


ENGINE IMPLEMENTATION (vdev.c)
----------------------------------------------------------------------

In engine/src/device/vdev.c:
  Returns channel buffer pending count.


ERROR CODES
----------------------------------------------------------------------

  Error Code  Name                  Condition
  ----------  --------------------  ----------------------------------
  52          ERR_BAD_FILE_NUMBER   Channel not open
