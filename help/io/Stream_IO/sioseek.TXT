SIOSEEK Statement Reference
======================================================================

The SIOSEEK statement positions the active read/write file pointer
on a stream I/O channel to a specified byte offset.


SYNTAX
----------------------------------------------------------------------

    SIOSEEK channel%, byte_offset&


PARAMETERS
----------------------------------------------------------------------

  channel%     - Active stream channel number (1..16).
  byte_offset& - Destination byte position (0-based).


CODE EXAMPLES
----------------------------------------------------------------------

    10 OPEN "records.dat" FOR RANDOM AS #1
    20 SIOSEEK 1, 1024
    30 Data$ = SIOREAD$(1, 64)
    40 CLOSE #1


ENGINE IMPLEMENTATION (vdev.c)
----------------------------------------------------------------------

In engine/src/device/vdev.c:
  Invokes fseek() / _fseeki64() on the underlying descriptor.


ERROR CODES
----------------------------------------------------------------------

  Error Code  Name                  Condition
  ----------  --------------------  ----------------------------------
  52          ERR_BAD_FILE_NUMBER   Channel not open
  5           ERR_ILLEGAL_FUNCTION  Negative offset
