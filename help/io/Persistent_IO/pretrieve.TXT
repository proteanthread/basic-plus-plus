PRETRIEVE Function Reference
======================================================================

The PRETRIEVE built-in numeric function retrieves a persistent numeric
value associated with a string key from the key-value store.


SYNTAX
----------------------------------------------------------------------

    value# = PRETRIEVE(key_string$)


PARAMETERS & RETURN VALUE
----------------------------------------------------------------------

  key_string$ - String expression specifying lookup key.
  - Returns numeric value stored under key, or 0 if not found.


CODE EXAMPLES
----------------------------------------------------------------------

    10 HighScore# = PRETRIEVE("game.highscore")
    20 PRINT "Current High Score: "; HighScore#


ENGINE IMPLEMENTATION (kv.c & eval_builtins.c)
----------------------------------------------------------------------

In engine/src/server/kv.c:
  Executes hash table lookup in the global persistent store.


ERROR CODES
----------------------------------------------------------------------

  Error Code  Name                  Condition
  ----------  --------------------  ----------------------------------
  13          ERR_TYPE_MISMATCH     Argument is non-string
