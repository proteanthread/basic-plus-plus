PSTORE Statement Reference
======================================================================

The PSTORE statement stores a numeric or string value associated with
a key in the persistent key-value store.


SYNTAX
----------------------------------------------------------------------

    PSTORE key_string$, value_expression


PARAMETERS
----------------------------------------------------------------------

  key_string$      - String expression specifying destination key.
  value_expression - Numeric or string value to store.


CODE EXAMPLES
----------------------------------------------------------------------

    10 PSTORE "game.highscore", 99500
    20 PSTORE "game.playername", "Alice"
    30 PRINT "Saved."


ENGINE IMPLEMENTATION (stmt_pstore.c & kv.c)
----------------------------------------------------------------------

In engine/src/statements/io/stmt_pstore.c:
  Evaluates key and value, then calls kv_set() in libserver.


ERROR CODES
----------------------------------------------------------------------

  Error Code  Name                  Condition
  ----------  --------------------  ----------------------------------
  13          ERR_TYPE_MISMATCH     Key is non-string
