PRETRIEVE$ Function Reference
======================================================================

The PRETRIEVE$ built-in string function retrieves a persistent string
value associated with a string key from the key-value store.


SYNTAX
----------------------------------------------------------------------

    value_str$ = PRETRIEVE$(key_string$)


PARAMETERS & RETURN VALUE
----------------------------------------------------------------------

  key_string$ - String expression specifying lookup key.
  - Returns string value stored under key, or "" if not found.


CODE EXAMPLES
----------------------------------------------------------------------

    10 PlayerName$ = PRETRIEVE$("player.name")
    20 IF PlayerName$ = "" THEN PlayerName$ = "Guest"
    30 PRINT "Welcome back, "; PlayerName$; "!"


ENGINE IMPLEMENTATION (kv.c & eval_builtins.c)
----------------------------------------------------------------------

In engine/src/server/kv.c:
  Retrieves string payload from hash bucket and returns a
  reference-counted string via str_create().


ERROR CODES
----------------------------------------------------------------------

  Error Code  Name                  Condition
  ----------  --------------------  ----------------------------------
  13          ERR_TYPE_MISMATCH     Argument is non-string
