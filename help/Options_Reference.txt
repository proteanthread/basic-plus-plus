OPTION STATEMENT REFERENCE
============================
Version 1.5.0

The OPTION statement configures interpreter behavior at runtime.
All OPTION sub-commands take effect immediately and persist until
changed, overridden by a dialect switch, or the interpreter exits.


====================================================================
1. OPTION BASE
====================================================================

Syntax:
  OPTION BASE 0
  OPTION BASE 1

Sets the default lower bound for array subscripts created with DIM.

  OPTION BASE 0    (default)
    DIM A(10) creates elements A(0) through A(10) — 11 elements.

  OPTION BASE 1
    DIM A(10) creates elements A(1) through A(10) — 10 elements.

OPTION BASE must be set BEFORE any DIM statement. Changing it
after arrays are dimensioned does not resize existing arrays.

This corresponds to ECMA-55 and ECMA-116 standard BASIC behavior.

Example:
  OPTION BASE 1
  DIM Scores(5)
  FOR I = 1 TO 5
    Scores(I) = I * 10
  NEXT I


====================================================================
2. OPTION STRICT
====================================================================

Syntax:
  OPTION STRICT          Enable strict mode
  OPTION STRICT ON       Enable strict mode (same)
  OPTION STRICT OFF      Disable strict mode (union mode)

Controls whether keyword filtering is enforced based on the
active dialect.

UNION MODE (default, OPTION STRICT OFF):
  All keywords from ALL 16 dialects are available. A program
  can freely mix GW-BASIC's WHILE/WEND with Commodore's CLR,
  ECMA-116's WHEN EXCEPTION, and SUPER BASIC's UNLESS.

STRICT MODE (OPTION STRICT or OPTION STRICT ON):
  Only keywords that belong to the active dialect's bitmask
  are accepted. Any keyword not native to the current dialect
  raises a WHAT? error.

Example:
  DIALECT "C64B"
  OPTION STRICT
  WHILE I < 10     ' ERROR! WHILE not in Commodore BASIC
  CLR              ' OK — CLR is in Commodore BASIC

  OPTION STRICT OFF
  WHILE I < 10     ' OK — union mode, all keywords accepted

Use OPTION STRICT to verify that a program is compatible with
a specific machine's BASIC.


====================================================================
3. OPTION ANGLE
====================================================================

Syntax:
  OPTION ANGLE DEGREES
  OPTION ANGLE RADIANS

Controls whether trigonometric functions (SIN, COS, TAN, ATN,
ASIN, ACOS) expect and return values in degrees or radians.

RADIANS (default):
  SIN(3.14159) returns approximately 0 (pi radians = 180°)
  ATN(1) returns 0.7854 (pi/4 radians = 45°)

DEGREES:
  SIN(90) returns 1.0 (90 degrees)
  ATN(1) returns 45.0 (45 degrees)

This setting is part of the ECMA-116 Full BASIC standard.

Example:
  OPTION ANGLE DEGREES
  PRINT SIN(90)          ' 1
  PRINT COS(0)           ' 1
  PRINT ATN(1)           ' 45

  OPTION ANGLE RADIANS
  PRINT SIN(3.14159/2)   ' 1
  PRINT ATN(1)           ' 0.7854


====================================================================
4. OPTION TAB
====================================================================

Syntax:
  OPTION TAB REAL
  OPTION TAB SPACES
  OPTION TAB             (show current mode)

Controls how the TAB() function in PRINT statements moves to
a column position.

SPACES (default):
  TAB emits space characters (ASCII 32) to reach the target
  column. This is compatible with all terminals and file output.

REAL:
  TAB emits actual horizontal tab characters (HT, ASCII 9).
  This produces smaller output but depends on the terminal's
  tab stop settings (usually every 8 columns).

Example:
  OPTION TAB SPACES
  PRINT TAB(20); "HERE"     ' 20 spaces then "HERE"

  OPTION TAB REAL
  PRINT TAB(20); "HERE"     ' HT characters then "HERE"


====================================================================
5. OPTION ZONE
====================================================================

Syntax:
  OPTION ZONE n          Set zone width to n columns
  OPTION ZONE 0          Reset to dialect default

Overrides the PRINT comma zone width. When PRINT uses commas
to separate output items, each item is placed at the next
multiple of the zone width.

Default zone widths by dialect:
  PATB:     8 columns
  Atari:   10 columns
  C64B:    10 columns
  GW-BASIC: 14 columns (Microsoft standard)
  Apple:   16 columns
  CoCo:    16 columns

OPTION ZONE lets you override regardless of dialect.

Example:
  OPTION ZONE 20
  PRINT 1, 2, 3
  ' Output: 1                   2                   3

  OPTION ZONE 0
  ' Reset to dialect default (e.g., 14 for GW-BASIC)


====================================================================
6. OPTION ALIASES
====================================================================

Syntax:
  OPTION ALIASES

Displays the current alias system capacity — how many keyword
aliases are defined vs. the maximum allowed.

Output example:
  Alias capacity: 5 / 256

This is a diagnostic command. To manage aliases themselves, use
the ALIAS command:

  ALIAS PRINT = "IMPRIME"     Define an alias
  ALIAS LIST                  List all aliases
  ALIAS CLEAR                 Remove all aliases

See Using_Aliases.txt for complete alias documentation.


====================================================================
7. OPTION KEYWORD
====================================================================

Syntax:
  OPTION KEYWORD UPPER     All keywords stored/displayed uppercase
  OPTION KEYWORD LOWER     All keywords stored/displayed lowercase
  OPTION KEYWORD TITLE     Keywords in Title Case
  OPTION KEYWORD MIXED     Keywords stored as-entered (default)
  OPTION KEYWORD           (show current mode)

Controls how keywords are stored and displayed in LIST output
and error messages.

MIXED (default):
  Keywords are stored exactly as the user types them.
  "print", "PRINT", "Print" are all valid and preserved.

UPPER:
  All keywords are converted to uppercase for storage.
  "print" becomes "PRINT" in LIST output.

LOWER:
  All keywords are converted to lowercase.
  "PRINT" becomes "print" in LIST output.

TITLE:
  Keywords are converted to title case.
  "PRINT" becomes "Print", "GOTO" becomes "Goto".

Example:
  OPTION KEYWORD UPPER
  10 print "hello"
  LIST
  ' Output: 10 PRINT "hello"

Note: OPTION KEYWORD affects LIST output and keyword storage,
not parsing. Keywords are always recognized case-insensitively.


====================================================================
8. OPTION ARITHMETIC
====================================================================

Syntax:
  OPTION ARITHMETIC NATIVE
  OPTION ARITHMETIC DECIMAL

Controls the arithmetic mode as defined by ECMA-116.

NATIVE (default):
  Uses hardware IEEE 754 floating-point arithmetic. This is
  the standard mode for all BASIC++ operations. Fast and
  compatible with all dialects.

DECIMAL:
  Would use base-10 decimal arithmetic for exact representation
  of values like 0.1 and financial calculations. This mode is
  defined in the ECMA-116 standard but is NOT currently
  implemented in BASIC++. Attempting to set DECIMAL mode
  raises a SORRY error.
