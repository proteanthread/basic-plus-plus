IMPLEMENTING OLDER DIALECTS AND MEMORY MAPS
============================================
Version 1.5.0

BASIC++ can emulate classic computer systems by combining its
dialect engine with the MEMMAP virtual memory system.  This
guide explains how to recreate the experience of programming
a Commodore 64, Apple II, Atari 800, or other classic machines.


1. THE MEMMAP SYSTEM
====================

MEMMAP provides a 64 KB virtual address space that mimics the
memory layout of classic computers.  PEEK and POKE read and
write to this virtual memory, just like they did on real hardware.

  MEMMAP "MSDOS"        MS-DOS PC memory map (default)
  MEMMAP "C64"          Commodore 64
  MEMMAP "ATARI8"       Atari 400/800/XL/XE
  MEMMAP "APPLE2"       Apple II / IIe / IIc
  MEMMAP "ZXSPEC"       ZX Spectrum 48K
  MEMMAP "TI99"         TI-99/4A
  MEMMAP "BBC"          BBC Micro
  MEMMAP "MSX"          MSX standard
  MEMMAP "CPC"          Amstrad CPC 464
  MEMMAP "COCO"         TRS-80 CoCo


2. MEMORY MAP DETAILS
=====================

2.1  MS-DOS (MSDOS) -- Default
  $0000-$03FF   Interrupt Vector Table (IVT)
  $0040:$0049   Video mode byte
  $0040:$004A   Screen columns
  $0040:$0062   Active page
  $0400-$9FFF   Conventional memory (free)
  $A000-$BFFF   Video memory segment
  $C000-$EFFF   ROM/adapter area
  $F000-$FFFF   System BIOS

  Key POKEs:
    POKE &H449, mode     Set video mode
    POKE &H44A, cols     Set screen columns
    PEEK(&H417)          Keyboard shift flags

2.2  Commodore 64 (C64)
  $0000-$0001   CPU port (bank switching)
  $0002-$00FF   Zero page
  $0100-$01FF   Stack
  $0200-$03FF   System variables
  $0400-$07FF   Screen memory (1000 characters)
  $0800-$9FFF   BASIC program / free RAM
  $A000-$BFFF   BASIC ROM (8K)
  $C000-$CFFF   Free RAM
  $D000-$D3FF   VIC-II registers
  $D400-$D7FF   SID registers (sound)
  $D800-$DBFF   Color RAM (1000 nybbles)
  $DC00-$DCFF   CIA #1 (keyboard, joystick)
  $DD00-$DDFF   CIA #2 (serial, NMI)
  $E000-$FFFF   Kernal ROM

  Key POKEs:
    POKE 53280, color    Border color (0-15)
    POKE 53281, color    Background color (0-15)
    POKE 1024+pos, ch    Character at screen position
    POKE 55296+pos, col  Color at screen position
    PEEK(56320)          Joystick port 2
    POKE 54296, 15       SID volume maximum

2.3  Atari 8-bit (ATARI8)
  $0000-$00FF   Zero page (OS shadow registers)
  $0100-$01FF   Stack
  $0200-$02FF   OS variables
  $D000-$D0FF   GTIA (graphics)
  $D200-$D2FF   POKEY (sound, keyboard, serial)
  $D300-$D3FF   PIA (ports)
  $D400-$D4FF   ANTIC (display list)

  Key POKEs:
    POKE 710, color      Playfield 2 color
    POKE 712, color      Border color
    POKE 53279, 0        Read console keys
    POKE 559, 0          Turn off display (speed up)

2.4  Apple II (APPLE2)
  $0000-$00FF   Zero page
  $0100-$01FF   Stack
  $0200-$02FF   Input buffer
  $0300-$03FF   DOS vectors
  $0400-$07FF   Text page 1 / Lo-res page 1
  $0800-$0BFF   Text page 2 / Lo-res page 2
  $2000-$3FFF   Hi-res page 1
  $4000-$5FFF   Hi-res page 2
  $C000-$C0FF   I/O soft switches
  $D000-$FFFF   ROM

  Key POKEs:
    PEEK(49152)          Last keypress ($C000)
    POKE 49168, 0        Clear keyboard strobe ($C010)
    PEEK(49200)          Click speaker ($C030)

2.5  ZX Spectrum (ZXSPEC)
  $0000-$3FFF   ROM (16K)
  $4000-$57FF   Screen bitmap (6144 bytes)
  $5800-$5AFF   Screen attributes (768 bytes)
  $5B00-$FFFF   RAM

  Key POKEs:
    POKE 23693, attr     Permanent screen attributes
    POKE 23624, 0        Frame counter

2.6  TI-99/4A (TI99)
  $0000-$1FFF   Console ROM
  $2000-$3FFF   Low memory expansion
  $8000-$83FF   Scratch-pad RAM (256 bytes)
  $8400-$87FF   Sound chip
  $8800-$8BFF   VDP read
  $8C00-$8FFF   VDP write
  $9800-$9BFF   GROM read
  $A000-$FFFF   Expansion

2.7  BBC Micro (BBC)
  $0000-$00FF   Zero page
  $0400-$07FF   OS workspace
  $0E00-$7FFF   User RAM
  $8000-$BFFF   Paged ROM
  $C000-$FBFF   OS ROM
  $FE00-$FEFF   SHEILA (I/O page)
  $FF00-$FFFF   OS vectors

2.8  MSX (MSX)
  $0000-$3FFF   Slot 0 (BIOS ROM)
  $4000-$7FFF   Slot 1 (cartridge)
  $8000-$BFFF   Slot 2
  $C000-$FFFF   Slot 3 (RAM)

2.9  Amstrad CPC (CPC)
  $0000-$3FFF   RAM bank 0 / ROM overlay
  $4000-$7FFF   RAM bank 1
  $8000-$BFFF   RAM bank 2
  $C000-$FFFF   Screen memory / RAM bank 3


3. USING PEEK AND POKE
=======================

  MEMMAP "C64"
  POKE 53280, 0                 ' Black border
  POKE 53281, 6                 ' Blue background
  POKE 1024, 1                  ' 'A' at top-left
  PRINT PEEK(53280)             ' Read border color

  MEMMAP "APPLE2"
  X = PEEK(49152)               ' Check keyboard
  IF X > 127 THEN PRINT CHR$(X AND 127)

The values you POKE are stored in BASIC++'s virtual memory
and can be read back with PEEK.  Hardware-triggering addresses
(like sound registers or video mode switches) trigger the
corresponding virtual device if available.


4. INP AND OUT WITH MEMMAP
===========================

INP and OUT use the same virtual address space as PEEK/POKE:

  MEMMAP "C64"
  OUT &HD418, 15               ' SID volume = max
  V = INP(&HD418)              ' Read it back

For the MSDOS map, INP/OUT operate on the I/O port space
($0000-$03FF), which overlaps the IVT.


5. COMBINING DIALECT + MEMMAP
==============================

For the most authentic experience, combine both:

  DIALECT "COCO"
  MEMMAP "COCO"
  ' Now you have CoCo BASIC syntax + CoCo memory map

  DIALECT "GWBS"
  MEMMAP "MSDOS"
  ' GW-BASIC syntax + PC memory layout

  DIALECT "BPP"
  MEMMAP "C64"
  ' Full BASIC++ syntax but C64 memory model


6. WHAT THE MEMORY MAPS DO
============================

  - PEEK/POKE addresses are mapped to the virtual layout
  - "Magic" addresses trigger side effects:
      Video registers update the virtual screen buffer
      Sound registers trigger BEEP/SOUND if available
      Keyboard addresses return INKEY$ state
  - Non-magic addresses are plain read/write memory
  - The 64K address space is always fully accessible
  - Switching maps does NOT clear memory (use NEW for that)


7. WRITING PORTABLE CODE
=========================

If your program must work with any memory map:

  10 REM Portable screen clear
  20 CLS
  30 REM (Don't POKE screen memory directly)

If your program targets a specific machine:

  10 MEMMAP "C64"
  20 REM Safe to use C64-specific POKEs here
  30 POKE 53280, 0
