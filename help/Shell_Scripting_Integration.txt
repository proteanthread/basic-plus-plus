==============================================================================
BASIC++ v6.5.2 SHELL SCRIPTING INTEGRATION ARCHITECTURE
==============================================================================

The authoritative specification for headless batch execution, Unix
pipelines, operating system command dispatch, and environment
integration in BASIC++ v6.5.2.


1. THE BATCH SCRIPT RUNNER (bs / bs.exe)

The bs executable is specifically designed for non-interactive shell
scripting, automated tasks, and CI/CD pipelines:

* Zero Banner & Zero Prompt: Produces no startup banner or interactive
  prompt, ensuring clean stdout streams.
* Deterministic Exit Codes:
  - 0: Successful execution.
  - 1: Runtime error.
  - 2: Script file not found.
  - 3: Syntax or compilation error.
* Pipeline Invocation:
    bs script.bas
    cat data.csv | bs filter.bas > output.csv


2. STANDARD I/O PIPELINES

The batch runner attaches directly to standard OS streams:
* INPUT and LINE INPUT read from standard input (stdin).
* PRINT and WRITE emit data to standard output (stdout).
* Diagnostics, assertions, and error messages are directed to standard
  error (stderr).

    10 REM Filter stdin to stdout
    20 ON ERROR GOTO 100
    30 WHILE 1
    40   LINE INPUT LineData$
    50   PRINT UCASE$(LineData$)
    60 WEND
    100 END


3. OPERATING SYSTEM COMMAND EXECUTION

BASIC++ provides multiple complementary mechanisms for interacting with
the host operating system:

* SHELL "command": Executes a command string via host command
  interpreter (cmd.exe or /bin/sh). Execution halts until command
  completes.
* SHELL$("command"): Executes an OS shell command and captures its
  standard output as a string.
* EXEC$(binary$ [, arg1$ [, arg2$...]]): Spawns an external binary
  directly with argument vector passing, bypassing shell interpretation.
* ERRORLEVEL: Built-in system variable containing integer exit code of
  the most recently executed SHELL or EXEC$ process.


4. ENVIRONMENT VARIABLES AND PROCESS TERMINATION

* ENVIRON$("VAR"): Reads the value of an environment variable.
* ENVIRON "VAR=VALUE": Sets or modifies an environment variable in the
  active process environment.
* COMMAND$: Returns raw command-line argument string passed to script.
* SYSTEM [exit_code]: Immediately terminates interpreter process,
  returning exit_code to parent shell.
