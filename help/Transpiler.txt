==============================================================================
BASIC++ TRANSPILER ARCHITECTURE & C17 CODE GENERATION REFERENCE
==============================================================================

The authoritative specification for the BASIC++ source-to-source
transpiler (trans / trans.exe), focusing on the active ISO C17 code
generation target.


1. WHAT IT DOES

1. Translates BASIC++ source code into clean, human-readable,
   freestanding-compliant ISO C17 source code.
2. Emits structured C17 control flow constructs (for, while, do-while,
   switch-case, if-else) matching BASIC control structures.
3. Preserves original BASIC source lines as synchronized C code comments
   (/* Line 10: ... */).
4. Maps BASIC scalar variables and array allocations to typed C17
   identifiers (bpp_<name>).
5. Generates calls to lightweight BASIC++ C runtime library for string
   operations, formatted I/O, and mathematical routines.
6. Emulates vintage GOSUB / RETURN stacks using C functions and label tables.
7. Emulates ON ERROR GOTO and structured TRY...CATCH exception handling via
   setjmp / longjmp scaffolds.
8. Supports single-file compilation via --inline-runtime, embedding runtime
   functions directly into generated C source.
9. Performs static optimization passes including constant folding,
   dead-code elimination, and scalar type specialization.
10. Operates as an independent build target (trans.exe on Windows, trans
    on Linux) deployed directly to repository root.


2. WHY IT EXISTS

1. Enables BASIC++ programs to compile into native bare-metal machine code
   with zero interpreter overhead.
2. Produces standard portable C17 code compiling under GCC, Clang, MSVC.
3. Serves as compilation bridge for embedded microcontrollers.
4. Integrates vintage BASIC algorithms directly into modern C pipelines.
5. Verifies AST semantic correctness across interpreted and compiled models.
6. Preserves branchless vintage arithmetic invariants (-1 truth value).
7. Conforms to ISO/IEC 25010 Portability and Maintainability standards.
8. Enforces strict Documentation and Help Mirror Parity.


3. INVOCATION AND COMMAND-LINE USAGE

    trans [options] input_file.bas [-o output_file.c]

* -o <path>: Designates target C17 output filename.
* --inline-runtime: Inlines runtime functions into emitted C file.
* --freestanding: Generates freestanding ISO C17 (zero hosted headers).
* --trace: Emits AST transformation tracing to standard output.
