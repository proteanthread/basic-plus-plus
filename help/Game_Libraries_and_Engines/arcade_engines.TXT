Arcade Game Engines
======================================================================

BASIC++ includes a suite of specialized companion game libraries
designed for action, arcade, real-time physics, and entity simulation.
These modular libraries can be combined to build vertical shooters,
side-scrolling platformers, flocking swarm AI, and maze navigation
games.


1. FIXED AND VERTICAL SHOOTER ENGINE (ARCADE_SHOOTER.LIB)
======================================================================

The ARCADE_SHOOTER.LIB module provides high-speed entity pooling,
projectile lifecycle tracking, and Axis-Aligned Bounding Box (AABB)
collision detection tailored for classic space shooters (Space
Invaders, Galaxian, Defender).

Procedures & API:
  - AS_INIT_SWARM(Count%): Initializes an array of Count% enemy ships
    across horizontal rows with velocity and boundary limits.
  - AS_UPDATE_BULLETS(): Advances all active player and enemy bullet
    positions by velocity vectors; recycles off-screen bullets.
  - AS_CHECK_COLLISIONS(): Performs 2D AABB bounding-box intersection
    tests between active bullets and enemy entities.

Code Example:
    10 REM Space Shooter Loop
    20 CALL AS_INIT_SWARM(20)
    30 WHILE GameRunning%
    40     K$ = INKEY$
    50     IF K$ = " " THEN CALL AS_FIRE_BULLET(PlayerX, PlayerY)
    60     IF K$ = "A" AND PlayerX > 1 THEN PlayerX = PlayerX - 1
    70     IF K$ = "D" AND PlayerX < 78 THEN PlayerX = PlayerX + 1
    80     CALL AS_UPDATE_BULLETS()
    90     CALL AS_CHECK_COLLISIONS()
    100    CALL AS_RENDER_SCENE(PlayerX, PlayerY)
    110    _TIMER_DELAY 0.016
    120 WEND


2. PLATFORMER & PHYSICS ENGINE (PLATFORMER.LIB)
======================================================================

The PLATFORMER.LIB module provides 2D kinematic physics simulation,
including downward gravitational acceleration, jump impulse velocity,
and tilemap collision checking for platformers (Mario, Donkey Kong).

Procedures & API:
  - PF_APPLY_GRAVITY(): Applies gravitational acceleration to all
    active entities not grounded on a solid surface.
  - PF_CHECK_FLOOR(X%, Y%): Evaluates whether (X%, Y%) contains a
    solid platform tile. Returns TRUE (-1) or FALSE (0).
  - PF_JUMP(Force#): Imparts an upward vertical velocity impulse if
    the player entity is currently grounded.

Code Example:
    100 REM Update Player Kinematics
    110 IF PF_CHECK_FLOOR(PX%, PY% + 1) THEN
    120     IsGrounded% = 1
    130     VelY = 0
    140 ELSE
    150     IsGrounded% = 0
    160     CALL PF_APPLY_GRAVITY()
    170 END IF
    180 IF INKEY$ = "W" AND IsGrounded% THEN CALL PF_JUMP(4.5)


3. SWARM & MULTI-ENTITY AI (SWARM.LIB)
======================================================================

The SWARM.LIB module implements synchronized formation movement,
flocking algorithms, and individual entity combat AI.

Procedures & API:
  - SW_UPDATE_POSITIONS(): Updates global offsets for the active swarm
    using sinusoidal horizontal oscillation and downward shifts.
  - SW_DIVE_BOMB(EnemyIndex%): Detaches EnemyIndex% from formation to
    perform a direct homing attack on the player.


4. PROCEDURAL MAZE GENERATOR (MAZE.LIB)
======================================================================

The MAZE.LIB module implements randomized maze carving algorithms
(recursive backtracking and cellular automata) for maze games.

Procedures & API:
  - MZ_GENERATE(Width%, Height%): Generates a fully connected 2D maze
    with guaranteed path traversability and boundary walls.
  - MZ_DRAW(StartX%, StartY%): Renders the generated maze onto VCon.
  - MZ_CHECK_WALL(X%, Y%): Returns TRUE (-1) if (X%, Y%) is a wall.
