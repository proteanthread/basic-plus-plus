==============================================================================
BASIC++ v6.5.2 How To Use Help
==============================================================================

1. THE HELP COMMAND

The HELP command provides built-in interactive documentation directly from
the interpreter prompt. It displays authoritative syntax, description,
parameter rules, and examples for any keyword, statement, function, or
subsystem topic.

To look up documentation for a keyword, type HELP followed by the keyword
identifier:

    > HELP PRINT
    > HELP FOR
    > HELP LEFT$
    > HELP ON ERROR

HELP accepts keywords with or without type suffixes (e.g., HELP LEFT and
HELP LEFT$ both resolve to LEFT$). Multi-word keywords use their standard
natural spacing (HELP ON ERROR, HELP LINE INPUT, HELP SELECT CASE).

Typing HELP with no argument displays a categorized master catalog of
available documentation topics.

2. THE CATALOG COMMAND

The CATALOG command outputs a tabular index of all reserved words, functions,
statements, and operators recognized by the active engine:

    > CATALOG

CATALOG accepts optional category filters:
* CATALOG STATEMENTS: Filters display to intrinsic statements.
* CATALOG FUNCTIONS: Filters display to builtin functions.
* CATALOG OPERATORS: Filters display to arithmetic, relational, and logical
  operators.

3. THE CATEGORY COMMAND

The CATEGORY command provides category-level introspection:
* CATEGORY: Lists all registered functional categories.
* CATEGORY <keyword>: Displays the category classification of a specific
  keyword.
* CATEGORY <"Category Name">: Lists all keywords belonging to the specified
  category.
* CATEGORY$(keyword$): Built-in function returning the category string in
  expressions.

Example:

    > CATEGORY ABS
    Mathematical Functions
    > PRINT CATEGORY$("SHUFFLE$")
    String Functions

4. THE INFO COMMAND

INFO outputs comprehensive system diagnostics, including the engine version,
edition name (Desktop baspp, Lite bpp, Batch bs, or IoT iot), memory arena
allocations, stack depths, and platform details:

    > INFO
    BASIC++ Desktop Edition v6.5.2
    Program Memory: 128 MB
    Variable Memory: 128 MB
    String Heap: 256 MB
    Scratch Area: 128 MB
    Stack Depth: 1023
    Named Variables: 8192
    Security Level: OPEN

5. THE VER COMMAND & VER$ FUNCTION

VER prints the version banner to the console. The VER$ function returns the
version identifier as a string value for program inspection: V$ = VER$.

6. THE VARS COMMAND

VARS dumps all currently allocated variables, their runtime types, and active
values. Arrays show dimensional bounds and total element counts, assisting
interactive debugging.

7. THE DEVICES COMMAND

DEVICES enumerates all registered virtual devices on the virtual hardware bus
(VDev), displaying device slot numbers, driver type identifiers, and
operational status.

8. TOPICAL HELP CATEGORIES

HELP accepts specialized topical categories when detailed thematic reference
is required:
* HELP ERRORS: Displays numeric error codes and descriptions.
* HELP OPERATORS: Displays operator precedence and delimiter rules.
* HELP TYPES: Details the type hierarchy (BLOCK { SET [ GROUP ( OBJECT ) ] }).
* HELP FILES: Summarizes file I/O modes and channel rules.
* HELP GRAPHICS: Summarizes display modes and BGI drawing commands.
* HELP SOUND: Summarizes sound synthesis and music macro statements.
* HELP DEBUG: Summarizes interactive debugging commands.
* HELP SECURITY: Documents sandboxing and EU CRA safety levels.
* HELP MODULES: Details module loading and namespace management.

9. INTROSPECTION SYSTEM VARIABLES

Several built-in variables and functions provide programmatic access to
metadata:
* VER$: Returns the full engine version string.
* MEMMAP$: Returns the active memory configuration profile name ("MODERN",
  "LITE", "BATCH", "IOT", "FREEDOS").
* ALIAS$(keyword$): Returns the registered alias for a keyword, if defined.
* FRE(0): Returns available bytes in the string heap.
* FRE(-1): Returns the largest contiguous free block in the string arena.
* FRE(-2): Returns remaining bytes in the variable memory partition.
