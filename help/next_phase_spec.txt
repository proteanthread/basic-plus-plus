Phase 11a — Foundation (Language Core)
======================================
  11a.1: configuration Layer (src/dialect/ — EMPTY, needs implementation)
  11a.2: Bit Manipulation Functions (_SHL, _SHR, _READBIT, _SETBIT, _RESETBIT, _TOGGLEBIT, _BITCOUNT)
  11a.3: Extended Math Functions (_ACOS, _ASIN, _ATAN2, _ACOSH, _ASINH, _ATANH, _CEIL, _HYPOT, _PI, _D2R, _R2D, _D2G, _G2D)
  11a.4: ENUM Support (ENUM...END ENUM)
  11a.5: WITH Blocks (WITH var...END WITH)

Phase 11b — I/O & Devices
==========================
  11b.1: Sound System (SOUND, PLAY MML, _SNDOPEN, _SNDPLAY, _SNDLOOP, _SNDSTOP, _SNDPAUSE, _SNDVOL, _SNDLEN, _SNDGETPOS, NOISE)
  11b.2: Mouse/Joystick Input (MOUSE(), _MOUSEINPUT, _MOUSEWHEEL, STICK(), STRIG(), _DEVICES, _DEVICE$)
  11b.3: Clipboard Access (_CLIPBOARD$)
  11b.4: Window Management (_TITLE, _SCREENMOVE, _FULLSCREEN, _SCREENX/_SCREENY, _DESKTOPWIDTH/_DESKTOPHEIGHT, _RESIZE, _ICON)

Phase 11c — Advanced Runtime
=============================
  11c.1: TCP/IP Networking (_OPENHOST, _OPENCONNECTION, _CONNECTED, _CONNECTIONADDRESS$)
  11c.2: Image File Loading (_LOADIMAGE, _FREEIMAGE, _PUTIMAGE, _NEWIMAGE, _COPYIMAGE)
  11c.3: Compression (_DEFLATE$, _INFLATE$)
  11c.4: Session State Save/Load (_STATESAVE, _STATELOAD, _STATEINFO$)

Cross-Cutting
=============
  C1: API Documentation Package (docs/api/ — 38 headers documented)
  C2: HELP/CATALOG Parity Catch-Up (~200+ keywords to register)
  C3: Implementation Status Tracker (docs/IMPLEMENTATION_STATUS.md)
  C4: Compiler/Transpiler Synchronization (bppc + trans for every new keyword)

Dual Syntax Convention
======================
  All keywords support BOTH classic GW-BASIC syntax AND modern dot-access syntax:
    Classic:  SOUND 440, 18
    Modern:   sound.tone(440, 18)

Build Flags
===========
  BASIC_SDL2             ON  (baspp default) — Full SDL2 backend
  BASIC_HEADLESS         ON  (blite/bscript) — No graphics or sound
  BASIC_FRAMEBUFFER_ONLY OFF — Software framebuffer only, no SDL2 window
