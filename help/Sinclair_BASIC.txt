======================================================================
  BASIC++ V6.5.2 SINCLAIR BASIC (ZX SPECTRUM) DIALECT
======================================================================


======================================================================
  1. HISTORY
======================================================================

Sinclair BASIC was the built-in language of the ZX Spectrum series (1982-1992). It featured a unique single-keypress keyword entry system, attribute-based color graphics, and BEEP for sound generation. BASIC++ implements Sinclair BASIC compatibility through the SINC dialect configuration.


======================================================================
  2. ACTIVATING SINCLAIR MODE
======================================================================

10 DIALECT "SINC"

Or launch with: baspp --dialect=SINC.


======================================================================
  3. COLOR ATTRIBUTES
======================================================================

Sinclair BASIC uses INK, PAPER, BORDER, BRIGHT, FLASH, INVERSE, and OVER for color control:

10 BORDER 1              ' Blue border
20 PAPER 0               ' Black background
30 INK 7                 ' White text
40 CLS
50 PRINT "Hello, Spectrum!"

INK n sets the foreground (ink) color (0-7). PAPER n sets the background (paper) color (0-7). BORDER n sets the screen border color (0-7). BRIGHT n enables bright mode (n=1 for bright, n=0 for normal). FLASH n enables flashing (n=1 for flash, n=0 for normal).

Standard Spectrum colors: 0=Black, 1=Blue, 2=Red, 3=Magenta, 4=Green, 5=Cyan, 6=Yellow, 7=White. With BRIGHT 1, colors become their brighter variants.


======================================================================
  4. INVERSE AND OVER
======================================================================

INVERSE 1 swaps ink and paper for subsequent output. INVERSE 0 returns to normal. OVER 1 enables overprint mode (XOR characters onto existing screen content). OVER 0 returns to normal.


======================================================================
  5. PRINT AT
======================================================================

Sinclair BASIC uses PRINT AT row, col for cursor positioning (equivalent to LOCATE):

10 PRINT AT 10, 15; "Center of screen"
20 PRINT AT 0, 0; "Top left"

AT positions are 0-based in Sinclair BASIC (row 0-21, col 0-31 for 32-column mode). BASIC++ accepts both 0-based (Sinclair) and 1-based (GW-BASIC) positioning depending on the active dialect.


======================================================================
  6. BEEP
======================================================================

Sinclair BASIC's BEEP statement takes duration and pitch parameters:

10 BEEP 0.5, 0           ' Middle C for 0.5 seconds
20 BEEP 0.5, 2           ' D
30 BEEP 0.5, 4           ' E
40 BEEP 1, 7             ' G for 1 second

Duration is in seconds. Pitch is in semitones relative to middle C (0 = middle C, 12 = C one octave up, -12 = C one octave down). This differs from GW-BASIC's SOUND statement which takes frequency in Hz and duration in ticks.


======================================================================
  7. GRAPHICS
======================================================================

Sinclair BASIC graphics use a 256x192 pixel resolution with attribute-based coloring (each 8x8 cell shares one ink and paper color):

PLOT x, y ? Set a pixel (equivalent to PSET).
DRAW dx, dy ? Draw a line from the current position by dx, dy pixels.
DRAW dx, dy, angle ? Draw an arc.
CIRCLE x, y, radius ? Draw a circle.

10 BORDER 0 : PAPER 0 : INK 7 : CLS
20 FOR I = 0 TO 255
30   PLOT I, 96 + SIN(I / 40) * 80
40 NEXT I


======================================================================
  8. SCREEN$ AND ATTR
======================================================================

SCREEN$(row, col) returns the character displayed at the specified position. ATTR(row, col) returns the attribute byte at the specified position.


======================================================================
  9. PAUSE
======================================================================

PAUSE n suspends execution for n/50 seconds (PAL timing) or n/60 seconds (NTSC timing). PAUSE 0 waits indefinitely until a key is pressed.


======================================================================
  10. INPUT
======================================================================

Sinclair BASIC INPUT uses a different visual style: it clears the bottom lines of the screen and displays the input area there. BASIC++ emulates this behavior in SINC dialect mode.


======================================================================
  11. SPECTRUM-SPECIFIC FUNCTIONS
======================================================================

INKEY$ reads a single key without waiting (same as GW-BASIC). PEEK and POKE access the ZX Spectrum memory map emulation. Key Spectrum addresses: 16384 (screen memory start), 22528 (attribute area start), 23693 (system variable ATTR_P for permanent attribute).


======================================================================
  12. COMPATIBILITY NOTES
======================================================================

When running Spectrum BASIC programs: INK/PAPER/BORDER map to BASIC++ color operations through the VCon device. BEEP is translated to frequency/duration parameters. AT-based positioning is converted to 1-based coordinates internally. POKE/PEEK to Spectrum memory addresses are handled by the BIOS emulation layer's Spectrum memory map module.
