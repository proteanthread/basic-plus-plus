SINCLAIR BASIC (ZX Spectrum) DIALECT REFERENCE
================================================
Version 1.5.0
Dialect Code: SINC

====================================================================
HISTORY
====================================================================

Sinclair BASIC was the built-in programming language of the ZX
Spectrum, released by Sinclair Research in April 1982. The Spectrum
used a Zilog Z80A CPU running at 3.5 MHz with 16K or 48K of RAM.

The BASIC was developed by Nine Tiles Networks (Steve Vickers and
John Grant), building on the earlier ZX80 and ZX81 BASICs. It was
stored in a 16K ROM alongside the operating system.

The ZX Spectrum sold over 5 million units and was the dominant
home computer in the United Kingdom throughout the 1980s. Its
BASIC had several unique characteristics:

  - Keyword entry via single keypress (each key mapped to a keyword)
  - LET is mandatory for all assignments
  - No CLS command (BASIC++ provides CLS for convenience)
  - GO TO and GO SUB as two-word forms (mapped to GOTO/GOSUB)
  - BORDER, INK, PAPER for color control
  - BEEP duration, pitch (note reversed parameter order)
  - RANDOMIZE USR for machine code calls
  - VAL$ function (evaluate string as expression)

The Spectrum was famous for its rubber-keyboard model, color
attribute clashing (only 2 colors per 8x8 cell), and an enormous
library of games — over 24,000 commercial titles were released.


====================================================================
ACTIVATION
====================================================================

To enter Sinclair BASIC mode:

    DIALECT "SINC"

This changes:
  - Statement separator: ':' (colon)
  - LET is optional (relaxed from original for usability)
  - THEN is required in IF statements
  - Maximum line number: 9999
  - Ready prompt: "0 OK, 0:1"
  - Print zone width: 14
  - CLS is not available in strict mode
  - No WHILE/WEND or DO/LOOP (original had none)

To combine with the ZX Spectrum memory map:

    DIALECT "SINC"
    MEMMAP "SPECTRUM"


====================================================================
SPECTRUM-SPECIFIC FEATURES
====================================================================

--- Color Control ---

  BORDER n    Set border color (0-7)
  INK n       Set foreground ink color (0-7)
  PAPER n     Set background paper color (0-7)

  Color values:
    0 = Black     4 = Green
    1 = Blue      5 = Cyan
    2 = Red       6 = Yellow
    3 = Magenta   7 = White

  In BASIC++, BORDER/INK/PAPER map to ANSI escape codes
  for terminal color emulation.

--- Sound ---

  BEEP duration, pitch

  On the real Spectrum, BEEP takes duration in seconds and
  pitch in semitones relative to middle C.  In BASIC++, the
  BEEP statement is available but uses the platform speaker.

--- Memory Access ---

  The ZX Spectrum had important PEEK/POKE addresses:

    PEEK(23672)        Frame counter (50 Hz clock)
    PEEK(23560)        Last key pressed
    POKE 23693, attr   Set permanent screen attributes
    PEEK(23659)        PPC (current line number)

  Use MEMMAP "SPECTRUM" to access the virtual memory map
  with correct Spectrum addresses.

--- Screen Memory ---

  $4000-$57FF: Bitmap (6144 bytes, 256x192 pixels)
  $5800-$5AFF: Attributes (768 bytes, 32x24 cells)

  Each attribute byte: FBPPPIII
    F = Flash (bit 7)
    B = Bright (bit 6)
    PPP = Paper color (bits 5-3)
    III = Ink color (bits 2-0)

====================================================================
EXAMPLE PROGRAMS
====================================================================

Simple color demo:

  10 DIALECT "SINC"
  20 FOR I = 0 TO 7
  30   PRINT "Color "; I
  40 NEXT I
  50 END

Number guessing game (Spectrum style):

  10 DIALECT "SINC"
  20 RANDOMIZE
  30 LET T = INT(RND * 100) + 1
  40 LET G = 0
  50 PRINT "I'm thinking of a number (1-100)"
  60 INPUT "Your guess? "; N
  70 LET G = G + 1
  80 IF N < T THEN PRINT "Too low!": GOTO 60
  90 IF N > T THEN PRINT "Too high!": GOTO 60
  100 PRINT "Correct! You got it in "; G; " guesses."
  110 END
