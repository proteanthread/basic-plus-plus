BASIC++ v6.5.2 SOURCE MAP & REPOSITORY STRUCTURE

The comprehensive architectural navigation map of the BASIC++ repository,
top-level directories, engine/ subsystem trees, decomposed micro-libraries,
and implementing source file mappings.


1. ARCHITECTURAL OVERVIEW & LIBRARY SPECTRUM

The BASIC++ v6.5.2 codebase is decomposed into an 11-layer modular
micro-library chain (engine/CMakeLists.txt):

1. libboot: Bootstrap initialization, hardware probe, command line.
2. libplatform: OS abstraction (POSIX, Win32, FreeDOS, bare metal).
3. libkernel: Core primitives (memory arenas, error handling, lexer, vdev).
4. libengine: VM execution loop, statement dispatch, evaluator.
5. libhardware: Physical I/O virtualization, BIOS emulation, timers.
6. libserver: TCP/UDP networking (VNet), IPC, remote sessions.
7. libscript: Script execution pipeline, batch processing, stream I/O.
8. libcore: Data structures, strings, associative collections, types.
9. libflex: Advanced language runtime (UDT, arrays, matrices, patterns).
10. libstandard: Standard built-in function library and math intrinsics.
11. libadvanced: Graphics subsystems (BGI, SDL2), audio, TUI editor.
- libinterop_core: Multi-language interoperation and FFI bridges.

5. BUILD TARGETS & EXECUTABLE ROLES

The build system compiles seven decoupled executable targets:

1. baspp.exe / baspp (Desktop Edition): Console + SDL2, 640 MB memory.
2. bpp.exe / bpp (Lite REPL Edition): Headless REPL, 384 MB memory.
3. bs.exe / bs (Batch Script Runner): Non-interactive, 64 MB memory.
4. iot.exe / iot (Microcontroller Edition): Micro-REPL, 2 MB memory.
5. bppc.exe / bppc (Compiler & Transpiler): Emits bytecode or C17.
6. trans.exe / trans (Transpiler): Dialect-to-dialect translator.
7. detok.exe / detok (Detokenizer): Legacy binary decoder.
