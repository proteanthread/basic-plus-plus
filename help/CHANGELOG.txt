BASIC++ CHANGELOG
=================

0.21.0  (2026-06-07)
--------------------
  ADDED:
  - Shell scripting: SHELL$(), ERRORLEVEL, EXEC
  - PRINT redirection: PRINT > "file", PRINT >> "file", PRINT | "cmd"
  - SHELL redirection: SHELL "cmd" > "file", SHELL "cmd" | "cmd2"
  - Shebang (#!) support for executable scripts
  - Full random-access file I/O: OPEN FOR RANDOM, FIELD, GET#, PUT#
  - Binary file I/O: OPEN FOR BINARY, byte-level GET/PUT
  - LSET/RSET with field-width padding
  - IOCTL$ returns channel mode (I/O/A/R/B)
  - LOCK/UNLOCK with OS-level file locking (Windows)
  - LEN= clause for OPEN FOR RANDOM

0.20.0  (2026-06-07)
--------------------
  ADDED:
  - MEMMAP system: virtual memory maps for MSDOS, C64, Atari 8-bit,
    Apple II, ZX Spectrum, TI-99, BBC Micro, MSX, CPC
  - INP/OUT integrated with MEMMAP virtual address space
  - ALIAS command for keyword remapping
  - BEEP ON / BEEP OFF error sound toggle
  - Complete GW-BASIC/QBasic keyword audit (V-Z keywords verified)

0.19.0  (2026-06-06)
--------------------
  ADDED:
  - Complete GW-BASIC/QBasic keyword audit (R-U keywords)
  - RANDOMIZE, READ/DATA/RESTORE, RENUM, RESUME
  - SAVE/LOAD in ASCII format
  - SCREEN statement and function
  - SHELL statement
  - SOUND/PLAY statements
  - STOP/CONT debugging
  - SWAP statement
  - TAB/SPC print functions
  - TIMER function, TIME$/DATE$ functions
  - TRON/TROFF trace mode
  - WAIT statement
  - WHILE/WEND loops
  - WIDTH/VIEW/WINDOW statements
  - WRITE/WRITE# statements

0.18.0  (2026-06-06)
--------------------
  ADDED:
  - Multi-dialect engine: GWBS, QBAS, COCO, TB, DB, BPP
  - DIALECT command for runtime switching
  - Strict mode dialect enforcement
  - PRINT AT (col, row) relative positioning
  - PRINT @ pos absolute positioning (TRS-80 style)

0.17.0  (2026-06-05)
--------------------
  ADDED:
  - Security sandboxing with configurable levels (0-3)
  - SANDBOX command
  - Module system with IMPORT/EXPORT
  - Standard library module (mod_stdlib)
  - FUNCTION/SUB/END SUB user-defined procedures

0.16.0  (2026-06-05)
