ASSERT

1. Syntax & Parameters
ASSERT <condition> [, <message>]

2. Description & Usage
The ASSERT statement evaluates a conditional expression. If the condition evaluates to false (0), the engine immediately halts program execution and raises a runtime assertion error (error 99). If the condition is true (non-zero), execution continues silently.
An optional message expression (usually a string literal) can be appended to provide human-readable diagnostic context upon failure.
Usage: Primarily used in test suites and validation routines to verify invariants and correctness criteria without manual trace inspections.

3. Code Examples
`basic
10 LET A = 42
20 ASSERT A = 42, "A must be 42"
30 LET B = 10
40 ASSERT B = 20, "B must be 20"
`
Execution: The assertion at line 20 passes silently. The assertion at line 40 fails, raising runtime error 99 with the message "B must be 20".

5. Implementation Details
The ASSERT instruction parses the conditional expression using the standard expression parser. Under dry-run or transpiled builds, evaluation is bypassed to prevent compile-time failures, but syntax validation is preserved.
Error States: Raises ERR_ASSERTION_FAILED (99) on failure, which can be trapped using standard ON ERROR GOTO handlers.

7. Historical Context
ASSERT is a standard construct in modern structured programming languages but was absent from classical BASIC dialects. BASIC++ incorporates it natively to facilitate robust automated test execution directly inside the runtime engine.

8. Manual Testing Guide
1. Launch baspp.exe.
2. Type ASSERT 1 = 1 and press ENTER (should execute silently).
3. Type ASSERT 1 = 2 and press ENTER (should raise error 99).
4. Verify error reporting.
