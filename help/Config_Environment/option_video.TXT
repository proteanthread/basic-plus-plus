OPTION VIDEO
======================================================================

SYNTAX
----------------------------------------------------------------------

    OPTION VIDEO {PAL | SECAM | NTSC}

PARAMETERS
----------------------------------------------------------------------

  PAL   - Configures the timing multiplier for 50 Hz video systems
          (European broadcast standard).
  SECAM - Functionally identical to PAL, configuring the timing
          multiplier for 50 Hz video systems (French/Eastern European
          broadcast standard).
  NTSC  - Configures the timing multiplier for 60 Hz video systems
          (North American/Japanese broadcast standard). This is the
          default.


DESCRIPTION
----------------------------------------------------------------------

OPTION VIDEO selects the simulated video timing standard used by the
JIFFIES function. In legacy systems like the Commodore 64 or ZX
Spectrum, the system timer was physically tied to hardware interrupts
triggered by the video chip drawing the screen. PAL systems generated
50 interrupts per second; NTSC systems generated 60. GW-BASIC and
IBM PCs used the Intel 8253 timer chip (ticking at 18.2 Hz), but
many retro programs assumed either 50 Hz or 60 Hz timing.

OPTION VIDEO bridges this compatibility gap by setting the
jiffies_multiplier field in the VM context. The JIFFIES function
reads this multiplier to convert raw uptime into video-frequency-
scaled tick counts, allowing programs to use consistent timing
regardless of the actual host clock.

    10 OPTION VIDEO NTSC
    20 PRINT "Waiting for 60 jiffies (1 second in NTSC)..."
    30 START_TIME = JIFFIES
    40 IF JIFFIES < START_TIME + 60 THEN GOTO 40
    50 PRINT "Done."

    100 REM Simulate a 50Hz environment for European software
    110 OPTION VIDEO PAL
    120 START_T = JIFFIES
    130 GOSUB 1000
    140 END_T = JIFFIES
    150 PRINT "Processing took "; END_T - START_T; " PAL jiffies."
    160 END
    1000 REM Processing subroutine
    1010 FOR I = 1 TO 1000 : NEXT I
    1020 RETURN


MULTIPLIER VALUES
----------------------------------------------------------------------

  Mode    Multiplier  Ticks Per Second
  ------  ----------  ----------------
  NTSC    60.0        ~60 jiffies/sec
  PAL     50.0        ~50 jiffies/sec
  SECAM   50.0        ~50 jiffies/sec

The multiplier is applied by JIFFIES as:

    result = platform_get_uptime() * multiplier


JIFFIES FUNCTION INTERACTION
----------------------------------------------------------------------

The JIFFIES function (implemented in
engine/src/eval/eval_builtins.c) reads the current multiplier via
vm_get_jiffies_multiplier(vm) and multiplies it against
platform_get_uptime() to produce the tick count.

JIFFIES also accepts an optional string argument that temporarily
overrides the multiplier for that single call without changing the
persistent setting:

    OPTION VIDEO PAL
    PRINT JIFFIES           ' Uses PAL (50 Hz) multiplier
    PRINT JIFFIES("NTSC")   ' Temporarily uses NTSC (60 Hz)
    PRINT JIFFIES           ' Still PAL (50 Hz)

The JIFFIES argument override does not mutate jiffies_multiplier --
it only affects the return value of that single function call.

OPTION Statement Handler:

The OPTION statement handler (engine/src/statements/variables/option.c)
currently routes BASE and EXPLICIT sub-commands but does not yet route
VIDEO. Attempting OPTION VIDEO NTSC in v6.5.2 will produce Error 2
(Syntax Error in OPTION statement) because the else branch catches
unrecognized sub-keywords.


ERROR CODES
----------------------------------------------------------------------

  Error   Condition
  ------  --------------------------------------------------------
  2       OPTION VIDEO not yet routed in v6.5.2 OPTION handler

When fully wired, invalid modes should produce Error 5 (Illegal
Function Call), matching the original v5 behavior.

      (NTSC/PAL/SECAM)"}

OPTION VIDEO does not yet have its own help entry.

CROSS-REFERENCES
----------------------------------------------------------------------

  - JIFFIES: Uptime ticks scaled by video timing multiplier.
  - TICKS: Uptime ticks at fixed 100 Hz (not affected by
    OPTION VIDEO).
  - OPTION BASE: Configures array subscript indexing base.
  - OPTION EXPLICIT: Requires explicit variable declaration.


PROPOSED EXPANSION OR CHANGES
----------------------------------------------------------------------

The following capabilities existed in v5.0.5 but have not yet been
wired into the v6.5.2 OPTION statement handler:

  1. OPTION VIDEO sub-command routing: The v5 parser
     (source/config/parser_config.c, function pi_parse_option)
     handled OPTION VIDEO by reading the next token and writing
     to rt->jiffies_multiplier. In v6.5.2, the infrastructure
     exists (vm_set_jiffies_multiplier()) but the OPTION handler
     in engine/src/statements/variables/option.c needs a new
     branch for "VIDEO".

  2. Help system registration: OPTION VIDEO should be added to
     help_data.h as a separate entry.

  3. Micro-library metadata update: The OPTION statement's .syntax
     field should be expanded to include OPTION VIDEO.

  4. OPTION ARITHMETIC: Referenced in v5 cross-references but not
     yet implemented in v6.5.2.

  5. OPTION STRICT: Referenced in v5 cross-references but not yet
     implemented in v6.5.2. May overlap with OPTION EXPLICIT.
