==============================================================================
BASIC++ v6.5.2 TIMER EVENTS & TSR ARCHITECTURE
==============================================================================

The authoritative specification for asynchronous timer event traps,
interval handlers, and cooperative TSR-style background execution in
BASIC++ v6.5.2.


1. EVENT TRAPPING MODEL

BASIC++ provides asynchronous timer event trapping modeled on vintage
Microsoft BASIC and enhanced for modern real-time execution. Timer
events execute cooperatively at statement dispatch boundaries:

* Event handlers are invoked without interrupting long scalar math
  operations mid-instruction.
* When an event triggers, current program position is saved and
  execution jumps to registered trap line or procedure.
* Execution returns to point of interruption upon encountering RETURN.


2. TIMER TRAPPING STATEMENTS

* ON TIMER(interval) GOSUB line_num|label: Registers periodic timer
  trap triggering every interval seconds (supports fractional seconds).
* TIMER ON: Enables active polling and triggering of timer trap.
* TIMER OFF: Disables timer trap and clears pending events.
* TIMER STOP: Suspends timer trap while retaining queued events; when
  TIMER ON is subsequently executed, pending events trigger.


3. TSR-STYLE BACKGROUND EXECUTION

In embedded microcontrollers (iot) and desktop consoles (baspp), timer
event trapping allows writing non-blocking background utility loops:

* Background telemetry loggers, watchdog heartbeats, and sensor polling
  tasks operate via ON TIMER while main script runs foreground code.
* SLEEP interval or YIELD allows VM to sleep in low-power mode while
  maintaining precise timer responsiveness.


4. EXAMPLE: PERIODIC HEARTBEAT EVENT TRAP

    10 REM Timer Event Trap Demo
    20 Ticks = 0
    30 ON TIMER(1) GOSUB 1000
    40 TIMER ON
    50 PRINT "Timer trap enabled. Main program running..."
    60 FOR I = 1 TO 5
    70   PRINT "Working in foreground loop: "; I
    80   SLEEP 1.5
    90 NEXT I
    100 TIMER OFF
    110 PRINT "Timer disabled. Final tick count: "; Ticks
    120 END
    1000 REM Timer Event Handler
    1010 Ticks = Ticks + 1
    1020 PRINT "  [HEARTBEAT] Tick event #"; Ticks; " at "; TIME$
    1030 RETURN
