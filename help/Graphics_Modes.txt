
BASIC++ Graphics Modes Reference
================================

This document catalogs every display, text, and graphics mode available in BASIC++ under both the GW-BASIC SCREEN command and the Atari 8-bit GRAPHICS command. Modes are sorted by resolution (lowest resolution to highest resolution, measured in total pixel count).

---


Display Configuration Modifiers (Atari GRAPHICS)
------------------------------------------------
The 64 Atari 8-bit graphics modes come from the sixteen base GRAPHICS modes (0–15), each with four screen configuration modifiers:
   Normal / Split Screen (+0): Graphics mode on top, 4-line text window on bottom. (Split screen text width is 40 columns for standard modes, and 80 columns for 256-color modes 64-127).
   No Text Window (+16): Full-screen graphics.
   Split Screen (+32): (Same as +0; keeps graphics memory available below the screen).
   No Text Window + Split Screen (+48): (Same as +16).

Thus, modes 0–15, 16–31 (= mode +16), 32–47 (= mode +32), and 48–63 (= mode +48).
Custom 256-color modes are mapped to modes 64–127 (base + 64).
