======================================================================
  BASIC++ V6.5.2 GRAPHICS MODES
======================================================================


======================================================================
  1. THE BGI GRAPHICS SYSTEM
======================================================================

BASIC++ uses the BGI (BASIC++ Graphics Interface) for all pixel-level graphics operations. The BGI is a layered rasterizer implemented in engine/src/device/bgi/ that supports classic GW-BASIC/QBASIC screen modes, custom resolution modes, and retro hardware mode emulation. BGI is part of the libhardware library and requires the libadvanced library (SDL2) for actual display output. On text-only terminals, AAlib (engine/src/device/bgi/aalib/aalib.c) provides ASCII art approximation of graphics output.


======================================================================
  2. STANDARD SCREEN MODES
======================================================================

The SCREEN statement selects a display mode. BASIC++ supports all GW-BASIC and QBASIC screen modes:

| Mode | Resolution | Colors | Text | Type |
|------|-----------|--------|------|------|
| 0 | Text only | 16 | 80x25 | Text |
| 1 | 320x200 | 4 | 40x25 | CGA |
| 2 | 640x200 | 2 | 80x25 | CGA |
| 3 | 720x348 | 2 | 80x25 | Hercules |
| 4 | 320x200 | 4 | 40x25 | EGA |
| 7 | 320x200 | 16 | 40x25 | EGA |
| 8 | 640x200 | 16 | 80x25 | EGA |
| 9 | 640x350 | 16 | 80x25 | EGA |
| 10 | 640x350 | 4 | 80x25 | EGA mono |
| 11 | 640x480 | 2 | 80x30 | VGA |
| 12 | 640x480 | 16 | 80x30 | VGA |
| 13 | 320x200 | 256 | 40x25 | VGA/MCGA |

10 SCREEN 12        ' 640x480, 16 colors
20 LINE (0,0)-(639,479), 15
30 CIRCLE (320,240), 100, 14

SCREEN 0 returns to text mode. SCREEN mode, colorswitch, activepage, visualpage provides full control over color and paging.


======================================================================
  3. CUSTOM RESOLUTION MODES
======================================================================

BASIC++ extends standard modes with custom resolution initializers:

**SET SCREEN width, height [, bpp [, text_cols [, text_rows [, fps]]]]** ? Full-screen graphics mode. Defaults to 256 colors (8 bpp) and zero text window rows:

10 SET SCREEN 800, 600          ' 800x600, 256 colors, full graphics
20 SET SCREEN 1024, 768, 24     ' 1024x768, 24-bit true color

**SET GRAPHICS width, height [, bpp [, text_cols [, text_rows [, fps]]]]** ? Split-screen mode with a text window at the bottom. Defaults to 16 colors (4 bpp) and a text window of 80 columns by 4 rows:

10 SET GRAPHICS 640, 400         ' 640x400, 16 colors, 4-row text window
20 SET GRAPHICS 640, 480, 8, 80, 6  ' 640x480, 256 colors, 6-row text window

**SET MODE n** ? Selects from 42 predefined retro hardware mode profiles that emulate specific historical computer display configurations.

======================================================================
  5. GRAPHICS STATEMENTS
======================================================================

PSET (x, y), color ? Set a pixel. PRESET (x, y) ? Reset a pixel to background.

LINE (x1,y1)-(x2,y2), color ? Draw a line. LINE (x1,y1)-(x2,y2), color, B ? Draw a rectangle. LINE (x1,y1)-(x2,y2), color, BF ? Draw a filled rectangle.

CIRCLE (x,y), radius, color ? Draw a circle. CIRCLE (x,y), radius, color, start, end ? Draw an arc. CIRCLE (x,y), radius, color, start, end, aspect ? Draw an ellipse.

PAINT (x,y), fill_color, border_color ? Flood fill an area.

DRAW "command string" ? Execute a graphics macro language for turtle-style drawing. Commands: U (up), D (down), L (left), R (right), E (up-right), F (down-right), G (down-left), H (up-left), M x,y (move), B (move without drawing), N (return after drawing), C (set color), A (set angle), S (set scale).


======================================================================
  6. COLOR AND PALETTE
======================================================================

PALETTE attribute, color ? Remap a color attribute to a different physical color. PALETTE resets all attributes to defaults.

COLOR fg, bg ? Set drawing colors. The available colors depend on the active screen mode.

The BGI palette system (engine/src/device/bgi/bgi_palette.c) maps logical color indices to physical RGB values. The default palette for 16-color modes uses the standard CGA/EGA colors. For 256-color modes, the default uses a standard VGA palette.


======================================================================
  7. VIEWPORT AND COORDINATES
======================================================================

VIEW (x1,y1)-(x2,y2) ? Define a graphics viewport (clipping rectangle). All drawing operations are clipped to the viewport. VIEW SCREEN uses absolute coordinates; VIEW without SCREEN uses viewport-relative coordinates.

WINDOW (x1,y1)-(x2,y2) ? Define a logical coordinate system. Maps the physical pixel coordinates to logical values. WINDOW SCREEN places (0,0) at the top-left (screen coordinates). WINDOW without SCREEN places (0,0) at the bottom-left (math coordinates).

PMAP(coordinate, function) ? Convert between physical and logical coordinates.


======================================================================
  8. PAGE FLIPPING
======================================================================

PCOPY source, destination ? Copy one video page to another. Used for double-buffered animation:

10 SCREEN 7, , 0, 1      ' Draw on page 0, display page 1
20 ' Draw frame on page 0
30 PCOPY 0, 1             ' Copy completed frame to display page


======================================================================
  9. IMAGE OPERATIONS
======================================================================

PUTIMAGE stores a screen region to an array: GET (x1,y1)-(x2,y2), array. PUTIMAGE draws the stored region: PUT (x, y), array, action. The action can be PSET, PRESET, AND, OR, or XOR.

FREEIMAGE releases the memory used by a stored image.


======================================================================
  10. FONT RENDERING
======================================================================

The BGI font system (engine/src/device/bgi/bgi_font.c) provides built-in fonts for text rendering in graphics modes. ROM fonts at 1x1, 2x1, and 2x2 scaling factors are available for split-screen text windows. OUTTEXTXY x, y, "text" draws a string at the specified graphics coordinates.
