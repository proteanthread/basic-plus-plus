======================================================================
  BASIC++ V6.5.2 SOURCE TREE REFERENCE
======================================================================


======================================================================
  1. TOP-LEVEL DIRECTORIES
======================================================================

basic-plus-plus/
  engine/                 ? v6.5.2 source code (the active codebase)
  source/                 ? Legacy v5.0.5 source (not used for v6 development)
  docs/                   ? Markdown documentation files
  help/                   ? Plaintext help mirrors of docs/
  tests/                  ? Regression test suites
  samples/                ? Model documents and sample programs
  classics/               ? Preserved standalone educational modules
  tools/                  ? Build tools and utilities
  CMakeLists.txt          ? Root CMake configuration
  AGENTS.md               ? Project architectural rules
  README.md               ? Project overview


======================================================================
  2. ENGINE DIRECTORY
======================================================================

The engine/ directory contains all v6.5.2 source code, organized by subsystem:

engine/
  CMakeLists.txt          ? Engine build configuration (1465 lines)
  Engine_Features.md      ? Feature documentation
  Engine_Features.TXT     ? Plaintext feature list
  include/                ? Public header files
    bpp_api.h             ? Top-level API surface
    bios/                 ? BIOS emulation headers
    compiler/             ? Compiler subsystem headers
    core/                 ? Core subsystem headers
    debug/                ? Debug/logging headers
    device/               ? Virtual device headers
    docgen/               ? Documentation generator headers
    editor/               ? TUI editor headers
    eval/                 ? Expression evaluator headers
    functions/            ? Built-in function headers
    interop/              ? Host interop headers
    lexer/                ? Lexer headers (lexer.h)
    memory/               ? Memory manager headers (memory.h)
    module/               ? Module system headers
    platform/             ? Platform abstraction headers
    runtime/              ? Runtime subsystem headers
    scope/                ? Scope stack headers
    security/             ? Security system headers (security.h)
    statements/           ? Statement handler headers
    stmt/                 ? Statement category headers
    types/                ? Core type definitions
    vm/                   ? VM headers (vm.h, host.h)
  src/                    ? Implementation source files
    bios/                 ? BIOS: bios.c, bios_at.c, bios_cpu8086.c, etc.
    bootstrap/            ? Boot: common/common.c
    compiler/             ? Compiler implementation
    core/                 ? Core: bpp_api.c, dialect.c, feature_reg.c, struct.c
    debug/                ? Debug: logger.c, dap_server.c
    device/               ? Devices: vdev.c, vcon.c, bus.c, console.c, mux.c, gfx.c
    device/bgi/           ? BGI: bgi_core.c, bgi_font.c, bgi_modes.c, bgi_raster.c
    device/bgi/aalib/     ? AAlib ASCII art fallback
    docgen/               ? DocGen: docgen.c
    editor/               ? Editors: edit.c, editor.c, edlin.c, vi.c, ws.c
    eval/                 ? Evaluator: eval.c, ast.c, dispatch.c, ops.c, rpn.c
    eval/functions/bits/  ? Bit functions: bitcount.c, readbit.c, setbit.c, etc.
    eval/functions/math/  ? Math functions: abs.c, sin.c, cos.c, sqr.c, etc.
    eval/functions/string/ ? String functions: len.c, left.c, mid.c, chr.c, etc.
    eval/functions/system/ ? System functions: timer.c, date.c, fre.c, etc.
    interop/              ? Host interoperability
    lexer/                ? Lexer: lexer.c
    memory/               ? Memory: mem_system.c, segmented_mem.c
    module/               ? Modules: module.c, arrayext.c, mathext.c, regex.c
    parser/               ? Parser: parser.c
    runtime/              ? Runtime: variables.c, strings.c, arrays.c, file.c, etc.
    scope/                ? Scope: scope.c
    security/             ? Security: security.c
    statements/core/      ? Core statements: print.c, input.c, if.c, goto.c, etc.
    statements/loops/     ? Loop statements: for.c, next.c, do.c, loop.c, wend.c
    statements/dialect/   ? Dialect: help.c, selftest.c, alias.c, scope.c, etc.
    tools/                ? Internal tools
    vm/                   ? VM: context.c, control.c, exec.c, error.c, events.c
  lib/                    ? Library implementations
    platform/             ? Platform: plat_console.c, plat_fs.c, plat_sys.c, etc.
    editor/               ? Editor library: editor_buffer.c, editor_render.c, etc.

======================================================================
  5. STANDALONE CLASSICS DIRECTORY
======================================================================

The standalone/ directory contains standalone educational BASIC interpreters preserved as freestanding C89/C90:

standalone/
  1964.c                  - 1964 Dartmouth BASIC recreation
  level1.c                - Level I BASIC (TRS-80 style, 1977)
  woz.c                   - Apple II Integer BASIC (Steve Wozniak, 1977)
  cbm.c                   - Commodore PET / 64 BASIC v2.0 (1977)
  tinybasic.c             - Palo Alto Tiny BASIC (Dr. Li-Chen Wang, 1976)
