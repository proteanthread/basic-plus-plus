=====================================================================
  BASIC++ on FreeDOS -- Complete Compilation Guide
=====================================================================

  This guide covers everything you need to build a custom BASIC++
  binary for FreeDOS -- including how to select your own dialects,
  modules, keywords, sections, and memory pools.

  See also: FreeDOS_Build.txt for the quick-reference version.


=====================================================================
  1. PREREQUISITES
=====================================================================

  Hardware / OS:
    - FreeDOS 1.3 or FreeDOS 1.4
    - Minimum 640K conventional memory (512K usable)
    - Hard disk with at least 10 MB free space

  Software:
    - OpenWatcom C Compiler (v1.9 or v2.0)
      wcc      16-bit real mode compiler
      wcc386   32-bit protected mode compiler
      wmake    build tool
      wlink    linker

  Environment Setup:
    After installing OpenWatcom:

      SET WATCOM=C:\WATCOM
      SET PATH=%WATCOM%\BINW;%PATH%
      SET INCLUDE=%WATCOM%\H

    Or run OWSETENV.BAT from your OpenWatcom installation.

  Directory Layout:

    C:\BPP\                       project root
    +-- build-fd.bat              FreeDOS build script
    +-- source\                   all source code
    |   +-- makefd                wmake makefile for FreeDOS
    |   +-- config.h              memory pools and defaults
    |   +-- core\                 core interpreter files
    |   +-- dialect\              dialect profile files
    |   +-- modules\              optional modules
    |   +-- ...
    +-- docs\                     documentation (markdown)
    +-- help\                     documentation (plaintext)


=====================================================================
  2. QUICK START
=====================================================================

  From the project root directory on FreeDOS:

    build-fd

  That's it. This builds a 16-bit bpp.exe with:
    Dialect:  Palo Alto Tiny BASIC (PATB) only
    Modules:  STDLIB only
    Memory:   512K conventional memory pools

  To run:

    bpp

  You'll see:

    BASIC++ 3.3.0
    @COPYLEFT ALL WRONGS RESERVED

    Ready.
    >


=====================================================================
  3. BUILD MODES: 16-BIT vs 32-BIT
=====================================================================

  16-bit (default):

    build-fd 16

    - Runs in real mode on any 8086 or better CPU
    - Limited to 640K conventional memory
    - Broadest hardware compatibility
    - Recommended for original/vintage hardware

  32-bit (DOS/4GW):

    build-fd 32

    - Requires 386 or better CPU
    - Uses DOS/4GW protected mode extender
    - Access to extended memory beyond 640K
    - You can increase memory pools in config.h

  When to use 32-bit:
    - Programs with large arrays (>4096 elements)
    - Programs with heavy string manipulation
    - Programs longer than 1024 lines
    - When you want to add more dialects


=====================================================================
  4. DEFAULT DIALECT (PATB)
=====================================================================

  The FreeDOS build defaults to Palo Alto Tiny BASIC (PATB).
  This is the smallest, most memory-efficient dialect.

  PATB provides:
    PRINT, INPUT, LET, IF/THEN, GOTO, GOSUB/RETURN
    FOR/NEXT loops
    Single-letter variables (A-Z)
    Integer arithmetic
    RND, ABS, SIZE functions
    LIST, RUN, NEW, SAVE, LOAD

  PATB does NOT provide:
    String variables (A$, B$)
    Multi-character variable names
    DEF FN user functions
    Block IF/THEN/ELSE
    WHILE/WEND, DO/LOOP
    SELECT CASE


=====================================================================
  5. SWITCHING THE DEFAULT DIALECT
=====================================================================

  At Runtime:
  If you've compiled multiple dialects, switch at runtime:

    DIALECT "GWBS"

  At Compile Time (Permanent):
  Edit source\config.h, find the FreeDOS section:

    #undef BASICPP_DEFAULT_DIALECT
    #define BASICPP_DEFAULT_DIALECT DIALECT_TINY_BASIC

  Change to your preferred dialect:

    #undef BASICPP_DEFAULT_DIALECT
    #define BASICPP_DEFAULT_DIALECT DIALECT_GW_BASIC

  IMPORTANT: You must also add the dialect's source file to the
  build. See Section 6.

  Available Dialect Constants:

    Constant             Code   Description
    -------------------- ------ --------------------------
    DIALECT_TINY_BASIC   PATB   Palo Alto Tiny BASIC
    DIALECT_GW_BASIC     GWBS   GW-BASIC / BASICA
    DIALECT_TRS80_I      TRS1   TRS-80 Level I
    DIALECT_TRS80_II     TRS2   TRS-80 Level II
    DIALECT_ECMA55       E55    ECMA-55 Minimal BASIC
    DIALECT_ECMA116      E116   ECMA-116 Full BASIC
    DIALECT_QBASIC       QBAS   QBasic / QuickBASIC
    DIALECT_APPLE_INT    AINT   Apple Integer BASIC
    DIALECT_APPLESOFT    ASFT   Applesoft BASIC
    DIALECT_ATARI        ATAR   Atari BASIC
    DIALECT_C64          C64    Commodore 64 BASIC V2
    DIALECT_COCO         COCO   Color Computer BASIC
    DIALECT_MBASIC       MBAS   MBASIC (CP/M)
    DIALECT_SINCLAIR     SINC   Sinclair ZX Spectrum
    DIALECT_SUPERBASIC   SUPB   QL SuperBASIC
    DIALECT_SBASIC       SBAS   SBASIC (S-BASIC)


=====================================================================
  6. SELECTING DIALECTS
=====================================================================

  Edit source\makefd and find the dialect section:

    INCLUDE_PATB = yes
    # INCLUDE_GWBS = yes
    # INCLUDE_TRS1 = yes
    ...

  Uncomment any dialect you want to include:

    INCLUDE_PATB = yes
    INCLUDE_GWBS = yes

  Then rebuild:

    build-fd clean
    build-fd

  Memory Impact (approximate per dialect):

    Dialect   Size    Impact
    --------- ------- -----------
    PATB      ~8 KB   Minimal
    GWBS      ~12 KB  Small
    TRS1      ~8 KB   Minimal
    TRS2      ~10 KB  Small
    E55       ~8 KB   Minimal
    E116      ~12 KB  Small
    QBAS      ~12 KB  Small
    All 16    ~160 KB Significant

  Recommended Combinations:

    Use Case                   Dialects              Total
    -------------------------- --------------------- ------
    Minimal Tiny BASIC         PATB                  ~8 KB
    Classic home computer      PATB + GWBS           ~20 KB
    Standards-compliant        PATB + E116           ~20 KB
    TRS-80 compatible          PATB + TRS1           ~16 KB
    Feature-rich (32-bit)      PATB+GWBS+E116+QBAS  ~44 KB


=====================================================================
  7. SELECTING MODULES
=====================================================================

  Available Modules:

    Module    Description                 Size     FreeDOS
    --------- --------------------------- -------- --------
    STDLIB    Standard library (always)   ~8 KB    Always
    USB       USB device support          ~16 KB   Optional
    FUJINET   FujiNet network adapter     ~12 KB   Optional
    UPNP      UPnP/SSDP discovery         ~8 KB   Optional
    JIT       JIT compiler                stub     No-op

  Edit source\makefd:

    INCLUDE_STDLIB  = yes
    # INCLUDE_USB     = yes

  JIT on FreeDOS:
    The JIT module compiles as a no-op stub on FreeDOS.
    MODULE "JIT" prints "JIT not available on this platform."
    Use BRUN instead -- same bytecode, VM execution.


=====================================================================
  8. SELECTING SECTIONS (FEATURE GROUPS)
=====================================================================

  Sections are groups of related source files. Strip entire feature
  groups to create a smaller binary.

  Available Sections:

    Section    Keywords Affected                       Size
    ---------- --------------------------------------- ------
    GRAPHICS   PSET, LINE, CIRCLE, DRAW, PAINT        ~12 KB
    SOUND      SOUND, PLAY, BEEP                       ~4 KB
    STRUCT     SELECT CASE, SUB, FUNCTION, TYPE        ~16 KB
    FILEIO     OPEN, CLOSE, INPUT#, PRINT#, GET, PUT   ~20 KB
    BLOCKIO    BLOAD, BSAVE, block read/write           ~4 KB
    STREAMIO   Stream-oriented I/O                      ~4 KB
    SHELL      SHELL, SYSTEM, ENVIRON$                  ~4 KB
    DEBUG      TRON, TROFF, BREAK, SELFTEST             ~8 KB
    HELP       HELP command                             ~8 KB
    PCODE      BRUN (bytecode compiler and VM)          ~16 KB

  To remove a section, comment it out in source\makefd:

    INCLUDE_GRAPHICS = yes
    INCLUDE_SOUND    = yes
    # INCLUDE_STRUCT   = yes     <-- REMOVED

  WARNING: Programs using keywords from a removed section will
  produce "WHAT?" errors at runtime.


=====================================================================
  9. KEYWORD CUSTOMIZATION
=====================================================================

  Runtime Keyword Control:

    OVERRIDE "SHELL" DISABLE     Disable a keyword
    OVERRIDE "PR" ALIAS "PRINT"  Add a keyword alias
    OVERRIDES                    List current overrides

  Configuration File (basicpp.cfg):

    dialect=patb
    override PR ALIAS PRINT
    override ? ALIAS PRINT
    override SHELL DISABLE

  This loads automatically at startup next to bpp.exe.


=====================================================================
  10. MEMORY BUDGET REFERENCE
=====================================================================

  Default FreeDOS Pools (config.h):

    Pool                Size       Purpose
    ------------------- --------- --------------------------
    Program memory      32 KB     Stored program text
    Variable memory     16 KB     Runtime variable storage
    Scratch memory      16 KB     Tokenizer/parser workspace
    String pool         32 KB     String values during RUN
    Array pool          ~64 KB    DIM array elements
    ------------------- --------- --------------------------
    Total               ~160 KB   Fits within 512 KB

  Tuning Examples:

    256K system:
      PROGRAM_MEMORY_SIZE   16384L
      MAX_STRING_POOL       16384L
      MAX_PROGRAM_LINES     512
      MAX_ARRAY_ELEMENTS    2048

    640K system:
      PROGRAM_MEMORY_SIZE   65536L
      MAX_STRING_POOL       65536L
      MAX_PROGRAM_LINES     4096
      MAX_ARRAY_ELEMENTS    16384

    32-bit DOS/4GW:
      PROGRAM_MEMORY_SIZE   524288L
      MAX_STRING_POOL       1048576L
      MAX_PROGRAM_LINES     16384
      MAX_ARRAY_ELEMENTS    131072


=====================================================================
  11. BRUN / BYTECODE ON FREEDOS
=====================================================================

  The BRUN command compiles your program to bytecode and executes
  it through a stack-based virtual machine.

    10 PRINT "HELLO WORLD"
    20 FOR I=1 TO 10
    30 PRINT I;
    40 NEXT I
    50 END
    BRUN

  Output:
    Compiling 5 lines to bytecode...
    Compiled: 11 instructions, 11 string bytes
    HELLO WORLD
    12345678910

  On FreeDOS, BRUN always uses the portable VM interpreter.
  On Windows/Linux with MODULE "JIT", BRUN can generate native code.
  Results are identical -- only execution speed differs.


=====================================================================
  12. BUILD SCRIPTS REFERENCE
=====================================================================

  build-fd.bat:

    build-fd              Build 16-bit (default)
    build-fd 16           Build 16-bit (explicit)
    build-fd 32           Build 32-bit (DOS/4GW)
    build-fd clean        Remove all .obj files

  source\makefd (direct wmake):

    cd source
    wmake -f makefd                 Build 16-bit
    wmake -f makefd BITS=32         Build 32-bit
    wmake -f makefd clean           Clean

  Output: bpp.exe in the project root directory.


=====================================================================
  13. ADDING A DIALECT STEP-BY-STEP
=====================================================================

  Example: Adding GW-BASIC (GWBS)

  Step 1 - Edit source\makefd:
    Uncomment:  INCLUDE_GWBS = yes

  Step 2 - Check source\dialect\dialect.c:
    If dialect_register_gwbs() is guarded by
    #ifndef BPP_FREEDOS, remove that guard.

  Step 3 - Optionally change default (config.h):
    #undef BASICPP_DEFAULT_DIALECT
    #define BASICPP_DEFAULT_DIALECT DIALECT_GW_BASIC

  Step 4 - Rebuild:
    build-fd clean
    build-fd

  Step 5 - Verify:
    bpp
    DIALECT


=====================================================================
  14. ADDING A MODULE STEP-BY-STEP
=====================================================================

  Example: Adding the USB module

  Step 1 - Edit source\makefd:
    Uncomment:  INCLUDE_USB = yes

  Step 2 - Check boot.c / main.c:
    If mod_usb_register() is guarded by
    #ifndef BPP_FREEDOS, remove that guard.

  Step 3 - Rebuild:
    build-fd clean
    build-fd

  Step 4 - Verify:
    bpp
    INFO


=====================================================================
  15. STRIPPING FEATURES FOR MINIMAL BINARY
=====================================================================

  For the absolute smallest binary (PATB only, no file I/O,
  no graphics, no sound, no structured programming):

  makefd:
    INCLUDE_PATB     = yes
    INCLUDE_STDLIB   = yes
    (comment out all INCLUDE_xxx sections)

  config.h:
    PROGRAM_MEMORY_SIZE   16384L
    VARIABLE_MEMORY_SIZE  8192L
    SCRATCH_MEMORY_SIZE   8192L
    MAX_STRING_POOL       16384L
    MAX_PROGRAM_LINES     512

  Result: ~80-100 KB binary, ~48 KB memory pools.


=====================================================================
  16. TROUBLESHOOTING
=====================================================================

  "SORRY. Cannot allocate memory."
    Reduce pool sizes in config.h, free conventional memory,
    or use a 32-bit build.

  "Unknown dialect"
    Dialect not compiled in. Check makefd. Use DIALECT to list.

  Link error: "undefined reference to dialect_register_xxx"
    Enabled in makefd but #ifndef BPP_FREEDOS guard not removed.

  "WHAT?" on a valid keyword
    The keyword's section may not be compiled in.

  wmake errors
    Ensure OpenWatcom environment is set (OWSETENV.BAT).
