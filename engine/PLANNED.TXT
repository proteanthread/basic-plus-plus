1. Executive Summary & Core Compiler/VM Roadmap
-------------------------------------------------------------------------------

The BASIC++ v6.5.2 engine provides a unified, non-recursive, C17 runtime
executing interpreted AST statements and bytecode. To achieve full universal
dialect emulation and native compilation, the following core subsystems are
actively planned:

1.1 Native Whole-Program AOT Compiler (bppc.exe / bppc):
  - Whole-Program AST Restructuring: Analyzes global program structure, infers
    strict variable types, and eliminates runtime symbol lookup overhead.
  - Optional Line Numbers in Multi-Statement Files: Supports pure modern
    structured BASIC syntax without line numbers across multi-module projects.
  - Freestanding C17 Code Generation: Emits standard ISO C17 source code
    compiling via MSVC, GCC, Clang, or Zig into zero-dependency binaries.
  - Bytecode VM Stub Injection: Generates lightweight executable stubs
    embedding pre-compiled Universal IR bytecode.

1.2 Cross-Dialect Source-to-Source Transpiler (trans.exe / trans):
  - Bidirectional Dialect Translation: Translates between legacy dialects
    (GW-BASIC, QBASIC, Super BASIC, ECMA-116, Dartmouth) and BASIC++.
  - Dialect Metaprogramming & Introspection: Natively validates, translates,
    and generates language specifications using BASIC++ macros and metadata.

1.3 16-Bit Real Mode Segmented Memory Virtualization (vmem):
  - DEF SEG = segment: Full 20-bit address calculation (Phys = SEG*16 + OFF).
  - Memory Trapping & Bounds Validation: Safe emulation of IBM PC BIOS Data
    Area (0x0040:0x0000), CGA/MDA/EGA VRAM (0xB800:0x0000, 0xA000:0x0000).
  - CALL ABSOLUTE(args..., addr): Sandboxed machine-code execution via libcpu8086.

1.4 Multi-Modal Built-In Editors:
  - MS-DOS EDLIN (--edlin / mod_edlin.h): Line editor emulation (A, D, E, I,
    L, M, P, R, S, W, Q).
  - Bill Joy VI (--vi / mod_vi.h): Modal text editor (Normal, Insert, Visual, Ex).
  - WordStar 3.3/4.0 (--ws / mod_ws.h): Control-key diamond cursor control (^E,
    ^X, ^S, ^D, ^A, ^F) and block commands (^KB, ^KK, ^KV, ^KC, ^KY).

1.5 FujiNet Hardware Bus & IoT SIO Virtualization:
  - FujiNet Network Device (N:): URL stream I/O (OPEN "N:HTTP://...", #1).
  - TNFS Remote Filesystem: Native mounting of remote TNFS file archives.
  - Microcontroller Embedded HAL: Freestanding C17 for ESP32, STM32, RP2040, AVR.

2. Mainframe & Timesharing Dialects Gap Analysis
-------------------------------------------------------------------------------

Historical Mainframe & Timesharing Lineage:
  1964: DTSS Dartmouth BASIC (GE-225/635) -> 1965: GE Mark I/II Time-Sharing
  1968: HP 2000 Time-Shared BASIC --------> 1974: HP 3000 MPE / Business BASIC
  1969: DEC PDP-11 RSTS/E BASIC-PLUS ------> 1975: DEC BASIC-PLUS-2 / VAX BASIC
  1969: Tymshare Super BASIC (SDS 940) ----> 1970: IBM CALL/360 & VS-BASIC
  1970s: Univac 1100, Burroughs CANDE, CDC Kronos/NOS, Multics, Prime PRIMOS

2.1 Dartmouth DTSS BASIC (1st Ed 1964 to 7th Ed 1979 / SBASIC):
  - Planned Statements: DEF FN... / FNEND multi-line blocks, CHANGE array TO
    string$ / CHANGE string$ TO array, LINPUT, MARGIN, PAGE, TIM, TIME.
  - Matrix Operations: MAT INPUT, MAT PRINT, MAT READ, MAT +, MAT -, MAT *,
    MAT INV, MAT TRN, MAT ZER, MAT CON, MAT IDN.

2.2 GE Mark I & Mark II Time-Sharing BASIC:
  - Planned Statements: EDIT, BUILD, EXTRACT, MERGE, ALTER.

2.3 HP 2000 & HP 3000 Time-Shared BASIC (MPE 3000, Business BASIC, HP 3000/V):
  - Substring Slicing: A$(start, end) and A$(start) syntax without MID$/LEFT$.
  - File System: ASSIGN #ch TO file$, FILES file1, file2..., PRINT #ch, rec;,
    READ #ch, rec;, ADVANCE #ch, recs, RESTORE #ch.
  - System Commands: CATALOG, NAME, PURGE, PROTECT, UNPROTECT, LOCK, UNLOCK.

2.4 DEC Timesharing Lineage (TSS-8, BASIC-10, BASIC-PLUS, BP2, VAX BASIC):
  - Postfix Modifiers: stmt IF cond, stmt UNLESS cond, stmt FOR..., stmt WHILE,
    stmt UNTIL.
  - Virtual Array: DIM #ch, array(d1, d2) mapping multi-megabyte arrays to disk.
  - Record Mapping & Locking: MAP (map_name), FIELD #ch, GET #ch, PUT #ch,
    FIND #ch, KEY condition, RESTORE #ch, KEY key.
  - String Functions: CVT$%, CVT%$, CVT$F, CVTF$, XLATE$, COMP%, RAD$, NUM$,
    NUM1$, VAL%.

2.5 Tymshare Super BASIC (SDS 940, XDS 940, PDP-10):
  - Planned Capabilities: Command-line dynamic execution, INSPECT variable,
    MODIFY line, ON expr GOTO... ELSE line_def, colon/semicolon delimiters.

2.6 IBM Mainframe Lineage (CALL/360, VS-BASIC, ITF, 5100, Series/1, S/34/36/38, AS/400):
  - CALL/360 & VS-BASIC: LET required/optional, DEF FN local args, PRINT USING
    with EBCDIC, RESET, BACKSPACE #ch, REWIND #ch, PAUSE [prompt$].
  - Series/1 & S/34/36: ATTACH task, POST event, WAIT event, keyed file access.

2.7 Univac 1100 Series CTS / Exec 8 Time-Sharing BASIC:
  - 36-bit word length integer arithmetic, FILE #ch: "NAME", multi-file locks.

2.8 Burroughs B5500 / B6700 CANDE Time-Sharing BASIC:
  - Tagged word architecture, INTEGER/REAL ARRAY dynamic bounds, SCAN, WHILE.

2.9 CDC 6000 / Cyber Kronos & NOS Time-Sharing BASIC:
  - 60-bit floating-point math (14 decimal digits precision), Display Code 6-bit.

2.10 Honeywell Multics BASIC:
  - Segmented virtual memory addresses, structured IF...THEN...ELSE...END IF.

2.11 Data General Extended / TSS BASIC (Nova / Eclipse RDOS, AOS, TSS):
  - INPUT (timeout, max_chars) var$, OPEN (ch, "file", mode), READ (ch, rec, err).

2.12 Prime Computer Prime BASIC / BASIC/VM (PRIMOS):
  - Virtual Memory pointer binding, segmented string heap up to 32 MB.

2.13 ICL 1900 / 2900 Maximop & George 3 BASIC:
  - 24-bit/48-bit arithmetic models, DATA file redirection, TRACE ON/OFF.

2.14 Wang 3300 Timesharing BASIC & Harris Vulcan / VOS BASIC:
  - CRT character formatting (HEXOF$, VER$), sector READ #ch, sec, off; vars.

2.15 PICK System / MultiValue Pick BASIC:
  - Dynamic arrays with 3-level delimiters: Item Marks (CHR$(255)), Field Marks
    (CHR$(254)/AM), Value Marks (CHR$(253)/VM), Subvalue Marks (CHR$(252)/SVM).
  - Statements: EXTRACT, INSERT, REPLACE, DELETE, LOCATE.

2.16 MAI Basic Four / Thoroughbred / ProvideX Business BASIC:
  - ROUND statement precision, variable record lengths, KEYED/DIRECT file open,
    EXTRACT (read with lock), FIND (read with lock exception).

3. International Standards Gap Analysis
-------------------------------------------------------------------------------

3.1 ANSI X3.113-1987 & ECMA-116 Full BASIC:
  - PROGRAM prog_name ... END PROGRAM
  - Multi-line function blocks: DEF fn(args) ... END DEF
  - Subprograms: SUB sub(args) ... END SUB with CALL sub
  - Structured decision blocks: SELECT CASE ... CASE ... END SELECT
  - Exception Handling: WHEN EXCEPTION USE handler ... USE ... END WHEN (RETRY, CONTINUE).
  - Module 1 (Graphics): SET WINDOW, SET VIEWPORT, PLOT POINTS, PLOT LINES, PLOT AREA.
  - Module 2 (Real Time): WHEN EVENT event USE handler, WAIT DURATION, WAIT TIME.
  - Module 3 (Fixed Decimal): OPTION ARITHMETIC FIXED (BCD financial precision).
  - Module 5 (Character Input): GET KEY var$, INPUT TIMEOUT(sec) var$.

3.2 ANSI X3.60-1978 & ECMA-55 Minimal BASIC:
  - Fully conformant in BASIC++ v6.5.2.
