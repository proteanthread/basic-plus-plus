BASIC++ CHANGELOG
=================

4.4.3  (2026-07-02) -- Regression Audit, GRAPHICS Crash Fix & Platform Abstraction
---------------------------------------------------------------------------------
  Regression Audit & Critical Bug Fixes:
  - Fixed a crash when executing the Atari 8-bit `GRAPHICS` command by adding the missing `case KW_GRAPHICS:` dispatch entry in `parser.c`. The keyword was registered in the lexer but never wired to the parser dispatch table.
  - Removed a spurious `lexer_next(lex)` call in `pi_parse_graphics` that double-consumed the keyword token, eating the first digit of the mode expression.
  - Removed a stale debug `fprintf` in `gw_console_write_char` (`console.c`) that printed `"DEBUG: gw_console_write_char g_out_fp is NOT NULL"` to stderr on every program run.
  - Fixed `gfxbuf_clear` to also clear the SDL pixel buffer when SDL is active, resolving CLS having no effect in graphics mode (SDL window retained old graphics).
  - Fixed `gfxbuf_paint` bounds checking to use dynamic SDL dimensions (`gw_sdl2_get_width`/`gw_sdl2_get_height`) instead of hardcoded `GFX_WIDTH`/`GFX_HEIGHT` (320x200), allowing PAINT to work correctly in higher-resolution SDL modes (e.g. 640x480 SCREEN 12).
  - Implemented actual `vdev_sleep` for Linux/POSIX using `platform_sleep_ms` and `gw_sdl2_delay` for SDL mode. Previously the Linux branch was a no-op, causing DELAY/SLEEP commands to do nothing on Linux.
  - Replaced raw `strdup()` call in `handle_environ` (`interp.c`) with `plat_strdup()` to fix MSVC deprecation warnings.
  - Implemented full QBASIC-style `IF...THEN...ELSEIF...ELSE...END IF` block parsing logic in `parser_flow.c`.
  - Fixed a critical logical error in nested `ELSEIF`/`ELSE` block parsing by introducing a `jumped_to_else` flag in `RuntimeState` to properly track execution depth bypassing rather than erroneously relying on `block_if_depth`.
  Platform Abstraction & OS API Isolation:
  - Abstracted all OS-specific keyboard and TTY detection APIs from `console.c` into `platform.c` portable functions: `platform_stdin_is_tty`, `platform_stdin_is_redirected`, `platform_kbhit`, `platform_getch`, `platform_nb_read_char`, and `platform_sleep_ms`.
  - Removed direct `_isatty`/`isatty`, `_kbhit`/`_getch`, `termios`, `select()`, `GetConsoleMode`, `GetFileType`, `PeekNamedPipe`, `ReadFile` calls from `console.c`, replacing them with the new platform abstraction layer.
  - Removed OS-specific headers (`<io.h>`, `<conio.h>`, `<unistd.h>`, `<termios.h>`, `<sys/select.h>`, `<sys/types.h>`, `<sys/stat.h>`) from `console.c` — these now live exclusively in `platform.c`.
  - Added `<conio.h>` (Windows) and `<termios.h>`, `<sys/select.h>`, `<sys/types.h>`, `<sys/stat.h>` (POSIX) to `platform.c` includes for the new abstraction functions.

4.4.2  (2026-07-02) -- SDL SCREEN Mode Bounds & Auto-Initialization Bug Fix
---------------------------------------------------------------------------------
  SDL Renderer & Boundary Safety:
  - Fixed a critical memory corruption/crash bug where higher-resolution SCREEN modes (such as SCREEN 11/12 with 30 rows or Hercules SCREEN 3 with 90 columns) caused out-of-bounds writes to the fixed `g_screen_chars[25][80]` grid array.
  - Sized `g_screen_chars` to `[MAX_GRID_ROWS][MAX_GRID_COLS]` (`40x100`) and clamped column and row counts inside `gw_sdl2_set_mode` to prevent buffer overflows.
  - Updated screen scrolling, character read-back (`gw_sdl2_get_char`), and cursor rendering (`gw_sdl2_write_char_cursor`) to use dynamic bounds checks.
  - Implemented dynamic auto-initialization of SDL when graphics drawing operations (like `PSET`, `LINE`, `CIRCLE`, `PAINT`) or any `SCREEN` commands are executed in the console-only build.
