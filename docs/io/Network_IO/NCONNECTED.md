# NCONNECTED

## 1. Syntax & Parameters
`status = NCONNECTED(socket_id)`

## 2. Description & Usage
Checks if a network socket is actively connected to a remote host. Returns -1 (True) if connected, 0 (False) if disconnected. Edge Cases: Can return False if the remote host abruptly closed the TCP connection via RST before the next read operation.

## 3. Code Examples
```basic
10 IF NCONNECTED(1) = 0 THEN PRINT "CONNECTION LOST": END
```

## 4. Internal C-Source Mapping
Mapped in `source/io/builtins_net.c` via `builtin_nconnected()`.

## 5. Implementation Details
Parser Expectation: Single integer argument. Mutability: Read-only. Execution Path: Checks internal socket state tracking flags within the VDev net driver. Troubleshooting: If it incorrectly reports connected, attempt to write; dead peers may only be detected upon write failure.

## 6. Cross-References / See Also
- `NSTATUS`
- `NEOF`

## 7. Historical Context
Introduced to provide explicit connection state tracking in BASIC++.

## 8. Manual Testing Guide
1. Run `basicpp-console.exe`.
2. Try `PRINT NCONNECTED(99)`.
3. Verify it gracefully returns 0 for an unopened socket.
