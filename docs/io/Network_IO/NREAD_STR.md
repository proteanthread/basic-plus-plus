# NREAD_STR

## 1. Syntax & Parameters
`data$ = NREAD$(socket_id, max_bytes)`

## 2. Description & Usage
Reads up to `max_bytes` from the network socket and returns it as an 8-bit clean BASIC++ string. Edge Cases: If the socket is non-blocking and no data is available, returns an empty string. If `max_bytes` exceeds String Pool capacity, causes OOM.

## 3. Code Examples
```basic
10 PACKET$ = NREAD$(1, 512)
20 PRINT "RECEIVED: "; PACKET$
```

## 4. Internal C-Source Mapping
Mapped in `source/io/builtins_net.c` via `builtin_nread_str()`.

## 5. Implementation Details
Parser Expectation: Two integer arguments. Returns String. Mutability: Mutates String Pool and advances network stream pointer. Execution Path: Calls `recv()` up to `max_bytes`, handles socket chunking, and writes directly into a new string struct. Troubleshooting: Use `NBYTESWAITING` before `NREAD$` to prevent blocking on synchronous sockets.

## 6. Cross-References / See Also
- `NWRITE`
- `NBYTESWAITING`

## 7. Historical Context
Implements the core socket `recv` function while adhering to the BASIC++ string suffix mandate.

## 8. Manual Testing Guide
1. Run `basicpp-console.exe`.
2. `PRINT NREAD$(1, 10)`.
3. Verify it returns empty if not connected.
