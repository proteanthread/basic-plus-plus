# EXISTS

## 1. Syntax & Parameters
`result = EXISTS(filename$)`
- `filename$`: A string containing the relative or absolute path of the file to check.

## 2. Description & Usage
Returns a boolean integer (`1` for True, `0` for False) indicating whether the specified file currently exists on the virtual or host filesystem. It is the definitive method for preventing `File not found` (Error 53) prior to executing `OPEN` commands, acting as a preemptive filesystem probe.

## 3. Code Examples
```basic
10 F$ = "CONFIG.INI"
20 IF EXISTS(F$) THEN OPEN "I", 1, F$ ELSE PRINT "Missing file!"
```

## 4. Internal C-Source Mapping
- Function: `builtin_exists` in `source/io/builtins_fileio.c`
- Registration: `builtins.c` under `KW_EXISTS`

## 5. Implementation Details
Uses the `platform.c` abstraction `vfs_stat()` or equivalent `access()` API to determine file existence. It does not actually consume file handles or open the file stream, making it highly performant.
**Edge Cases & Boundary Conditions:**
- **Disk Access Edge Cases**: If the filesystem has a file but the interpreter lacks read permissions, `EXISTS` will gracefully return `0` rather than causing an unhandled permission panic.
- **Type Mismatch Exceptions**: Supplying a numeric literal instead of a string (e.g., `EXISTS(123)`) triggers a `TYPE MISMATCH`.
- **Troubleshooting**: If `EXISTS` returns `0` for a file you are certain is present, check your working directory using `CURDIR$`. Filesystem paths in BASIC++ are case-sensitive on Linux and case-insensitive on Windows.

## 6. Cross-References / See Also
- `FILESIZE`, `FILEMOD$`, `OPEN`

## 7. Historical Context
GW-BASIC lacked a native file existence check; programmers had to rely exclusively on `ON ERROR GOTO` to trap "File not found" errors upon execution of `OPEN`. `EXISTS` provides a clean, modern probing mechanism modeled after modern script engines.

## 8. Manual Testing Guide
**Interactive Test:**
1. Launch `basicpp-console.exe`.
2. Type `PRINT EXISTS("basicpp-console.exe")` and verify it returns `1`.
3. Type `PRINT EXISTS("DOESNOTEXIST.XYZ")` and verify it returns `0`.

**Scripted Test (.BAS):**

