# BASIC++ v6.5.2 Keyword Reference

## 1. OVERVIEW

This document provides a master index of all BASIC++ keywords organized by category. BASIC++ v6.5.2 recognizes 367 keywords defined in the BppKeywordId enum in engine/include/lexer/lexer.h. The exact set of keywords available at runtime depends on the active dialect and the build edition.
