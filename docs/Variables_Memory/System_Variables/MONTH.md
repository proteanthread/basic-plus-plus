# MONTH

## 1. Syntax & Parameters

**Syntax:**
```basic
MONTH
```
**Parameters:**
- None. `MONTH` is a read-only Numeric System Variable.

## 2. Description & Usage

Returns the current month of the year as an integer between 1 (January) and 12 (December).
Because it is a system variable, it does not require parentheses. It is read-only; you cannot assign a value to it (e.g., `MONTH = 1` will throw a syntax error).

## 3. Code Examples

**Example:**
```basic
PRINT "The current month is: "; MONTH
```
*Expected Output:*
```text
The current month is: 7
```

## 5. Implementation Details

Implemented as a system variable keyword. The lexer produces `KW_MONTH`. During expression parsing (`parser_expr.c`), `time()` and `localtime()` from the standard C library are called. The parser adds 1 to the `tm_mon` field (which is naturally 0-indexed in C) and pushes the result onto the value stack as an integer value. It is read-only.
If the C standard library's time functions fail or are unavailable on a specific embedded platform, the value may default to the system epoch (1970). The memory allocated for the string pool (for string variables) is managed by the garbage collector and freed appropriately. If you alter the system clock while a script is running, the next invocation of `MONTH` will reflect the updated clock.

At runtime, the `ast_interpreter.c` engine performs a post-order traversal to evaluate all child expression nodes before triggering the final execution hook. This two-pass system guarantees that syntax errors (like mismatched parentheses or missing commas) are caught globally before any destructive side-effects occur. Once parsed, the `AST_Node` resides in memory until `NEW` or `RUN` is executed, at which point the entire arena is zeroed out to prevent memory leaks.
