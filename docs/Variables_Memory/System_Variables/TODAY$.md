# TODAY$

## 1. Syntax & Parameters
`TODAY$`

**Parameters:**
None.

## 2. Description & Usage
`TODAY$` is a system-level string variable that returns the current UTC date and time in ISO 8601 format. It is a read-only variable maintained by the BASIC++ runtime environment.

This variable provides a standardized, universally recognized timestamp format suitable for logging, network transactions, and interoperability with modern external systems.

**Return Value:**
Returns a 20-character string in the format `YYYY-MM-DDTHH:MM:SSZ`.

## 3. Code Examples
```basic
10 PRINT "Current UTC Time: "; TODAY$
20 LET T$ = TODAY$
30 PRINT "Year: "; LEFT$(T$, 4)
```

## 5. Implementation Details
When `TODAY$` is encountered by the parser, it invokes the C standard library `time()` and `gmtime()` functions to retrieve the current UTC time. It formats the resulting `struct tm` into a 20-character ISO 8601 string (`"%04d-%02d-%02dT%02d:%02d:%02dZ"`) and stores it in the interpreter's string pool (`strpool_store`). The string is then returned as a `BValue`. 
Since it leverages `gmtime()` rather than `localtime()`, the output is always UTC, independent of the host operating system's timezone.

**Mutability:** Read-only. Attempting to assign to `TODAY$` (e.g., `TODAY$ = "..."`) will result in a Syntax Error.

## 7. Historical Context
`TODAY$` is entirely unique to BASIC++ and does not exist in GW-BASIC, QBasic, or the ECMA-116 standard. It was introduced to provide modern API and logging compatibility by adhering to the ISO 8601 standard for UTC timestamps, a concept that did not exist in early 8-bit or 16-bit dialects.
