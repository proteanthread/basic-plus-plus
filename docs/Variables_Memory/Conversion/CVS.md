# CVS

## 1. Syntax & Parameters
`float_val! = CVS(4_byte_str$)`
- `4_byte_str$`: A string containing exactly 4 bytes of raw binary data.

## 2. Description & Usage
Converts a 4-byte binary string into a Single-Precision floating-point numeric value (`!`).

## 3. Code Examples
```basic
10 OPEN "R", 1, "FLOATS.DAT", 4
20 FIELD 1, 4 AS S_STR$
30 GET 1, 1
40 S_VAL! = CVS(S_STR$)
50 CLOSE 1
```

## 4. Internal C-Source Mapping
- Function: `builtin_cvs` in `source/variables/builtins_conv.c`
- Registration: `builtins.c` under `KW_CVS`

## 5. Implementation Details
Copies 4 bytes from the string into an IEEE 754 32-bit `float`.
**Edge Cases & Boundary Conditions:**
- Triggers `Illegal function call` if the string is less than 4 bytes.
- Converts to infinity or NaN seamlessly without causing runtime panics if the raw bytes construct invalid floats.
- **Troubleshooting**: Due to single-precision rounding limits, the resulting number might have minor inaccuracies compared to literal assignments. Use `CVD` for precision.

## 6. Cross-References / See Also
- `MKS$`, `CVI`, `CVD`, `FIELD`

## 7. Historical Context
Replaces legacy MBF floating point formats with modern IEEE representations.

## 8. Manual Testing Guide
**Interactive Test:**
1. Launch `basicpp-console.exe`.
2. Type `PRINT CVS(MKS$(3.14))`
3. Verify it prints approx `3.14`.

**Scripted Test (.BAS):**
```basic
10 F! = 3.1415
20 G$ = MKS$(F!)
30 H! = CVS(G$)
40 IF ABS(F! - H!) < 0.01 THEN PRINT "SINGLE FLOAT OK"
```
