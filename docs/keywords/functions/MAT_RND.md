# `MAT_RND` Matrix Random Fill Statement

## 1. BASIC Usage and Keyword Definition

The `MAT ... = RND` statement populates all elements of a matrix with pseudo-random floating-point numbers in the range $[0.0, 1.0)$.

### Syntax Signatures:
```basic
MAT A = RND
MAT A = RND(rows%, cols%)
```

### Operational Rules:
- Fills every element $A_{i,j}$ with uniform pseudo-random values generated by the VM random number generator.

---

## 2. Code Examples

```basic
10 DIM M(4, 4)
20 MAT M = RND
30 PRINT "Matrix populated with random numbers."
```
