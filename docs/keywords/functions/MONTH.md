# `MONTH` Month Number Function

## 1. BASIC Usage and Function Definition

The `MONTH` function returns the current calendar month as an integer from $1$ (January) to $12$ (December).

### Syntax Signatures:
```basic
mon% = MONTH
mon% = MONTH()
```

### Operational Rules:
- Returns an integer in range $1 \le \text{month} \le 12$.

---

## 2. Code Examples

```basic
10 PRINT "Month Number: "; MONTH
```
