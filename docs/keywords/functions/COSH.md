# `COSH` Hyperbolic Cosine Function

## 1. BASIC Usage and Function Definition

The `COSH` function computes the hyperbolic cosine of a numeric argument:

$$\cosh(x) = \frac{e^x + e^{-x}}{2}$$

### Syntax Signatures:
```basic
result# = COSH(numeric_expression)
```

### Operational Rules:
- Returns real value $\ge 1.0$.

---

## 2. Code Examples

```basic
10 PRINT COSH(0) : REM Outputs 1
```
