# `DAY` Day of the Month Function

## 1. BASIC Usage and Function Definition

The `DAY` function returns the current calendar day of the month as an integer from $1$ to $31$.

### Syntax Signatures:
```basic
day_num% = DAY
day_num% = DAY()
```

### Operational Rules:
- Evaluates the current local day of the month ($1 \le \text{day} \le 31$).

---

## 2. Code Examples

```basic
10 PRINT "Day of Month: "; DAY
```
