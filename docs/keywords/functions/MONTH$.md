# `MONTH$` Current Month Name String Function

## 1. BASIC Usage and Function Definition

The `MONTH$` function returns the current calendar month name as an English text string (e.g. `"January"`, `"August"`, `"December"`).

### Syntax Signatures:
```basic
name$ = MONTH$
name$ = MONTH$()
```

### Operational Rules:
- Returns a reference-counted string containing the full month name.

---

## 2. Code Examples

```basic
10 PRINT "Current Month: "; MONTH$
```
