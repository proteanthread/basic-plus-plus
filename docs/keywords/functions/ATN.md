# `ATN` Arctangent Trigonometric Function

## 1. BASIC Usage and Function Definition

The `ATN` function computes the principal arctangent (inverse tangent) of a numeric argument in radians.

### Syntax Signatures:
```basic
radians# = ATN(numeric_expression)
```

### Operational Rules:
- Accepts any real numeric value from $-\infty$ to $+\infty$.
- Returns radians in range $(-\pi/2, +\pi/2)$.

---

## 2. Code Examples

```basic
10 PI# = 4.0 * ATN(1.0)
20 PRINT "Calculated Pi = "; PI#
```
