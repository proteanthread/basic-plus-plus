# `SIN` Sine Trigonometric Function

## 1. BASIC Usage and Function Definition

The `SIN` function calculates the trigonometric sine of an angle expressed in radians.

### Syntax Signatures:
```basic
result# = SIN(angle_radians)
```

### Operational Rules:
- Returns real float in range $[-1.0, +1.0]$.

---

## 2. Code Examples

```basic
10 PRINT SIN(0)                 : REM Outputs 0
20 PRINT SIN(1.570796326794896) : REM Outputs 1 (approx PI/2)
```
