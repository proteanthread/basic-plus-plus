# `ABS` Absolute Value Function

## 1. BASIC Usage and Function Definition

The `ABS` function returns the absolute value (magnitude) of a numeric expression, converting negative values to positive while leaving positive values and zero unchanged.

### Syntax Signatures:
```basic
result = ABS(numeric_expression)
```

### Operational Rules:
- Returns non-negative value $|x|$.
- Preserves integer and floating-point precision.

---

## 2. Code Examples

```basic
10 PRINT ABS(-42.5)  : REM Outputs 42.5
20 PRINT ABS(100)    : REM Outputs 100
```
