# `YEAR` Current Calendar Year Function

## 1. BASIC Usage and Function Definition

The `YEAR` function returns the 4-digit calendar year (e.g. `2026`) from the local system clock.

### Syntax Signatures:
```basic
yr% = YEAR
yr% = YEAR()
```

### Operational Rules:
- Returns full 4-digit Gregorian calendar year.

---

## 2. Code Examples

```basic
10 PRINT "Current Year: "; YEAR
```
