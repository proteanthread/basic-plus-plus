# `COS` Cosine Trigonometric Function

## 1. BASIC Usage and Function Definition

The `COS` function computes the trigonometric cosine of an angle expressed in radians.

### Syntax Signatures:
```basic
result# = COS(angle_radians)
```

### Operational Rules:
- Returns real float in range $[-1.0, +1.0]$.

---

## 2. Code Examples

```basic
10 PRINT COS(0)                 : REM Outputs 1
20 PRINT COS(3.141592653589793) : REM Outputs -1
```
