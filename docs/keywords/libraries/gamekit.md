# `gamekit` Game Development Asset & Animation Library

## 1. Library Overview & Usage

The `gamekit` library provides high-level sprite sheet animation, sound effect triggers, tilemap loaders, and gamepad input helpers.

### Features:
- **Sprite Animation**: Frame-by-frame animation sequencing from BGI sprite sheets.
- **Audio Channels**: Polyphonic background music and sound effects playback.

---

## 2. BASIC Example

```basic
10 SET SCREEN 320, 200, 8
20 PRINT "GameKit engine initialized."
```
