# `donkeykong` Multi-Tier Girder Platform & Ladder Game Template

## 1. Library Overview & Usage

The `donkeykong` game template provides tiered girder collision detection, diagonal rolling barrel physics, and ladder climbing mechanics in BGI.

### Features:
- **Girder Slopes**: Sloped platform collision slopes and ladder bounds.
- **Rolling Hazard Physics**: Rolling barrel momentum, gravity, and ladder drop chances.

---

## 2. BASIC Example

```basic
10 SET SCREEN 320, 200, 8
20 LINE (20, 180)-(300, 175), 4 : REM Sloped girder
30 PRINT "Platform girder active."
```
