# `REFORMAT` Program Source Pretty-Print Statement

## 1. BASIC Usage and Keyword Definition

Reformats, indents, and capitalizes BASIC source code in memory according to standard style guidelines.

### Syntax Signatures:
```basic
REFORMAT
```

### Operational Notes:
- Formatting utility command.

---

## 2. Code Examples

```basic
REFORMAT : REM Cleans up active program formatting
```
