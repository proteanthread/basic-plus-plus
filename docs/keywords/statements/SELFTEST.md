# `SELFTEST` Built-in Diagnostics Execution Command

## 1. BASIC Usage and Keyword Definition

Executes the full built-in engine diagnostics self-test suite (Lexer, Memory, Strings, Variables, Arrays).

### Syntax Signatures:
```basic
SELFTEST
```

### Operational Notes:
- Outputs PASS for all functional core modules.
