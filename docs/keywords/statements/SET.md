# `SET` Environment Variable Configuration Statement

## 1. BASIC Usage and Keyword Definition

Sets an environment variable or runtime engine configuration property.

### Syntax Signatures:
```basic
SET var_name$ = string_value$
```

### Operational Notes:
- Mutates runtime configuration and OS environment block.

---

## 2. Code Examples

```basic
10 SET "BPP_DIALECT" = "QBASIC"
```
