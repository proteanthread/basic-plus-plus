# `HOME` Cursor Home and Screen Clearing Statement

## 1. BASIC Usage and Keyword Definition

Clears the text screen and positions the cursor at row 1, column 1 (Apple II style).

### Syntax Signatures:
```basic
HOME
```

### Operational Notes:
- Equivalent to CLS in GW-BASIC.

---

## 2. Code Examples

```basic
10 HOME
20 PRINT "Top-left of Apple II screen"
```
