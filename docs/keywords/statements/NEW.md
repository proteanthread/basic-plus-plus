# `NEW` Erase Program Memory Command

## 1. BASIC Usage and Keyword Definition

Erases all program lines from memory, clears all variables, closes all files, and resets the interpreter state.

### Syntax Signatures:
```basic
NEW
```

### Operational Notes:
- Emits Ok / Ready prompt depending on edition.

---

## 2. Code Examples

```basic
NEW : REM Clear workspace for a new program
```
