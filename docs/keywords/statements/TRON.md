# `TRON` Turn On Line Tracing Statement

## 1. BASIC Usage and Keyword Definition

Enables line number execution tracing, displaying each executed line number in brackets (e.g. '[10][20]').

### Syntax Signatures:
```basic
TRON
```

### Operational Notes:
- Equivalent to TRACE ON.

---

## 2. Code Examples

```basic
10 TRON
20 PRINT "Hello with tracing"
30 TROFF
```
