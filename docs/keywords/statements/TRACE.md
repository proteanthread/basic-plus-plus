# `TRACE` Execution Tracing Statement

## 1. BASIC Usage and Keyword Definition

Toggles line-by-line program execution tracing on the console.

### Syntax Signatures:
```basic
TRACE ON | OFF
```

### Operational Notes:
- Displays executed line numbers during runtime.

---

## 2. Code Examples

```basic
10 TRACE ON
20 X = 10
30 Y = 20
40 TRACE OFF
```
