# LO

## 1. Syntax & Parameters
`LO(<integer_expression>)`

* `<integer_expression>`: A numeric expression that evaluates to an integer.

## 2. Description & Usage
The `LO` function returns the low-order (least significant) byte of an integer expression. It isolates the lower 8 bits (bits 0-7) of the given integer and returns them as a new integer value. This function is essential for low-level systems programming, graphics, and reading specific byte sequences from memory or files.

## 3. Code Examples
```basic
10 N = &H1234
20 PRINT LO(N)
' Output: 52 (which is &H34)
```

## 4. Internal C-Source Mapping
* Source File: `source/math/builtins_math.c`
* Function: `builtin_lo()`

## 5. Implementation Details
* **Parser/Evaluator:** Recognized as a pure math function (`FSAFE_PURE`, `FCAT_MATH`). Takes exactly one argument and returns an integer (`FRET_INT`).
* **Bitwise Logic:** Extracts the value by casting the argument to a `long` and masking it with `0xFF` (`val & 0xFF`).
* **Data Types:** Uses `bval_to_int()` to convert the parameter. Floating-point numbers are implicitly truncated to integers before the bitwise mask is applied.
* **Troubleshooting:** No exceptional error states typically occur. Ensure the logic accounts for negative numbers which are handled by standard two's complement bitwise extraction.

## 8. Manual Testing Guide
To manually test `LO`:
1. Open the BASIC++ console: `basicpp-console.exe` (Windows) or `./baspp-console` (Linux).
2. Enter:

3. The expected output is `205` (which is the decimal equivalent of `&HCD`).
