# TIME$

## 1. Syntax & Parameters
`TIME$`

- **Parameters**: None.
- **Return Type**: String (Format: `HH:MM:SS`)

## 2. Description & Usage
The `TIME$` system variable returns the current system time as a string formatted as `HH:MM:SS` (using a 24-hour clock). 
It evaluates the host machine's local time at the exact moment of execution. 
This function is essential for measuring elapsed real-world time in a human-readable format, displaying digital clocks, and scheduling time-based events within scripts.

## 3. Code Examples
```basic
10 PRINT "Current time: "; TIME$
20 H = VAL(LEFT$(TIME$, 2))
30 IF H < 12 THEN PRINT "Good morning!" ELSE PRINT "Good afternoon/evening!"
```

## 5. Implementation Details
Located in `parser_expr.c` (around line 1343), when `KW_TIME_FUNC` is parsed, the interpreter fetches the system time via `time()` and `localtime()`. 
A stack buffer is populated using `sprintf(buf, "%02d:%02d:%02d", tm->tm_hour, tm->tm_min, tm->tm_sec);`. 
This creates an 8-character string, which is then allocated to the string pool via `strpool_store(&rt->strpool, buf, 8)` and passed to the value stack as a `BVal` string.

Because it uses `localtime()`, the output correctly respects the host OS's timezone and daylight saving time settings.

## 7. Historical Context
Like `DATE$`, `TIME$` was a read/write pseudo-variable in GW-BASIC and QBASIC (e.g., `TIME$ = "12:00:00"`). BASIC++ supports reading `TIME$` identically to legacy implementations, outputting exactly 8 characters on a 24-hour scale.
