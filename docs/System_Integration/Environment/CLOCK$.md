# CLOCK$

## 1. Syntax & Parameters
`CLOCK$`

- **Parameters**: None.
- **Return Type**: String (Format: `YYYY-MM-DDTHH:MM:SSZ`, UTC timezone)

## 2. Description & Usage
The `CLOCK$` system variable retrieves the current system date and time as a fully formatted ISO 8601 string in the UTC timezone. 
It combines the functionality of date and time into a single, unified UTC timestamp representation.
This variable is particularly useful for timestamping log files, database entries, or any application that requires a precise recording of when an event occurred in a standardized timezone. 
It is evaluated dynamically at runtime, ensuring that every invocation captures the exact UTC time at that specific moment of execution.

## 3. Code Examples
```basic
10 PRINT "Current Timestamp: "; CLOCK$
20 OPEN "app.log" FOR APPEND AS #1
30 PRINT #1, "[" + CLOCK$ + "] Application started."
40 CLOSE #1
```

## 5. Implementation Details
When the parser encounters `KW_CLOCK_FUNC` during expression evaluation (around line 1415 in `parser_expr.c`), it queries the underlying C standard library `time()` and `localtime()` functions. 
A buffer of 64 characters is allocated on the C stack. It formats the system time using `sprintf` with the pattern `"%04d-%02d-%02d %02d:%02d:%02d"`, extracting `tm->tm_year + 1900`, `tm->tm_mon + 1`, `tm->tm_mday`, `tm->tm_hour`, `tm->tm_min`, and `tm->tm_sec` from the `struct tm` populated by `localtime()`. 
The resulting 19-character string is then dynamically pushed into the string pool via `strpool_store(&rt->strpool, buf, 19)`, and a `BVal` of type string is pushed onto the expression value stack (`val_stack`).

If the system time is unavailable or `localtime()` returns a corrupted structure, the behavior relies on the standard library's fallback mechanisms, which could result in epoch timestamps.

## 7. Historical Context
`CLOCK$` is an extended feature in BASIC++ that does not exist in standard GW-BASIC or QBASIC. In legacy dialects, developers were forced to concatenate `DATE$` and `TIME$` manually (e.g., `DATE$ + " " + TIME$`). `CLOCK$` provides a standardized, locale-independent timestamp format that aligns more closely with modern logging and database standards.
