# ENVIRON$

## 1. Syntax & Parameters
`val$ = ENVIRON$(env_var$)`
- `env_var$`: A string denoting the name of the system environment variable to read (e.g., `"PATH"` or `"USER"`).

## 2. Description & Usage
Retrieves the string value of a specified host operating system environment variable. Essential for scripts that need to adapt to the host OS, check user profiles, or determine installation paths dynamically.

## 3. Code Examples
```basic
10 U$ = ENVIRON$("USERNAME")
20 PRINT "Welcome, "; U$; "!"
```

## 4. Internal C-Source Mapping
- Function: `builtin_environ` in `source/core/builtins.c`
- Registration: `builtins.c` under `KW_ENVIRON_STR`

## 5. Implementation Details
Uses standard C library `getenv()`. The returned pointer is safely duplicated into the transient string pool to prevent memory corruption from OS-level changes.
**Edge Cases & Boundary Conditions:**
- If the environment variable is not found, `ENVIRON$` explicitly returns a safe empty string `""` rather than triggering a null-pointer exception or error.
- Passing empty strings (`ENVIRON$("")`) is a no-op and returns `""`.
- **Troubleshooting**: Environment variables are case-sensitive on Linux/Unix systems (`"path"` vs `"PATH"`). If the script behaves erratically across platforms, ensure exact uppercase matching for system defaults.

## 6. Cross-References / See Also

## 7. Historical Context
In GW-BASIC, `ENVIRON$` allowed primitive access to DOS parameters. In BASIC++, it provides a powerful bridge to modern Linux and Windows environments for cross-platform portability.

## 8. Manual Testing Guide

2. Type `PRINT ENVIRON$("PATH")`
3. Verify it prints your system's path string.

**Scripted Test (.BAS):**
