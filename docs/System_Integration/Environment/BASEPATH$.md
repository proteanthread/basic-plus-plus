# BASEPATH$

## 1. Syntax & Parameters

**Syntax:**
`BASEPATH$`

**Parameters:**
None. `BASEPATH$` is a parameterless system string function.

## 2. Description & Usage

The `BASEPATH$` function returns the full absolute path of the current working directory as a string.

## 3. Code Examples

**Example 1: Basic String Assignment**
```basic
P$ = BASEPATH$
PRINT "Current working directory path: " + P$
```
