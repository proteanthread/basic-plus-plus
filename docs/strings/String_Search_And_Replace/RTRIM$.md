# RTRIM$

### 1. Syntax & Parameters
`RTRIM$(target$)`
- `target$`: The original string expression to strip trailing whitespace from.

### 2. Description & Usage
The `RTRIM$` function removes all trailing space characters (` `) from the right side of the provided string and returns the cleaned string.

### Detailed Behavioral Edge Cases and Constraints:
- **Null or Empty Target String:** Safely returns an empty string.
- **Strings with Only Spaces:** Returns an empty string.
- **Leading Spaces:** Spaces at the start of the string are preserved entirely.
- **Tab Characters:** As with `TRIM$`, tab characters (`CHR$(9)`) are left intact. Only standard ASCII spaces (`CHR$(32)`) are removed.

### 3. Code Examples
```basic
10 A$ = "   HELLO WORLD   "
20 PRINT ">" + RTRIM$(A$) + "<" ' Output: >   HELLO WORLD<
```

### 5. Implementation Details
Iterates an index pointer `i` starting from `len`, decrementing as long as `s[i-1] == ' '`.

### In-Depth Architectural Narrative:
- **Struct Mutations:** It captures the length offset and calls `strpool_store(&state->strpool, s, i)` returning a `BValue` referencing the truncated length. This effectively crops the string length without shifting the memory pointer.
- **Error States & Fault Tolerance:** Same robust degradation as `TRIM$` for type mismatches.
- **Modification Constraints:** 
  - *What CAN be changed:* Can be expanded to strip tabs or form feeds if standard constraints allow.
  - *What CANNOT be changed:* The index boundary condition (`i > 0`) must remain to prevent out-of-bounds underflows when scanning strings containing only spaces.
