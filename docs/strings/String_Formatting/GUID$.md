# GUID$

## 1. Syntax & Parameters
`GUID$`

## 2. Description & Usage
Generates a random Version 4 Universally Unique Identifier (UUID) string formatted as `xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx`. The generation relies entirely on the internal deterministic random number generator, ensuring that if you seed the `RND` sequence (e.g. via `RND(-1)` or `RANDOMIZE`), the sequence of generated `GUID$` values will also be perfectly repeatable.

## 3. Code Examples
```basic
10 RANDOMIZE 42
20 PRINT "Trace ID: " + GUID$
```
Output:
`Trace ID: 7b8b2e10-4592-4116-b8e7-bd4587391942`

## 4. Internal C-Source Mapping
Implemented in `builtins_string.c` via the `builtin_guid()` function.
Registered in `funcreg.c` under the `FCAT_STRING` category.

## 5. Implementation Details
The `builtin_guid()` function calls the LCG PRNG engine 16 times consecutively to extract 16 random bytes. It sets the version nibble to `4` and the variant nibble to `8`, `9`, `A`, or `B` according to the RFC 4122 v4 UUID specification. It then formats the result into a 36-character ASCII string (including hyphens) and stores it in the string pool.
**Troubleshooting**: If memory exhaustion occurs during heavy `GUID$` usage in a loop, you may need to increase string pool sizes. Since the UUID algorithm consumes 16 random seed states per invocation, be aware that it rapidly advances the internal `RND` state machine.

## 6. Cross-References / See Also

## 7. Historical Context
`GUID$` is an original BASIC++ extension not found in GW-BASIC, QBASIC, or standard ECMA-116. It was introduced to support modern web, database, and telemetry scenarios directly within BASIC scripts.

## 8. Manual Testing Guide
Run `basicpp-console.exe`.
Type `PRINT GUID$` and verify a standard 36-character v4 UUID is printed to the console.
To test determinism, type `PRINT RND(-42) : PRINT GUID$` multiple times; the same UUID string should be generated each time immediately following the seed reset.
