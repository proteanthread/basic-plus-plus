# GUID$

## 1. Syntax & Parameters
`GUID$`

---

## 2. Description & Usage
Generates a standard 36-character UUIDv4 (Universally Unique Identifier version 4) string.
The output format is:
`123e4567-e89b-12d3-a456-426614174000`

- Consists of 32 hexadecimal digits displayed in 5 groups separated by hyphens.
- Conforms to standard RFC 4122 UUIDv4 specification.
- Uses high-entropy random numbers generated by the internal engine.

---

## 3. Code Examples
```basic
10 REM Generate a UUID
20 LET u$ = GUID$
30 PRINT "Generated UUID: "; u$
```
