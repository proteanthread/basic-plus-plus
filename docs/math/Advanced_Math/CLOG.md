# CLOG

## 1. Syntax & Parameters
**Syntax:** `CLOG(z)`

**Parameters:**
- z : A complex or numeric expression.

## 2. Description & Usage
Returns the complex natural logarithm of a complex number.
Calculates ln(z) for a complex number z = a + bi. The result is ln(|z|) + i*arg(z).
Edge Cases:
- Invalid types (like Strings) will trigger a `Type Mismatch` error.
- Providing too many or too few arguments will trigger an `Argument Count Mismatch` error.
- Very large numbers may cause overflow. Always check your bounds.

## 3. Code Examples

```basic
20 PRINT CLOG(Z)
```

## 5. Implementation Details
Computes magnitude `r`. If `r` is 0, returns COMPLEX(0,0). Otherwise returns `COMPLEX(log(r), atan2(b, a))`.
**Mutability Constraints:** Built-in functions must not mutate their arguments. They are marked `FSAFE_PURE`.
**Troubleshooting:** If this fails, trace `bval_to_float` conversions. A failure in memory allocation for a new BValue (though rare for pure value returns) could cause an abort.
