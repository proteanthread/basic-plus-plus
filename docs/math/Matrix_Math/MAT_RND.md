# MAT RND

## 1. Syntax & Parameters
`MAT <array> = RND`

* `<array>`: The name of a pre-dimensioned 1D, 2D, or 3D numeric array.

## 2. Description & Usage
The `MAT RND` statement populates every element of a given array with a pseudo-random floating-point number between `0.0` (inclusive) and `1.0` (exclusive). This is highly useful for generating random datasets, procedural generation, or initializing weights in simulations.

## 3. Code Examples
```basic
10 DIM R(2, 2)
20 MAT R = RND
30 MAT PRINT R;
```

## 4. Internal C-Source Mapping
* Source File: `source/arrays/parser_mat.c`
* Function: `pi_parse_mat_cmd()`
* Condition: `pi_mat_match_ident(lex, "RND")`

## 5. Implementation Details
* **Parser Expectations:** The parser expects the `MAT` keyword, followed by an array name, an equals sign `=`, and the `RND` identifier.
* **Dimensionality:** Supports 1D, 2D, and 3D arrays.
* **Random Generation:** Uses a Linear Congruential Generator (LCG) state machine (`rt->rnd_seed = (rt->rnd_seed * 1103515245UL + 12345UL) & 0x7FFFFFFFUL;`). Values are normalized by dividing by `2147483648.0` (2^31).
* **Troubleshooting:** If `ERR_HOW` is raised, check that the array exists and is properly dimensioned.

## 8. Manual Testing Guide
To manually test `MAT RND`:
1. Open the BASIC++ console: `basicpp-console.exe` (Windows) or `./baspp-console` (Linux).
2. Enter:
   ```basic

   20 MAT A = RND
   30 MAT PRINT A;
   RUN
   ```
3. Verify that the matrix is filled with floating-point values between 0.0 and 1.0. Run multiple times to ensure values change if not seeded.
