# MAT TRN

## 1. Syntax & Parameters
`MAT <arrayA> = TRN(<arrayB>)`

* `<arrayA>`: The target 2D array that will store the transposed matrix.
* `<arrayB>`: The source 2D array to be transposed.

## 2. Description & Usage
The `MAT TRN` statement computes the transpose of matrix `<arrayB>` and stores it in `<arrayA>`. Transposition flips a matrix over its main diagonal, effectively swapping rows and columns. `<arrayA>` must be dimensioned such that its rows equal `<arrayB>`'s columns, and its columns equal `<arrayB>`'s rows.

## 3. Code Examples
```basic
10 DIM B(2, 3), A(3, 2)
20 B(0,0)=1: B(0,1)=2: B(0,2)=3
30 B(1,0)=4: B(1,1)=5: B(1,2)=6
40 MAT A = TRN(B)
50 MAT PRINT A;
```

## 4. Internal C-Source Mapping
* Source File: `source/arrays/parser_mat.c`
* Function: `pi_parse_mat_cmd()`

## 5. Implementation Details
* **Parser Expectations:** Matches `TRN`, consumes a left parenthesis, array name, and right parenthesis.
* **Dimensionality Check:** Both `<arrayA>` and `<arrayB>` must be 2D arrays. `<arrayA>` dimensions must precisely match the inverted dimensions of `<arrayB>` (`a->size[0] == b->size[1]` and `a->size[1] == b->size[0]`). If not, raises `ERR_HOW`.
* **Mutation:** Iterates through the target dimensions and applies `A(r,c) = B(c,r)` using 0-based packed 1D index mapping (`a_off = r * a->size[1] + c; b_off = c * b->size[1] + r;`).
* **Troubleshooting:**
  * `ERR_HOW`: Check that both arrays are 2D and the dimensions of `<arrayA>` exactly mirror those of `<arrayB>`.
